クラス

ここではプログラミングの中で重要な構文であるクラスについて説明します

クラスとは何か

1. クラスは「設計図」

Fletで TextField や ElevatedButton といったコントロールがありますよね。

これらは「クラス（設計図）」です。つまり、TextField というクラスは「テキスト入力欄はこういう構造・機能を持ちます」という定義をしています。

python

import flet as ft

def main(page: ft.Page):
# TextFieldクラスを元にオブジェクトを作成
name_input = ft.TextField(label="名前を入力")

# ElevatedButtonクラスを元にオブジェクトを作成
submit_button = ft.ElevatedButton(text="送信")

page.add(name_input, submit_button)

ft.app(target=main)

a

2. インスタンス化

Pythonのクラスでは、MyClass() のように呼び出すとインスタンスが生成されます。

Fletでも同じで、TextField() と書けばテキスト入力欄のオブジェクトができます。

つまり 「クラス」= 設計図、「インスタンス」 = 実際に画面に置かれる部品。

3. プロパティとメソッド

クラスには「プロパティ」と「メソッド」があります。

Fletのコントロールにも同じで、たとえば TextField には label や value というプロパティがあり、focus() というメソッドがあります。

python

name_input = ft.TextField(label="名前を入力")
name_input.value = "太郎" # プロパティの変更
name_input.focus() # メソッドの呼び出し

a

つまり、今まで使っていたFletのコントロールとはクラスなのです。

なぜクラスを使うのか

クラスを使う主なメリットは以下の通りです：

1. コードの再利用性が高まる

同じような処理を何度も書かずに、クラスを1つ作れば何度でも使い回せます。

2. データと機能をまとめて管理できる

関連するデータ（プロパティ）と処理（メソッド）を1つのクラスにまとめることで、コードが整理されます。

3. 複雑なプログラムを整理できる

大きなプログラムを「ユーザー管理」「データ処理」「UI部品」などの部品に分けて考えられます。

4. チーム開発がしやすくなる

クラスという単位で役割分担ができ、他の人が作ったクラスも使いやすくなります。

クラスの基本的な書き方

クラス定義の基本構造

python

class User: # クラス名は大文字で始める（PascalCase）
def __init__(self, name): # 初期化メソッド
self.name = name # インスタンス変数

def greet(self): # メソッド
return f"こんにちは、{self.name}さん！"

a

__init__ メソッドとは

__init__ はコンストラクタ（初期化メソッド）と呼ばれる特別なメソッドです。

・インスタンスが作られる時に自動的に呼ばれる

・インスタンスの初期設定を行う場所

・__init__ という名前は決まっており、変更できません

python

# User("太郎") と書くと、__init__(self, "太郎") が自動で呼ばれる
user1 = User("太郎")

a

self とは何か

self はそのインスタンス自身を指す特別な変数です。

python

class User:
def __init__(self, name):
self.name = name # このインスタンスのname属性に値を保存

user1 = User("太郎")
user2 = User("花子")

# user1のselfとuser2のselfは別のインスタンスを指している
print(user1.name) # 太郎
print(user2.name) # 花子

a

なぜ self が必要なのか

・クラス内のメソッドは、どのインスタンスに対して動作するのかを知る必要がある

・self によって「このインスタンスの属性」を参照・変更できる

・メソッドの第1引数は必ず self にする（Pythonの決まり）

インスタンス変数とは

self.name のように self. を付けて定義する変数をインスタンス変数と呼びます。

・インスタンスごとに異なる値を持てる

・クラス内のどのメソッドからもアクセスできる

・インスタンスが存在する限り値が保持される

python

class Student:
def __init__(self, name, grade):
self.name = name # インスタンス変数
self.grade = grade # インスタンス変数

def study(self, subject):
# 他のメソッドからもインスタンス変数にアクセスできる
print(f"{self.name}さんは{subject}を勉強しています")

student1 = Student("太郎", 2)
student1.study("数学") # 太郎さんは数学を勉強しています

a

シンプルな例で理解する

例1: ユーザークラス

python

class User:
def __init__(self, name, age):
self.name = name
self.age = age

def greet(self):
return f"こんにちは、{self.name}さん！"

def is_adult(self):
return self.age >= 20

# インスタンスを作成
user1 = User("太郎", 22)
user2 = User("花子", 18)

# メソッドを呼び出し
print(user1.greet()) # こんにちは、太郎さん！
print(user1.is_adult()) # True
print(user2.is_adult()) # False

a

例2: 学生クラス（データ管理の実例）

python

class Student:
def __init__(self, name, student_id):
self.name = name
self.student_id = student_id
self.scores = [] # 空のリストで初期化

def add_score(self, score):
self.scores.append(score)

def get_average(self):
if len(self.scores) == 0:
return 0
return sum(self.scores) / len(self.scores)

def show_info(self):
avg = self.get_average()
return f"{self.name}（ID: {self.student_id}）平均点: {avg:.1f}"

# 使い方
student = Student("山田太郎", "S001")
student.add_score(85)
student.add_score(92)
student.add_score(78)
print(student.show_info()) # 山田太郎（ID: S001）平均点: 85.0

a

この例では、学生の情報（名前、ID、点数）と処理（点数追加、平均計算、情報表示）を1つのクラスにまとめています。

Fletとの組み合わせ（応用）

クラスを自作すると、Fletのコントロールを組み合わせた自作部品も作れます。

python

import flet as ft

# 自作クラス（Fletの部品を組み合わせたもの）
class NameInput:
def __init__(self):
self.input = ft.TextField(label="名前を入力")
self.button = ft.ElevatedButton(text="送信", on_click=self.say_hello)
self.text = ft.Text()

def say_hello(self, e):
self.text.value = f"こんにちは、{self.input.value}さん！"
self.text.update()

# Fletに渡せるようにまとめる
def controls(self):
return [self.input, self.button, self.text]

def main(page: ft.Page):
ui = NameInput()
page.add(*ui.controls())

ft.app(target=main)

a

これでPythonのクラスで自分専用のコントロールを作れるのです。
