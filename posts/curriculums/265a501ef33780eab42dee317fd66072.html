クラス

ここではプログラミングの中で重要な構文であるクラスについて説明します

クラスとは何か

1. クラスは「設計図」

Fletで TextField や ElevatedButton といったコントロールがありますよね。

これらは「クラス（設計図）」です。つまり、TextField というクラスは「テキスト入力欄はこういう構造・機能を持ちます」という定義をしています。

python
1import flet as ft
2
3def main(page: ft.Page):
4    # TextFieldクラスを元にオブジェクトを作成
5    name_input = ft.TextField(label="名前を入力")
6    
7    # ElevatedButtonクラスを元にオブジェクトを作成
8    submit_button = ft.ElevatedButton(text="送信")
9
10    page.add(name_input, submit_button)
11
12ft.app(target=main)

a

2. インスタンス化

Pythonのクラスでは、MyClass() のように呼び出すとインスタンスが生成されます。

Fletでも同じで、TextField() と書けばテキスト入力欄のオブジェクトができます。

つまり 「クラス」= 設計図、「インスタンス」 = 実際に画面に置かれる部品。

3. プロパティとメソッド

クラスには「プロパティ」と「メソッド」があります。

Fletのコントロールにも同じで、たとえば TextField には label や value というプロパティがあり、focus() というメソッドがあります。

python
1name_input = ft.TextField(label="名前を入力")
2name_input.value = "太郎"      # プロパティの変更
3name_input.focus()            # メソッドの呼び出し

a

つまり、今まで使っていたFletのコントロールとはクラスなのです。

なぜクラスを使うのか

クラスを使う主なメリットは以下の通りです：

1. コードの再利用性が高まる

同じような処理を何度も書かずに、クラスを1つ作れば何度でも使い回せます。

2. データと機能をまとめて管理できる

関連するデータ（プロパティ）と処理（メソッド）を1つのクラスにまとめることで、コードが整理されます。

3. 複雑なプログラムを整理できる

大きなプログラムを「ユーザー管理」「データ処理」「UI部品」などの部品に分けて考えられます。

4. チーム開発がしやすくなる

クラスという単位で役割分担ができ、他の人が作ったクラスも使いやすくなります。

クラスの基本的な書き方

クラス定義の基本構造

python
1class User:  # クラス名は大文字で始める（PascalCase）
2    def __init__(self, name):  # 初期化メソッド
3        self.name = name  # インスタンス変数
4
5    def greet(self):  # メソッド
6        return f"こんにちは、{self.name}さん！"

a

__init__ メソッドとは

__init__ はコンストラクタ（初期化メソッド）と呼ばれる特別なメソッドです。

・インスタンスが作られる時に自動的に呼ばれる

・インスタンスの初期設定を行う場所

・__init__ という名前は決まっており、変更できません

python
1# User("太郎") と書くと、__init__(self, "太郎") が自動で呼ばれる
2user1 = User("太郎")

a

self とは何か

self はそのインスタンス自身を指す特別な変数です。

python
1class User:
2    def __init__(self, name):
3        self.name = name  # このインスタンスのname属性に値を保存
4
5user1 = User("太郎")
6user2 = User("花子")
7
8# user1のselfとuser2のselfは別のインスタンスを指している
9print(user1.name)  # 太郎
10print(user2.name)  # 花子

a

なぜ self が必要なのか

・クラス内のメソッドは、どのインスタンスに対して動作するのかを知る必要がある

・self によって「このインスタンスの属性」を参照・変更できる

・メソッドの第1引数は必ず self にする（Pythonの決まり）

インスタンス変数とは

self.name のように self. を付けて定義する変数をインスタンス変数と呼びます。

・インスタンスごとに異なる値を持てる

・クラス内のどのメソッドからもアクセスできる

・インスタンスが存在する限り値が保持される

python
1class Student:
2    def __init__(self, name, grade):
3        self.name = name      # インスタンス変数
4        self.grade = grade    # インスタンス変数
5    
6    def study(self, subject):
7        # 他のメソッドからもインスタンス変数にアクセスできる
8        print(f"{self.name}さんは{subject}を勉強しています")
9
10student1 = Student("太郎", 2)
11student1.study("数学")  # 太郎さんは数学を勉強しています

a

例2: 学生クラス（データ管理の実例）

python
1class Student:
2    def __init__(self, name, student_id):
3        self.name = name
4        self.student_id = student_id
5        self.scores = []  # 空のリストで初期化
6    
7    def add_score(self, score):
8        self.scores.append(score)
9    
10    def get_average(self):
11        if len(self.scores) == 0:
12            return 0
13        return sum(self.scores) / len(self.scores)
14    
15    def show_info(self):
16        avg = self.get_average()
17        return f"{self.name}（ID: {self.student_id}）平均点: {avg:.1f}"
18
19# 使い方
20student = Student("山田太郎", "S001")
21student.add_score(85)
22student.add_score(92)
23student.add_score(78)
24print(student.show_info())  # 山田太郎（ID: S001）平均点: 85.0

a

この例では、学生の情報（名前、ID、点数）と処理（点数追加、平均計算、情報表示）を1つのクラスにまとめています。

Fletとの組み合わせ（応用）

クラスを自作すると、Fletのコントロールを組み合わせた自作部品も作れます。

python
1import flet as ft
2
3# 自作クラス（Fletの部品を組み合わせたもの）
4class NameInput:
5    def __init__(self):
6        self.input = ft.TextField(label="名前を入力")
7        self.button = ft.ElevatedButton(text="送信", on_click=self.say_hello)
8        self.text = ft.Text()
9
10    def say_hello(self, e):
11        self.text.value = f"こんにちは、{self.input.value}さん！"
12        self.text.update()
13
14    # Fletに渡せるようにまとめる
15    def controls(self):
16        return [self.input, self.button, self.text]
17
18def main(page: ft.Page):
19    ui = NameInput()
20    page.add(*ui.controls())
21
22ft.app(target=main)

a

これでPythonのクラスで自分専用のコントロールを作れるのです。
