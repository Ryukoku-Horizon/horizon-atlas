リポジトリについて

ここではリポジトリについて改めて補足します。リポジトリ (repository) は、ファイルとその変更履歴を保存する場所です。

特に Git では、リポジトリはプロジェクトの履歴をすべて記録するデータベースと考えるとわかりやすいです。

リポジトリとは

Git におけるリポジトリは、

・プロジェクトのファイル

・ファイルの変更履歴（コミット）

・ブランチの情報

・設定

これらを すべて永続的に保存する場所。

リポジトリの種類

・ローカルリポジトリ

・リモートリポジトリ

があります。

ローカルリポジトリ

あなたの PC の中にあるリポジトリ。

「.git」という隠しフォルダがローカルリポジトリです。

git init コマンドを実行すると.gitが作られます。

bash
1プロジェクトフォルダ/
2 ├── .git/  ← ローカルリポジトリ（履歴データ）
3 ├── ...(開発ファイル)

a

ローカルリポジトリでは、

・git add

・git commit

・git branch

・git merge

などすべてできます。

GitHub なしでも普通に Git は使えます。

実は「ローカルリポジトリ」は .git フォルダのことです。

中を覗くと

powershell
1HEAD
2config
3objects/
4refs/
5logs/

a

難しそうに見えますが、Git の仕組みは全部ここに入っています。

削除すると Git 管理は完全に消えます。

リモートリポジトリ

GitHubのサーバーにあるリポジトリ。

複数人で共有するためのもの。

ローカルの変更を共有したい時は

powershell
1git push

a

他の人の変更を取り込みたい時は

powershell
1git pull

a

GitHubのリモートリポジトリは サーバー上の .git とファイル を持っているだけです。

GitHub は「見やすく表示」「連携しやすくする」ためのサービスであり、

本質的には「リポジトリの保管庫」です。

まとめ

リポジトリ = プロジェクト + その完全な履歴
