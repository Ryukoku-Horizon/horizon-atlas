1-3 無限ループを使ってみよう

a

さて、ここでは実装する7つの機能の内の「プレイヤーの数字が正解の数字と完全一致したなら、ゲームクリアとなりプログラムを終了させる」と「プレイヤーの数字が正解の数字と完全一致していないなら、もう一度プレイヤーが数字を入力させるようにし、正解できるまでプログラムが終わらせないようにする」の二つが作れるようなりましょう。ここでキーワードとなるのは「無限ループ」です。

ということで、ここでは無限ループについての説明と使い方について記述します。

a

Pythonの基礎文法カリキュラムでは、繰り返し文というのを学んだと思います。

python

alist = [1 , 2 , 3]

for i in alist:
    print(i)

上記のようなプログラムが繰り返し文のfor文のコードになります。for文の中に入ると、変数iの中にリストalistの左から順番に1つずつ値を代入し、for文の中のコードを繰り返して実行する。といった動きをするプログラムです。なんとなく思い出したでしょうか。

このfor文というのは、いわゆる終わりが見えているループ文となり、今回作成したい無限ループを制作するためにはこのfor文は使用できないのです。

では、どのようにしたら無限ループを実装できるのでしょうか。それは、このループ文という枠でくくられる「while文」という文法を使います。

while文は以下のように書く必要があります。

python

while 条件式:
    処理

while文は、whileの右に書かれている条件式が成立し続ける限り、永遠にwhile文の中にある処理をし続けるという動きをします。「永遠に」と書かれているとなんだか取り扱うのが怖くなりそうですが、こう書くしかないので許してください。

実際に使用例を見てみましょう。

python

a = 0

while a < 10:
    a = a + 1
    print(a)

結果

a

このコードを解説すると、最初に変数aの中に0を代入します。そして、今回の条件式は「aの値が10未満である間」となっています。最初はaの値は0なのでwhile文の中に突入します。そして、while文の中は、aに1を足した値をaに代入したのち、その時点までのaの値を出力します。そしてwhile文の中の処理がすべて終了した際に、もう一度条件式を判定します。次はaの値が1なのでまたwhile文の中に突入して…というのを繰り返していきます。最終的に条件式が成立しなくなるとwhile文の中の処理は行われず、その下にあるコードの処理を始める。といった動きになります。

ここまで読んで察しのいい方はわかると思うのですが、無限ループを実装させるためには条件式が永遠に成立し続ける必要があるということがわかります。どういうことかというと、今回書いたコードは、条件式を成立させないようにするためにwhile文の中でaの値を1ずつ足し続けたのですが、この部分を消せば無限ループが完成します。

python

a = 0

while a < 10:
    print(a)

こうするとaの値は0に固定されるため、永遠に0が出力されし続ける、ある意味恐怖なプログラムが完成します。実行してしまった場合は、「ctrl + C」を入力して強制終了させてください。

これで、「プレイヤーの数字が正解の数字と完全一致していないなら、もう一度プレイヤーが数字を入力させるようにし、正解できるまでプログラムが終わらせないようにする」という機能は実装できるようになります。

a

ちなみに、簡単に無限ループを実装できる方法があります。以下の2つのwhile文にまとめます。

python

#1つ目
while 1:
    処理
    
#2つ目
while True:
    処理

条件式の中に「1」か「True」と書くだけで簡単に無限ループが実装できます。この記述方法は、同じ処理を永遠に続けたいときに使われます。今回のNumer0nは、この記述方法を使って制作していきます。

a

では、「プレイヤーの数字が正解の数字と完全一致したなら、ゲームクリアとなりプログラムを終了させる」という機能を実装するためにはどうすればいいのでしょうか。

それは、「break文」というものを書くことによって実装することができます。

実際に使用例を見てみましょう。

python

a = 0

while 1:
    a = a + 1
    print(a)
    if a >= 10:
        break

結果

a

先ほどのコードを少し変えたものになります。条件式が「1」になったことによって、無限ループになってしまったのですが、while文の中に「aが10以上になったら」という意味を持つif文を追加しました。そのif文の中に「break」というものを記述しています。この「break」というものは、「どんな無限ループでも、実行すれば強制的にループから抜け出す」という意味があります。つまり、while文の中でaの値が1ずつ追加されていく中で、if文の中にある条件式が成立するようになり、無限ループを抜け出せることができるようになりました。これが無限ループを抜け出せる方法です。

これにより、「プレイヤーの数字が正解の数字と完全一致したなら、ゲームクリアとなりプログラムを終了させる」という機能を実装することができるようになりました。

a

ちなみに、break文を学ぶときは、ループ文の中の処理を一旦終了させ、もう一度ループ文の最初から処理を始めさせるcontinue文を学ぶ必要があるのですが、これについてはもう少し後の方で解説させていただきます。

a
