3-1 入力される数字の桁数を制限しよう

a

いよいよ、ゲーム本編を作っていきます。

まず実装する機能として、「プレイヤーが3桁および4桁の数字を入力できるところを作る」から始めていきましょう。

python

player_number = input("正解だと思う3ケタの数字を入力してください。:")
player = list(player)

print(player)

結果：

a

たったこれだけです。入力できるところを作るときにinput関数を使うことは基礎文法カリキュラムで学んだと思います。そして、input関数で入力された文字は文字列型で扱うので、わざわざ文字列化してlist関数にいれる必要はありません。

しかし、このままでは何桁でも入力できしまい、答えが3桁の数字なのに5桁で答えてしまうというゲームとして成り立たないことが起こってしまいます。まぁ、わざわざ3桁の数字で答えるものを3桁以外の数字で答える人はいないと信じたいのですが…

a

では、そんな数字の桁数を指定するためにはどうしたらいいのでしょうか。次のコードを見てください。

python

while 1:
    player_number = input("正解だと思う3ケタの数字を入力してください。:")
    player = list(player_number)

    if len(player) != 3:
        continue
    else:
        break

print(player)

結果

a

「数字の桁数を指定する」ということは、「想定されている桁数以外はもう一回入力し直してもらう」という意味に言い換えることができます。なので、ここではwhile文を使用し、無限ループを作成します。その中に先ほどの入力部分を書きます。そして、桁数を指定するところはif文の条件式に書かれているところではlen関数を使用します。len関数はカッコ内に入れた文字列の文字数やリストの要素の個数を整数型として生成する関数です。条件式の意味は「playerの中にあるリストの要素の個数が3個でないなら」となります。これを満たすとき、else文内のcontinue文が実行されます。また、else文では条件式の逆、つまり「playerの中にあるリストの要素の個数が3個であるなら」という意味になり、これを満たすとき、if文内のbreak文を実行されwhile文を抜けます。

以前、1-3にて説明を省いたcontinue文の説明ですが、今回はちゃんとやります。次のコードを見てください。

python

alist=[3, 5, 2, 5, 1, 8, 2, 6, 9, 4]

for i in alist:
    if i % 2 == 1:
        continue
    print(i)

結果

a

このコードは簡単に言うと、リスト内にある偶数だけを出力させるプログラムです。しかし、リスト内には偶数も奇数もあるのにどうやって偶数だけを取り出すことができているか、それを可能にしているのがcontinue文になります。continue文は「実行されればどんな状態であってもループ文の中の処理を一旦止めて、もう一回ループ文の最初から処理をする」という意味になります。今回continue文が書かれている場所はif文の中にあり、そこの条件式には「alistの左から順番に1つずつ取り出した値を代入された変数iを2で割った余りが1だった時」という意味があります。つまり奇数だった場合はif文内の処理であるcontinue文が実行され、出力の処理が行われずにループの最初からまた処理を始めるという動きをするため、実行結果では偶数だけを出力できるというわけです。

このような結果が得られることから、入力された数字の桁数が3桁ではなかった場合にもう一度数字を入力させることができる、continue文を採用しているのです。

a
