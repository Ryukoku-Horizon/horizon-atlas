データベースとの接続とテーブルの作成

今回はpythonとそのライブラリであるsqlite3を使用して、データベースとの接続方法と、テーブルの作成方法を紹介します。

データの保存形式

データの保存形式については「データベースとは」で一度説明しましたが、ここで改めて解説します。

データベースはテーブル（表）の形式で保存されます。

以下は人の基本情報を保存するためのpersonテーブルの例です。

a

テーブルは、データの集まりを格納する場所です。テーブルはデータを行とカラム（列）の構造で整理し、それぞれの行が個別のデータ項目を表し、列がデータの属性や種類を示します。

カラムはテーブルの各列を指し、それぞれの属性を表します。例えば、personテーブルには、「id」、「name」、「gender」のカラムを含ます。カラムごとにデータの型（文字列、数値など）が決められており、各カラムに保存されたデータがその属性に応じた情報を提供します。

行は、実際のデータが格納されている単位です。例えば、personテーブルの1行目が「1、Sato、Man」であれば、それが1つのデータとして保存されます。テーブル内の各行は通常、識別のために一意（他と重複しない値）のID（主キー）を持ちます。

データベースと接続する

pythonでデータベースを操作するには、まずデータベースと接続する必要があります。

まず、「TEST.db」という名前のデータベースファイルを作ってください。
(すでに「TEST.db」を作った人はそのままでいいです)

そして、conn.pyというファイルを作ってください。

conn.pyに、以下のようなコードを書いてください。

conn.py

python

import sqlite3

# データベースファイルの名前を保持
dbname = 'TEST.db'
# データベースに接続
conn = sqlite3.connect(dbname)
# データベースを操作するカーソルオブジェクトを作成
cur = conn.cursor()
# データベースにデータをコミット
conn.commit()

# データベースの接続を切断
cur.close()
conn.close()

a

コードを上から順番に説明します。

最初に、sqlite3モジュールをインポートします。
dbnameにデータベースの名前を代入します。
sqlite3モジュールのconnect関数の引数にdbnameを入れて、データベースと接続します。
データベースを操作するためのcursorオブジェクトを作成します。
データベースにデータをコミット（確定）します。
最後に、データベースの接続を切断します。

これでデータベースに接続し、操作することが可能となります。

このコードはsqlite3を使う場合、ほぼ毎回必要になります。これだけで内容を理解することはできないと思いますが、とりあえず今はデータベースを操作するために必要な前準備だと思っておいてください。

データベースの操作方法

データベースを操作するためには、基本的にcursorオブジェクトのexecute メソッドを使います。

データベース操作方法

python

cursorオブジェクト.execute('データベースへの命令')

a

データベースへの命令の部分は、SQLというデータベースを操作するための言語で書きます。

CRUD操作（データの保存、データの取得、データの編集、データの削除）は、基本的にこのexecuteメソッドを使い、引数にSQL文を入れて行います。なお、SQL文の部分が文字列であることに注意してください。

データベーステーブルを作成する

それでは、ここから実際にデータベースを操作しましょう。

データを保存するためには、まずテーブルを作成しなければなりません。

テーブルを作成するには、SQL文ではCREATE TABLE を使います。

CREATE TABLEの書き方

sql

CREATE TABLE テーブル名(’カラム名 カラムの属性’)

a

例えば、personという名前のテーブルに、id、name、age、genderというカラムを持たせたければ、下のように書きます。
conn.pyの内容を以下のようにしてください。

conn.py

python

import sqlite3

# データベースファイルの名前
dbname = 'TEST.db'
# データベースに接続
conn = sqlite3.connect(dbname)

# データベースを操作するカーソルオブジェクトを作成
cur = conn.cursor()

# テーブル作成
cur.execute(
'CREATE TABLE person(id INTEGER PRIMARY KEY AUTOINCREMENT, name STRING, age INTEGER, gender STRING)')

# データベースにデータをコミット
conn.commit()

# データベースの接続を切断
cur.close()
conn.close()

a

テーブルを作成するSQL文は以下のようになっています。

sql

CREATE TABLE person(id INTEGER PRIMARY KEY AUTOINCREMENT, name TEXT, age INTEGER, gender TEXT)

a

・idの属性は、INTEGER PRIMARY KEY AUTOINCREMENTです。

・nameの属性は、TEXTです。

・ageの属性は、INTEGERです。

・genderの属性は、TEXTです。

まずidを見ましょう。

idには、INTEGER、PRIMARY KEY、AUTOINCREMENTの三つの属性があります。
・INTEGERは、値の型であり、pythonでいうところのint型です。
・PRIMARY KEY は、テーブル内で各行を一意に識別するカラムに設定します。カラムは重複を許さず、NULL 値（空の値）も許可しません。
・AUTOINCREMENTは、あるデータが保存される時、idの値を指定していなくても自動で値が入るようにする属性です。

他を見ると、nameとgenderの属性はSTRINGであり、ageの属性はINTEGERです。
・TEXTは、値の型であり、pythonで言うところのstr型です。

一度、conn.pyを実行してみましょう。

TEST.dbの中を確認してください。TEST.dbの中が以下のようになっていればテーブルの作成に成功です。

a
