Pythonガイド

✅ 概要

このガイドは、Pythonがどんな言語なのかを紹介し、「Hello, World!」を出力するところまでをわかりやすく解説する学習資料です。

1. Pythonとは？

✔️ Pythonは、シンプルな文法でとても読みやすいプログラミング言語です。

✔️ プログラミングの初心者に向いの言語になります！

✔️ 機械学習、Web開発、データ分析、自動化などでよく使われます。

💡 Pythonの特徴

・書きやすい・読みやすい：英語みたいな文法で、初心者でもすぐに始められます。

・できることが多い：AI、ゲーム、自動処理、アプリ、グラフ、なんでもできる万能言語。

・ライブラリが多い：他の人が作った便利なライブラリをすぐに使える。

→ 例：NumPy(計算)、Pandas(データ分析)、Flask(Web)など。

・日本語の情報が多い： 初心者向けの本や記事、動画などの情報が多くあります。

a

📝 主なPython使用例

分野できること
Web開発Flask、DjangoなどでWebアプリを作れる
データ分析Excelより強力な集計やグラフ
機械学習・AI人工知能(AI)の開発に必須の言語
自動化面倒な作業(例：ファイル整理、スクレイピングなど)を自動化
ゲーム制作Pygameなどで簡単なゲームもOK

1-2. 開発環境の構築

✅ (1) Python本体をインストール

1. 公式サイト：https://www.python.org/ にアクセス

2. 「Download」から最新バージョンを選び、インストール

3. インストール後、ターミナルやコマンドプロンプトで確認：

shell
1python --version

a

または

shell
1python3 --version

a

→ Python 3.xx と出ればOK！

✅ (2) エディタのおすすめ：VS Code（Visual Studio Code）

1. VS Codeをインストール

2. 拡張機能「Python」をインストール

1-3. はじめてのプログラム - "Hello, World!"

Hello World を表示するコード

python
1print("Hello, World!")

a

実行方法（ターミナルやVS Code）：

1. hello.py という名前で保存

2. ターミナルで実行：

shell
1python hello.py

a

または

shell
1python3 hello.py

a

実行結果：

Hello, World!

a
