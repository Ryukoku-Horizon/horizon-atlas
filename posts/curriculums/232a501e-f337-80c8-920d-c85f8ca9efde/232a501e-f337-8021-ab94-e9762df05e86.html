シンプルメモアプリの手引き

Q. シンプルメモアプリとは？

A. ボタンを押すと、タイトルと本文を書けるメモ欄が下に追加されていくアプリです。

具体的には「買い物リスト」「日記」など、自由にメモとして書き残しておけるようなもの。

a

ただ今回は簡単にするために、保存機能や削除機能はつけず、書いて表示するだけで実装します。

具体的な使い方は、「メモを追加」ボタンを押して、「タイトル」と「本文」を入力するだけです。

主な機能

a

1. 「メモを追加」ボタンを押すと、タイトルと本文を書ける新しいメモ欄が1つ増える

1. 各メモ欄には、タイトル入力欄と本文入力欄の2つがある

1. 本文入力欄は複数行入力が可能

1. 何個でもメモを追加でき、下にどんどん積み重なっていく

a

一覧表示するColumnと、ボタンを用意する

目標：メモを一覧表示するColumnと、ボタンを用意しよう

目標の達成方法：

・メイン関数を定義

アプリの起動

python

import flet as ft

def main(page: ft.Page):
  page.add()

ft.app(main)

a

・メモを一覧表示するColumnをmemo_columnとして定義

空のColumn（memo_column）の作成

python

memo_column = ft.Column(
  controls=[]  # このリストに並べたいコントロールを入れる
)

a

・Columnは、縦にコントロールを並べるためのコンテナです。

・controlsプロパティはリストになっていて、その中にText, TextField, Containerなどのコントロールを追加できます。

・ここでcontrols=[]とするのは、最初は何も表示しない空のリストを持った状態でColumnを作るためです。

・メモを追加するボタンをadd_buttonとして定義

中に表示する文字をcontentプロパティに入れます

add_button の作成

python

add_button = ft.FilledTonalButton(
    content=ft.Text(
        value="メモを追加",
    )
)

a

・memo_columnとadd_buttonをpage.addでページに追加します

部品をページに追加する

python

page.add(memo_column,add_button)

a

a

2. 「メモを追加」ボタンを押すと、新しいメモが表示される

目標：

「メモを追加」ボタンを押すと、画面下に1つのメモが追加される

目標の達成方法：

・on_click=add_memo でボタンに関数を紐づける

・add_memo関数の中で、memo_column.controls.append(...) を使ってメモカードを追加

・追加後に memo_column.update() を実行して画面を更新

add_memo関数の定義

python

def add_memo(e):
    memo_column.controls.append(
        ft.Container(
            content=ft.Column(
                controls=[
                    ft.TextField(...),  # タイトル入れるTextField
                    ft.TextField(...),  # 本文入れるTextField
                ]
            ),
            ...
        )
    )
    memo_column.update()

a

なぜmemo_column.controls.append(...)と書けるの？

3. 本文入力欄は複数行に対応している

目標：

メモ本文を長く書けるように、複数行入力を可能にしたい

目標の達成方法：

・下側のTextFieldに multiline=True を設定するだけ

TextFieldにmultiline=Trueを設定

python

ft.TextField(
    multiline=True
)

4.見た目を整える

目標：見やすいようにアプリ全体の見た目を整える

目標の達成方法：

・メモをカードのような見た目にする

Containerを使って、内側の余白(padding)や、枠線(border)、角丸(border_radius)を指定

カードの右ようなメモ枠を作る Container の設定

python

ft.Container(
    padding=ft.padding.symmetric(vertical=5, horizontal=15),
    border=ft.border.all(width=2, color=ft.colors.BLACK54),
    border_radius=20
)

a

・TextFieldを整える

python

ft.TextField(
    hint_text="タイトル",
    hint_style=ft.TextStyle(color=ft.colors.BLACK26),
    text_size=20,
    border=ft.InputBorder.UNDERLINE # ft.InputBorder.NONEにすると枠線が非表示になる
)

a

hint_textプロパティでヒントテキストを表示 hind_styleプロパティでヒントテキストの見た目を設定できます（今回は色を設定します） text_sizeプロパティで入力文字の大きさを設定できます borderプロパティで枠線について設定できます（タイトルではft.InputBorder.UNDERLINEを設定し、本文ではft.InputBorder.NONEを設定しましょう）

・FilledTonalButtonの見た目を整える

python

add_button = ft.FilledTonalButton(
  content=ft.Text(
    value="メモを追加", 
    size=20
  ),
  height=50,
  width=page.window.width,　
  on_click=add_memo
)

a

各サイズの設定

中のTextコントロールのsizeプロパティで文字の大きさを設定する
heightプロパティで高さを設定する
widthで横幅を設定する（page.window.widthはページ全体の横幅のこと）
