TypeScriptガイド

✅概要

このガイドは、TypeScriptがどんな言語なのかを紹介し、「Hello, World!」を出力するところまでをわかりやすく解説する学習資料です。

1. TypeScriptとは？

「JavaScriptに型（Type）を加えたプログラミング言語」のことです！

💡 特徴

・コンパイルすると普通のJavaScriptになる

・型のおかげでバグを減らしやすい

・大規模開発に向いている

例えば、以下のコードを見てください

typescript
1function add(a: number, b: number): number {
2  return a + b;
3}
4
5add(1, "2"); // ❌ エラーが出る

a

JavaScriptの場合、このようなコードでもエラーが起きず、アプリでバグが発生した時にどこがおかしいのかを見つけるのが困難です。しかし、TypeScriptの場合、こうして「間違った使い方」をした部分でエラーが出るので、バグをすぐに発見できて、開発がどんどん楽になる、というわけです！

a

1-2. 開発環境の構築

・VS Codeを使用：Visual Studio Codeを使用

・公式サイト（https://nodejs.org/ja）からNode.jsをインストール（Node.jsについてはこちらで解説しています）

プロジェクトの作成

新しいフォルダ（ディレクトリ）を作成し、以下のコマンドでプロジェクトを作成します

powershell
1npm init

a

以下のコマンドでtypescriptとそれを実行するためのライブラリをインストールします

typescript - TypeScriptのこと
@types/node - TypeScriptの型のこと
ts-node - TypeScriptを実行するためのもの

powershell
1npm install typescript @types/node ts-node

a

プロジェクト直下にtsconfig.jsonというファイルを設置し、中に以下の内容を記述します

json
1{
2    "compilerOptions": {
3      "target": "es6",
4      "module": "commonjs",
5      "rootDir": "./",
6      "outDir": "./dist",
7      "esModuleInterop": true,
8      "strict": true
9    },
10    "include": ["**/*.ts", "index.ts"],
11    "exclude": ["node_modules"]
12  }

a

（tsconfig.jsonは、TypeScriptをコンパイルするための設定ファイルです）

最後に、package.jsonの中身を以下のように書き換えます

json
1{
2  "name": "test",
3  "version": "1.0.0",
4  "description": "",
5  "main": "index.ts",
6  "scripts": {
7    "index": "ts-node index.ts"
8  },
9  "author": "",
10  "license": "ISC",
11  "dependencies": {
12    "@types/node": "^22.15.2",
13    "ts-node": "^10.9.2",
14    "typescript": "^5.8.3"
15  }
16}

a

1-3. はじめてのプログラム - "Hello, World!"

基本的な作動方法を理解するために、「Hello, World!」を出力する簡単なコードを見てみましょう！

Hello Worldを表示するコード

javascript
1console.log("Hello World!")

a

実行方法：

( 1 ) コードをindex.tsファイルとして保存する

( 2 ) npm run indexコマンドを実行

実行結果：

Hello, World!

a

a

コード概説：

javascript
1console.log("Hello World!")

a
