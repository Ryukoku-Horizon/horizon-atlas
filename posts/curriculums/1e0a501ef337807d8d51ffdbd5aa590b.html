Cガイド

Cガイド

a

✅概要

このガイドは、C言語がどんな言語なのかを紹介し、「Hello, World!」を出力するところまでをわかりやすく解説する学習資料です。

1. C言語とは？

✔️ OS(windows, Linuxカーネル)やシステム、ゲーム開発などで広く使用されています。
✔️ 手続き型言語で、ポインタや構造体を活用し効率的なプログラムのメモリ管理が可能です。

💡C言語の特徴

・高速かつ効率的：コンパイルしたC言語のプログラムは実行速度が速く、リソースの少ない環境でも作動します。

・低レベルプログラミング：ソフトの深い操作（例：メモリ、アドレス操作）ができるため、ドライバやOS開発に多く使われています。

・多くの言語基礎：C++、Java、Pythonなど近年多くの使われているプログラミング言語は、C言語の構造や概念を基に作られています。

1-3. はじめてのプログラム - "Hello, World!"

C言語の基本的な作動方法を理解するために、「Hello, World!」を出力する簡単なコードを見てみましょう！

Hello Worldを表示するコード

c

#include <stdio.h>

int main() {
    printf("Hello, World!\n");
    return 0;
}

コード概説：

c

#include <stdio.h>             // 1. stdio.hというヘッダーファイルを参照する。

int main() {                   // 2. mainの宣言
    printf("Hello, World!\n"); // 3. 出力するprint関数
    return 0;                  // 4. 関数が終わったら0をreturn
}

a

このように、C言語では#include <stdio.h>で入出力ヘッダーを読み込み、main関数からプログラムが実行されます。

そしてprintf関数でconsoleに文字列を出力し、最後にreturn 0;で正常的に終了したことを表します。

💡

C言語は手続き言語で必ず1行目から下にコンパイル、実行されますので順序を気を付けて使いましょう。
