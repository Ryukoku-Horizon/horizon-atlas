表示する画像を指定する

どの画像を表示するかは、Imageコントロールのsrcプロパティで設定します。

srcプロパティには、表示したい画像ファイルの保存先を指定します。

例えば、プログラムファイル (main.py) と写真データ (picture.jpg) が以下のように同じディレクトリに配置されているとします。

│
├ main.py
└ picture.jpg

a

このとき、アプリ上にpicture.jpgを表示するにはsrcプロパティにmain.pyからの相対パスを指定します。

今回のカリキュラムで使用しているpicture.jpg

srcで画像を指定

コード↓

python
1import flet as ft
2
3def main(page: ft.Page):
4	img = ft.Image(src="./picture.jpg")
5	
6	page.add(img)
7
8ft.run(main)

インターネット上の画像を使う

FletのImageコントロールでは、ローカルに保存されている画像だけでなくネット上の画像も使用することができます。

方法は簡単。先ほど画像の保存先を指定したsrcプロパティに、画像への直リンクを指定します。

python
1img = ft.Image(src="https://example.com/xxx/...")

a

たとえば、https://picsum.photos/id/299/500/500にアクセスするとニューヨークの街中の写真にアクセスできます。

これを、srcプロパティに設定してみると…

こんな感じで、画像をダウンロードしなくてもアプリに画像を表示することができました。

サイズの指定方法

もちろん、画像の表示サイズを指定することも可能です。

サイズの指定には、widthプロパティおよびheightプロパティを使用します。

先程のpicture.jpgを小さく表示したい場合は、このように記述しましょう。

横幅を300に設定

コード↓

python
1import flet as ft
2
3def main(page: ft.Page):
4	img = ft.Image(src="picture.jpg", width=300)
5	
6	page.add(img)
7
8ft.run(main)

a

その出力結果↓

widthとheightは同時に設定することもできますが、後述するfitを設定しないと小さい方のサイズに合うように、縦横比をそのまま画像を小さくされてしまいます。

たとえば、widthは同じ300でも、heightをより小さい150に設定すると、150のほうに引っ張られて画像がさらに小さくなりました。

高さも指定

コード↓

python
1img = ft.Image(src="picture.jpg", width=300, height=150)

a

その出力結果↓

💡

この画像のサイズ指定について、厳密には画像自体のサイズを指定しているわけではありません。

角を丸める

最初のスクショのアイコン画像のように、画像の角を丸めることもできます。

これには、border_radiusプロパティを使用します。

border_radiusプロパティの指定方法は2通りあります。単純に数字で設定する方法とft.border_radiusクラスを使う方法です。

数字で指定

丸みの半径を数字で指定します。

例えば、縦横200の画像に対してborder_radiusを50に設定すると、各隅が1/4ぐらい丸まった画像が表示されます。

画像の丸みを指定

コード↓

python
1img = ft.Image(src="./user_icon.jpg", width=200, height=200, border_radius=50)

a

その出力結果↓

さらに数字を大きくして100にすると、縦横の半分の数字となるので正円の画像となります。

アイコン表示などに使えます。

まんまるの画像を表示

コード↓

python
1img = ft.Image(src="./user_icon.jpg", width=200, height=200, border_radius=100)
