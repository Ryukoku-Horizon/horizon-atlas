a

ここでは「動的ルーティング」について解説します。

動的ルーティングを使うことによってページを1枚ずつ手作業で作る膨大な手間を省けることにつながります。

目次

静的ルーティングと動的ルーティング

ルーティングには大きく分けて 「静的ルーティング」 と 「動的ルーティング」 があります。

名前だけだとイメージしにくいので、まずは具体例で見てみましょう。

静的ルーティング

「ページの住所（ページルート）があらかじめ決まっている」ルーティング方法です。

中身も基本的に固定で、誰がアクセスしても同じページが表示されます。

📌

例

・/about → 会社概要ページ

・/contact → お問い合わせページ

・/product → 製品紹介ページ

✅ 特徴

・ページルートが固定されている

・ページの読み込みが速い

・ページ数が少ないサイトに向いている

動的ルーティング

「ページの住所の一部が変数になっている」ルーティング方法です。

アクセスするユーザーやデータによって、表示される内容が変わります。

📌

例

・/user/[id]

→ id=1 なら /user/1

→ id=2 なら /user/2

（同じ仕組みで、商品ページ /product/[id] なども作れる）

✅ 特徴

・ページルートの一部が可変（パラメータになる）

・多くのページを効率よく管理できる

・ユーザーや商品ごとのページに便利

a

TemplateRouteクラス

まず動的ルーティングをFletで実装するには、TemplateRouteというクラスを使う必要があります。

TemplateRouteというクラス

python
1ft.TemplateRoute()

a

このクラスは「ページルートを分解して、どのルートに一致しているか」を調べるためのものです。

基本の使い方

まずは現在のルートをもとに TemplateRoute のインスタンスを作ります。

TemplateRouteのインスタンス

python
1template_route = ft.TemplateRoute(page.route)

a

このインスタンスを使って、match メソッドでルートを判定します。

・match("/user") → URLが/userなら True を返す

・match("/") → URLが/なら True を返す

実装例

以下のようにルーティングを実装できます。

ルーティング

python
1import flet as ft
2
3def main(page: ft.Page):
4    def route_change():
5        page.views.clear()
6        template_route = ft.TemplateRoute(page.route)
7
8        if template_route.match("/user"):
9            page.views.append(
10                ft.View(
11                    route="/user",  # ユーザーページ
12                    controls=[ft.Text("ユーザーページだよ！")]
13                )
14            )
15        elif template_route.match("/"):
16            page.views.append(
17                ft.View(
18                    route="/",  # 最初のページ
19                    controls=[ft.Text("最初のページだよ！")]
20                )
21            )
22            
23    page.on_route_change = route_change
24    route_change()
25
26ft.run(main)

a

if template_route.match("/user"):ここで、ページルートが”/user”であれば、ユーザーページを表示します。

elif template_route.match("/user"):ここで、ページルートが”/”であれば、最初のページを表示します。

このように、TemplateRouteクラスを使うことによってルーティングを実装できます。

a

動的ルーティングの実装

1. 動的ルートの書き方

ページルートの一部を 変数（パラメータ） にできます。

変数にしたい部分は、先頭に : をつけます。

python
1template_route.match("/user/:id")

a

この場合、

・/user/1

・/user/123

のようなURLがすべてマッチします。

ここでの :id が動的な部分です。

ページルートの活用

上記のページルートの一部を変数にすることで動的ルーティングは実装できますが、ページルートの変数部分を活用しなければ意味がないです。

ページルートの変数部分はTemplateRouteクラスのプロパティとなって保管されます。例えば、以下のように変数部分を取得できます。

変数部分の取得

python
1if template_route.match("/user/:id"):
2	user_id = template_route.id

a

つまり、template_route.ページルートの変数部分のようにしてページルートを取得できます。

動的ルーティングの実装例

動的ルーティング

コード↓

python
1import flet as ft
2
3
4def main(page: ft.Page):
5
6    def route_change(e=None):
7        template_route = ft.TemplateRoute(page.route)
8
9        page.views.clear()
10
11        if template_route.match("/user/:id"):
12            user_id = template_route.id
13
14            async def go_home(e):
15                await page.push_route("/")
16
17            page.views.append(
18                ft.View(
19                    route=f"/user/{user_id}",
20                    controls=[
21                        ft.Text(f"ユーザーID: {user_id}のページです"),
22                        ft.Button(
23                            content="ホームに戻る",
24                            on_click=go_home,
25                        ),
26                    ],
27                )
28            )
29
30        elif template_route.match("/"):
31            user_id_field = ft.TextField(
32                label="ユーザーIDを入力してください"
33            )
34
35            async def go_user(e):
36                await page.push_route(f"/user/{user_id_field.value}")
37
38            page.views.append(
39                ft.View(
40                    route="/",
41                    controls=[
42                        ft.Text("ホームページ"),
43                        user_id_field,
44                        ft.Button(
45                            content="ユーザーページへ",
46                            on_click=go_user,
47                        ),
48                    ],
49                )
50            )
51
52    page.on_route_change = route_change
53
54    route_change()
55
56
57ft.run(main)

a

その出力結果↓

📌 この例では：

・ホームでユーザーIDを入力してボタンを押すと /user/入力したID に移動

・そのIDに応じてページが生成されます

まとめ

・:id のように書くとURLの一部を 動的パラメータ にできる

・値は TemplateRoute のプロパティで取得できる (template_route.id)

・これにより、ユーザーごとや商品ごとのページを簡単に作れる
