CRUD操作を使い回せるようにしよう

今回は、CRUD操作をする使い回し可能な関数の作り方の一例を紹介します。

なお、今回示す例はすべて、「データベースとの接続とテーブルの作成」で作成したデータベースを操作する関数となっています。テーブルのカラムなどを知りたい方はそちらのページをご覧ください。

共通の部分

まず、CRUD操作はすべて、データベースとの接続が不可欠です。

ですので、データベースと接続する部分のコードはCRUD操作をする関数の共通部分となります。

「データベースとの接続とテーブルの作成」においてすでに紹介しましたが、改めてデータベースと接続するコードを見ておきましょう。

データベースと接続するコード

python

dbname = 'TEST.db'
conn = sqlite3.connect(dbname)
cur = conn.cursor()

conn.commit()

cur.close()
conn.close()

a

このコードがCRUD操作をする関数の共通部分となります。conn.commit()がデータベースへの操作を確定する部分となるので、その上にデータベースを操作するコードを付け足すことになります。

データの保存

データを保存するための使い回し可能な関数の一例を示します。

データを保存する関数

python

def insert_data(name, age, gender):
	dbname = 'TEST.db'
	conn = sqlite3.connect(dbname)
	cur = conn.cursor()
	
	cur.execute('INSERT INTO person(name, age, gender) VALUES (?, ?, ?)', (name, age, gender))
	
	conn.commit()
	
	cur.close()
	conn.close()

a

この関数では、引数として受け取ったname、age、gender の値が、それぞれのカラムに保存されるようになっています。

この関数は以下のように使用できます。

insert_data の使用例

python

insert_data("Jeido", 40, "Woman")

a

これで、カラムnameに”Jeido”、カラムageに40、カラムgenderに”Woman”がそれぞれ保存されます。

データの取得

データを取得するための使い回し可能な関数の一例を示します。

任意のデータを取得する関数

python

def get_data(id):
    dbname = 'TEST.db'
    conn = sqlite3.connect(dbname)
    cur = conn.cursor()

    cur.execute('SELECT * FROM person WHERE id = ?',(id,))
    data = cur.fetchall()

    conn.commit()

    cur.close()
    conn.close()

    return data

a

a

すべてのデータを取得する関数

python

def get_all_data():
    dbname = 'TEST.db'
    conn = sqlite3.connect(dbname)
    cur = conn.cursor()

    cur.execute('SELECT * FROM person')
    data = cur.fetchall()

    conn.commit()

    cur.close()
    conn.close()

    return data

a

get_data は引数のid の値でどのidの行を取得するかを指定できます。

get_dataとget_all_dataの戻り値は、それぞれ取得したデータのリストです。

get_dataの使用例

python

# 一行目のデータを取得する
print(get_data(1))

a

データの編集

データを編集するための使い回し可能な関数の一例を示します。

データを編集する関数

python

def update_data(name, age, gender, id):
	dbname = 'TEST.db'
	conn = sqlite3.connect(dbname)
	cur = conn.cursor()
	
	cur.execute('UPDATE person SET name = ?, age = ?, gender = ? WHERE id = ?', (name, age, gender, id))
	
	conn.commit()
	
	cur.close()
	conn.close()

a

update_data は、引数のname、age、genderが、それぞれのカラムの値となっており、引数idの値でどの行を編集するか指定できるようになっています。

update_data の使用例

python

update_data("Watanabe", 32, "Man", 1)

a

これで、一行目のデータを、カラムnameを"Watanabe"に、カラムageを32に、カラムgenderを”Man”に編集できます。
