コンテナ起動までの流れ

コンテナ起動までの流れ

ここでは、コンテナを起動するまでの流れを説明します

プロジェクトフォルダを作る

まず、アプリのファイルを置くフォルダを作ります

そのフォルダの上にapp.pyと言うpythonのファイルを作成し、以下の内容を記述してください

python

# app.py
print("Hello from Docker!")

a

Dockerfileを作成

同じディレクトリに以下の内容で Dockerfile を作成します：

docker

# Python公式イメージを使用
FROM python:3.11
# 作業ディレクトリを設定
WORKDIR /app
# ファイルをコンテナにコピー
COPY . /app
# アプリを実行する
CMD ["python", "app.py"]

a

Dockerfileのコードの説明

今のディレクトリ構成

a

Docker イメージをビルド

Docker DesktopまたはDocker Engineを起動してください

Dockerfileがあるディレクトリで以下を実行：

shell

docker build -t my-python-app .

a

・t my-python-app はイメージに名前をつけている部分。

・. は現在のフォルダ（Dockerfileの場所）を指定。

これで my-python-app という名前のDockerイメージが作成されます。

コンテナを起動する

ビルドしたイメージからコンテナを起動します：

shell

docker run --name my-running-app my-python-app

a

・-name はコンテナに名前をつけるオプション（省略可）。

・コンテナが起動すると app.py が実行されて、出力が表示されます。

つまり、my-python-appと言うイメージを元にmy-running-appと言う名前のコンテナを起動します。

期待される出力

shell

Hello from Docker!

a

おまけ：不要になったら掃除

shell

docker ps -a                 # コンテナ一覧表示
docker rm my-running-app     # コンテナ削除
docker rmi my-python-app     # イメージ削除

a
