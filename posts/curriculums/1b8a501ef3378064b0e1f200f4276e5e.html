3. 変数の型

今回は、コードの注釈をつけるコメントアウトと、データの種類を決める変数の型を学習します。

コメントアウトは、プログラムの実行を邪魔せずに説明を付け加えることができ、変数の型は、今後プログラミングをやっていく上で非常に重要になっていきます。

目次

プログラム上のコメント

プログラム上に、そのプログラムの処理の説明などを残したいときがあると思います。例えば、次のように…

横にそのまま説明文を書く

コード↓

python
1a = 10         変数 a に10を代入
2b = 5          変数 b に5を代入
3print(a, b)    a と b を出力

a

その出力結果↓

a

しかし、これではエラーが起こってしまいます。1章「Hello World!」でも紹介したように、プログラムに全角文字はあってはいけませんし、そもそもプログラムとして成り立っていません。

そこで使うのが、「#」です。ハッシュタグとかシャープとか呼ぶ記号ですね。

説明として残したい部分の頭に「#」をつけてみましょう。

説明部分の頭に「#」をつける

python
1a = 10         #変数 a に10を代入
2b = 5          #変数 b に5を代入
3print(a, b)    #a と b を出力

a

ちなみにコメントアウトのテクニックとして…

こうすることで、プログラム中の#以降はパソコンに無視されるようになり、エラーもなくなります。

#を使って説明を書くことをコメント、旧コードなど今使いたくはないけれど残しておきたい部分をコメント化することをコメントアウトといいます。コメントはこれからの説明でも頻繁に使っていくのでぜひ覚えていてください。

a

変数の型

では、本題に取り掛かりましょう！

「変数の型」とは、変数にどのようなデータを格納するかを決めるルールです。Pythonでは、その変数にどのようなデータが格納されたかで変数の型が決まります。

例えば、次のプログラムでは…

格納するデータによって、変数の型が決まる

python
1a = 10    #a は整数型
2b = 3.5   #b は実数型
3c = "文字列" #c は文字列型

a

変数 a には整数である10が格納されているので、変数 a は「整数型」ということになります。
プログラミングでは、少数を含む数字を実数と呼びます。変数 b は実数である3.5が格納されているため「実数型」となります。

また、数字ではなく”文字列”のような文字のデータに関しては、文字列と呼びます。Pythonでは、任意のテキストをダブルクォート(””)で囲むことで文字列とすることができます。よって、変数 c は「文字列型」となります。文字列に関しては、Pythonカリキュラムの後半で詳しく扱います。

Pythonでは、この 型 は変数にどのようなデータが代入されたかで決まります。また、違う型の値を代入すれば、その変数の型は自動的に変更されます。

種類の異なるデータを格納する

python
1a = 5      #この時点では a は整数型
2a = 4.2    #実数が代入されたため、a は実数型に変更
3a = "文字"  #文字列が代入されたため、a は文字列型に変更

a

a

型の確認

プログラミングをしていると、変数がどの型であるかを知りたくなるときがあります。Pythonにはこのための便利な機能があります。type関数と呼ばれるものです。type関数は続く()の中に型を知りたい変数をいれると、その変数がどの型であるかを教えてくれます。次のように使うことが一般的です。

type関数の使用例

コード↓

python
1a = 10   
2b = 3.5
3c = "文字列"
4print(type(a))  #a の型を確認
5print(type(b))  #b の型を確認
6print(type(c))  #c の型を確認

a

その出力結果↓

<class 'int'>
<class 'float'>
<class 'str'>

a

型の呼び方は英語と日本語で異なるため、以下のような出力になります。

日本語英語
整数型integer または int
実数型float
文字列型string または str

これらの英語での呼び方は、プログラミングの分野では一般的に使われることがあるので、ぜひ覚えておきましょう。

a
