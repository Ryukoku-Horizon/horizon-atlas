import文

import文

ほとんどの場合、Pythonでコードを書くと、一番はじめに行う命令はimportです。今回はこのimportが何を行なっているのか、どのように使うのかを学んでいきます。

import文とは

結論から言うと、「モジュール」をそのファイル内で使えるようにするための命令です。

と言われてもあまりピンとこないと思いますので、順番に説明していきます。

概要

pythonで言う「モジュール」とは、関数やクラスなどが定義されたpythonファイルのことです。ですので、「モジュールをそのファイル内で使えるようにする」というのは、つまり、他のpythonのファイルで定義された関数やクラスなどを、import文で呼び出したファイル内で使えるようにするということです。

import文の書き方

python

import モジュール名

a

例えば、みなさんにお馴染みのモジュールといえばFletが挙げられます。

Fletをimport文で呼び出す例

python

import flet as ft

a

このように書くことで、fletというモジュールを呼び出しているわけです。これによって、みなさんは、fletモジュール内で定義された関数やクラスを使えて、アプリを簡単に開発できるのです。

import flet の後ろにあるas ft は、fletというモジュールの呼称を定めているコードです。これによって、fletモジュールをftという名前で使用できます。

使い方

呼び出したモジュールの関数やクラスを使用するには、モジュール名.関数名やモジュール名.クラス名 というように、呼び出した関数やクラスの前にモジュール名をつける必要があります。as ftと言うのは、このモジュール名をftにしていると言うわけです。

したがって、例えば、ft.Text() と言うのは、fletモジュールの中で定義されているTextと言うクラスを使用しているわけです。Fletを使って開発するときに、ft. と書くのは、このように、使用するクラスや関数がfletモジュール内で定義されていることを明示するためです。

自分で作成したモジュールを呼び出す

上述した通り、import文はモジュール（他のpythonファイル）を呼び出す命令です。

Fletは他の人が開発したモジュールでしたが、みなさんも自分のpythonファイルで関数やクラスを定義することができますよね。import文を使うと、あるファイルで定義した関数やクラスを、別のファイルで使用することができるようになります。

例えば、以下のようにscript.pyで定義した関数を、main.pyで呼び出して使用することができます。

script.py

python

def add_number(a,b):
	return a + b

a

main.py

python

import script

print(script.add_number(4,5))

a

main.pyを実行すると、9 と出力され、script.pyで定義された関数を使用できることがわかります。

このように、import文を使うことによって、複数のファイルを使って開発をすることができるようになります。

💡

複数のファイルを使って開発することのメリット

複数のファイルを使って開発をすることによって、一つのファイルにコードを詰め込まなくてよくなり、コードが読みやすくなります。また、汎用的な関数やクラスをそれぞれのファイルに分けて定義しておくことで、再度ゼロからコードを書く必要がなくなり、開発効率が劇的によくなります。

from文

一度ふりかえると、import文を使って他のファイルで定義されている関数を使用する場合、以下のように書きます。

他のファイルで定義された関数を使用する

python

import script

print(script.add_number(4,5))

a

このように他のファイルの関数を使用するには、モジュール名.関数名 と、関数の前にモジュール名をつける必要があります。

しかし、その関数を何度も使う場合、モジュール名を毎回つけるのは面倒に感じるときもあるでしょう。そのような時には、from文を使って、モジュール内の関数やクラスを単体で呼び出しましょう。

from文の書き方

python

from モジュール名 import クラス名、関数名、変数名など

a

先ほどのscriptファイルからadd_number関数を単体で呼び出すとすれば以下のように書きます。

main.py

python

from script import add_number

print(add_number(4,5))

a

このようにfrom文を使うことによって、関数やクラスを単体で呼び出すことができます。

（呼び出した関数やクラスを使用する時にモジュール名を書かずにそのまま使えます。）

a
