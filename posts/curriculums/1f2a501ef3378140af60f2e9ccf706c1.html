8. プロパティへのアクセス

Fletでは、ボタンやテキストフィールドなどのコントロール（UI部品）にある「プロパティ（属性）」をコードから読み取ったり、変更したりすることができます。

この章では、実際のプログラムを通して、コントロールのプロパティにアクセスする方法を学びます。

プロパティってなに？

プロパティとは、4. コントロール で説明したようにコントロールが持っている情報や設定のことです。

例えば、Textコントロールは以下のようなプロパティを設定できます。

プロパティ説明
value表示する文字
size文字の大きさ
color文字の色

プロパティは、基本的にコントロールを作成するときに設定しますが、あとから変更することも可能です。

そのため、例えば、状況に応じて文字の内容や、コントロールの大きさなど、柔軟に設定することができます。

実例で確認しよう

プロパティの設定

以下のコードでは、Textコントロールのプロパティの設定をしています。

実際にコードをコピーして実行してみましょう

python
1import flet as ft
2
3def main(page: ft.Page):
4
5    hello_world_text = ft.Text(value="Hello World!",size=25,color="blue")
6    page.add(hello_world_text)
7
8ft.app(target=main)

a

このコードを実行すると、以下のように少し大きくて青いHello World!という文字が表示されます。

a

ポイント解説

python
1hello_world_text = ft.Text(value="Hello World!",size=25,color="blue")

a

プロパティを設定するには、プロパティ名=値という形式で書きます。

例えば、value="Hello World!"というのはvalueプロパティを"Hello World!"という値に設定しています。valueプロパティは、Textコントロールの表示する文字に当たるので、このように設定することで、"Hello World!"という文字が表示されます。

size=25は、文字の大きさを設定しており、color="blue"は、文字の色を設定しています。

a

プロパティへのアクセス

以下は、Textコントロールのvalueプロパティ（表示する文字）をprint関数でターミナルに表示するコードです。

実際にコードをコピーして実行してみましょう

python
1import flet as ft
2
3def main(page: ft.Page):
4    def outputText(e):
5	    print(hello_world_text.value)
6
7    hello_world_text = ft.Text("Hello World!")
8    output_button = ft.FilledButton(text="表示する", on_click=outputText)
9
10    page.add(hello_world_text,output_button)
11
12ft.app(target=main)

a

a

ポイント解説

python
1print(hello_world_text.value)

a

改めて言いますが、Textコントロールは、文字を表示することができるコントロールです。その表示される文字というのは、valueプロパティにあります。なので、hello_world_textで表示している"Hello World!"は、そのvalueプロパティにあります。以上のことから、上記のコードのようにprint(hello_world_text.value)を実行すると、hello_world_textで表示している文字（"Hello World!"）をターミナルで出力することができます。

a

プロパティの変更

以下は、Textコントロールのvalueプロパティ（表示する文字）を変更するコードです。

実際にコードをコピーして実行してみましょう

python
1import flet as ft
2
3def main(page: ft.Page):
4    def changeText(e):
5        hello_world_text.value = "変更しました！"
6        hello_world_text.update() 
7
8    hello_world_text = ft.Text(value="Hello World!")
9    change_button = ft.FilledButton(text="変更する", on_click=changeText)
10    page.add(hello_world_text, change_button)
11
12ft.app(target=main)

a

ポイント解説

python
1hello_world_text.value = "変更しました！"

a

先に述べたように、Textコントロールの表示している文字は、valueプロパティにあります。ですので、表示している文字を変更したい場合は、valueプロパティを変更すれば良いのです。

つまり、上記のコードのように、hello_world_text.value = "変更しました！"と、別の文字を代入すれば良いということです。

しかし、代入しただけでは、アプリのUI（見た目）にはまだ反映されません。UI（見た目）を更新したい場合は、以下のように、updateメソッドを呼び出す必要があります。

python
1hello_world_text.update()

a
