ルーティング

このページでは、複数ページを扱うアプリを作るうえで必要な知識であるルーティングについて説明するための前知識を説明します。

ルーティングとは

ルーティングとは、複数のページ間を移動できるように繋げることです。

ルーティングを実装することで、より規模の大きいアプリを作ることが可能になります。

flet createコマンド

まず、説明をするうえで共通の認識を持ってもらうためにflet createコマンドで作ったアプリの雛形を題材に話を進めていきます。

CLI(ターミナルなど)にて、

という構造のフォルダができます（「保存する名前」部分の文字列は任意）。

この中の「main.py」では、

python

import flet as ft


def main(page: ft.Page):
    counter = ft.Text("0", size=50, data=0)

    def increment_click(e):
        counter.data += 1
        counter.value = str(counter.data)
        counter.update()

    page.floating_action_button = ft.FloatingActionButton(
        icon=ft.Icons.ADD, on_click=increment_click
    )
    page.add(
        ft.SafeArea(
            ft.Container(
                counter,
                alignment=ft.alignment.center,
            ),
            expand=True,
        )
    )


ft.app(main)

という内容のコードが生成されます。

以下では、このコードをもとに説明をしていきます。

Viewコントロール （ページを管理するコントロール）

Viewコントロールとは

Fletアプリにおいて、「1ページ」に相当するのがViewコントロールです。

家全体がアプリ(Page)だとすると、Viewはその中にある個々の「部屋」にあたります。

実行して見えている画面は、このViewの一つにすぎません。

そして、先ほど作ったコード中には書いていないものの、内部的には使われています。

a

では、実際に書いて使うとするとどのようにするのでしょうか？

それは以下のようになります（行末に「#」がついている行が変更があった部分）。

python

import flet as ft


def main(page: ft.Page):
    counter = ft.Text("0", size=50, data=0)

    def increment_click(e):
        counter.data += 1
        counter.value = str(counter.data)
        counter.update()

    home_view = ft.View(  #
        route="/",  #
        controls=[  #
            ft.SafeArea(  #
                ft.Container(  #
                    counter,  #
                    alignment=ft.alignment.center,  #
                ),  #
                expand=True,  #
            )  #
        ],  #
        floating_action_button=ft.FloatingActionButton(  #
            icon=ft.Icons.ADD, on_click=increment_click  #
        )  #
    )  #
    page.views.append(home_view)  #
    page.update()  #

ft.app(main)

a

元のコードとの相違点を比べてみましょう。

1. 「page.add」に書いていたコントロールをViewの「controls」プロパティに入れている。

1. 「page.floating_action_button」に書かれていたコントロールをViewの「floating_action_button」プロパティに入れている。

1. ページの内部識別用の名前となる「route」プロパティを設定している。

1. 「page.add」部分が「page.views.append(home_view)」と「page.update()」に変更されている。

1. について、これはページ内の内装といったイメージで、今までよく使ってきたコントロールを使って見た目や機能を追加します。

1. について、これは1と違いページ内の外装ともいえる部分で、アプリにありがちな画面を移動してもアプリ内の画面上で常に同じ位置に表示されるコントロールを設定します。
これには他にも「appbar」や「navigation_bar」など様々あります。

1. について、このコードでは直接Viewにつけた変数名でページの遷移を行っているので使われませんが関数を使ってページ遷移を行う場合に重要になってきます。

1. について、「page.add」は見た目の準備と実行を同時にしてくれますが、「page.views.append(home_view)」の場合は準備にとどまってしまうため「page.update()」が必要になります。
※page.views.appendはViewを上に重ねていくものです。

以上がルーティングの前知識となります。
