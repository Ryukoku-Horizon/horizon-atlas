9. 文字列

前回(練習問題3)

a

ここでは、これまで何度か触れてきた文字列に関してより詳しく学習します。文字列といえば、”Hello World!”とか”Horizon”とかですね

ダブルクォートとシングルクォート

これまで、Pythonで文字列を作成するには、テキストをダブルクォート（""）で囲ってきました。

プログラム

python

str = "Hello World!"

a

Pythonでは同様のことが、シングルクォート（''）でも行えます。

プログラム

python

str = 'Helllo World!'

a

ダブルクォートとシングルクォートを組み合わせれば、文字列の中にダブルクォートまたはシングルクォートを入れることもできます。

プログラム

python

str1 = "Hello 'World'!"
str2 = 'プログラミング部 "Horizon"'
print(str1)
print(str2)

a

出力結果

plain text

Hello 'World'!
プログラミング部 "Horizon"

a

トリプルクォート

さらにトリプルクォートというものも存在します。書き方は””””””または’’’’’’ であり位置付けとしては先ほどの二種類の上位互換です。
これを使うと改行が出来るようになります。（括弧のように使える）

プログラム

python

str3 = """
    Hello 
    'World'!
"""
str4 = '''
          プログラミング部 
          "Horizon"
       '''
print(str3)
print(str4)

a

出力結果

plain text


Hello
'World'!


プログラミング部
"Horizon"f

a

リストとの類似点

インデックスによる指定

文字列はリストと同じように、インデックスを使って特定の一文字を取り出すことができます。

プログラム

python

str = 'Horizon'
print(str[0])   #strの0番目（最初）
print(str[3])   #strの3番目
print(str[-1])  #strの最後

a

出力結果

plain text

H
i
n

a

スライス

リストで行ったのと同じように、文字列もスライスを行うことができます。

プログラム

python

sliced_str = str[x:y]

a

このようにすることで、最初の文字を0文字目としたstrの x文字目 ～ y-1文字目 (yは含まれず、yの直前の文字まで)を抜き出すことができます。例えば、「Hello World!」から「World」のみを抜き出すには、次のようなプログラムになります。

プログラム

python

#      0123456    11
str = 'Hello World!'
sliced_str = str[6:11]
print(sliced_str)

a

出力結果

plain text

World

a

for文との組み合わせ

文字列はfor文と組み合わせると、文字列から１文字ずつ取り出して処理を行うことができます。

プログラム

python

str = 'Horizon'
for char in str:
    print(char)

a

出力結果

plain text

H
o
r
i
z
o
n

a

結合

Pythonでの文字列は、結合（複数の文字列を繋げる処理）がとても簡単です。足し算のように+で文字列の結合を行うことができます。

プログラム

python

a = "Hello"
b = "World!"
str = a + b
print(str)

a

出力結果

plain text

HelloWorld!

a

これによって、文字列を含む文章を出力しようと思ったとき、これまではprint(”あなたの名前は”, name, “です”)のようにカンマで区切っていましたが、以下のように一つの変数にまとめてから出力ができるようになります。

プログラム

python

name = input("あなたの名前を入力してください；")
massage = "あなたの名前は" + name + "です"
print(massage)

a

出力結果

plain text

あなたの名前を入力してください：Haruto
あなたの名前はHarutoです

a

f文字列（フォーマット済み文字列リテラル）

結合と似ている別の書き方も紹介します。以下のコードを実行すると

プログラム

python

name = input("あなたの名前を入力してください；")
massage = f"あなたの名前は{name}です"
print(massage)

a

出力結果

plain text

あなたの名前を入力してください：Haruto
あなたの名前はHarutoです

a

というように先ほどと同じ結果が得られます。
