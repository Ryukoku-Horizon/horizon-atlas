not a git repositoryエラーについて

gitでは、not a git repositoryというエラーが起きることがあります。ここではその原因と解決方法を紹介します。

原因：リポジトリ以外の場所でリポジトリの操作を実行している

まず振り返り：

・リポジトリというのは、GitHubで作成できるデータの保管場所

・リポジトリは自分のPCにクローンすることで、ローカルで操作ができるようになる

「リポジトリ以外の場所」というのは、「リポジトリをクローンしたフォルダ以外の場所」ということです。

そして、「リポジトリの操作」というのは、PushやPullといったコマンドを使うことです。

つまり、リポジトリをクローンした以外のフォルダで、PushやPullといったgitのコマンドを使うとエラーになります。

🔴

エラー文

a

このように、リポジトリをクローンしたフォルダ以外でgit pullコマンド使うと「fatal: not a git repository (or any of the parent directories): .git（Git リポジトリ (または親ディレクトリのいずれか) ではありません）」と出ます。（「ディレクトリ」とは「フォルダ」のこと）

解決法

リポジトリをクローンしたフォルダがどこかを確認し、そのフォルダでコマンドを実行しましょう。
