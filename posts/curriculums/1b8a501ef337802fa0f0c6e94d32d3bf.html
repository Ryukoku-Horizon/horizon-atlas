前章で解説した関数は、実は自分で作ることもできます。

関数の利点

例えば、「ユーザーの名前を入力してもらい、その名前を『あなたの名前は {名前} です』の形で出力する」という一連の処理があったとします。

通常の処理の書き方

python
1name = input("あなたの名前を入力してください；")
2massage = "あなたの名前は" + name + "です"
3print(message)

a

この処理を実行するのが一度や二度だけならそのたびに書けば良いので問題ありません。しかし、1つにプログラム中でこの処理を何十回も書かなければいけなくなると、たった3行の処理といえど記述が大変です。

では、この処理をたった1行で済ませることができれば、少しは負担が減るのではないでしょうか？

それを実現できるのが関数の自作です。

インデントとブロック

早速関数の自作に関して紹介をしていきたいところですが、その前に…

Pythonを学習するうえで特に重要な概念となる、インデントについて説明をします。

インデント

a

インデントとは、別名字下げともよばれ、行頭を後ろにズラすことです。

インデント

python
1n = 10       　　　　　　　　　　　 # ✖　インデント
2
3if n > 5:    　　　　　　　　　　 　# ✖　インデント
4	print("nは5より大きいです。")    # 〇　インデント1回目
5else:                           # ✖　インデント
6	print("nは5より小さいです。")    # 〇　インデント2回目

a

このインデントは、基本的に「Tab」キーを押して行います。

エディタを開いて、何度か「Tab」キーを押してみてください。一定間隔で空白が入っていくと思います。

行頭にこのタブを入れることをインデントというのです。

実は、Pythonではこのインデントがとても重要なのです。Pythonではこのインデントを使ってブロックを形作るのです。

ブロック

ブロックとは、処理のかたまりを定義する単位です。

このブロックを使って、if文で条件に当てはまるときに実行する処理や、for文で繰り返す処理を定義するのです。

関数の自作

関数は以下のように記述することで作成ができます。

書き方のイメージ

python
1def 関数の名前():
2    関数を呼び出したときに行う処理

a

上記の名前のプログラムを関数にしようとすると、以下のようになります。これを関数の宣言と呼びます。

関数の宣言の書き方

python
1def print_your_name():
2    name = input("あなたの名前を入力してください：")
3    massage = "あなたの名前は" + name + "です"
4    print(massage)

a

この関数で実行される範囲も、先述のインデントでブロックを作って定義します。

a

この関数を実行するには、関数を宣言したのと同じファイル内で、print_your_name()を呼び出します。試しに、3回連続で呼び出してみましょう。

関数の呼び出し

python
1def print_your_name():
2    name = input("あなたの名前を入力してください；")
3    massage = "あなたの名前は" + name + "です"
4    print(massage)
5
6print_your_name()
7print_your_name()
8print_your_name()

引数を受け取る関数

先程のprint_your_name()関数は、引数も戻り値もない関数でした。

引数と戻り値がない関数の例

python
1#↓戻り値がない
2　　　　　　print_your_name()
3                          #↑引数もない

a

引数を受け取って、その引数をもとに処理を行う関数を作りたいときは、次のように書きます。

書き方のイメージ

python
1def 関数の名前(引数を受け取る変数):
2    関数を呼び出したときに行う処理

a

引数も戻り値もない関数から増えた部分は、「引数を受け取る変数」です。

例えば、「三角形の底辺と高さを受け取り、その面積を求めて表示する」という処理内容の関数を作るときには、以下のように書きます。

関数の作成例

python
1def find_triangle_area(tei, taka):  #受け取った底辺と高さを変数 tei と taka とする
2    area = tei * taka / 2
3    print("底辺" + str(tei) + "、高さ" + str(taka) + "の三角形の面積は" + str(area) + "です")

a

この関数を実行するには、以下のように書きます。底辺が3、高さが5だとすると…

関数の呼び出し

python
1find_triangle_area(3, 5)
2									#↑  ↑ この二つが引数！

a

こうすることで、find_triangle_area()関数の 引数を受け取る変数 であるteiに3、takaに5が格納され、関数の中身が実行されます。よって、実行結果は以下のようになります。

実行結果

底辺3、高さ5の三角形の面積は7.5です

戻り値を返す関数

さらに、戻り値を返す関数の作成方法も紹介します。

書き方のイメージ

python
1def 関数の名前(引数を受け取る変数):
2    関数を呼び出したときに行う処理
3    return 戻り値として返したい値

a

引数を受け取る関数から増えた部分は「return 戻り値として返したい値」ですね。

先程の三角形の面積を求めて表示する関数を、「三角形の面積を求め、面積を戻り値として返す関数」に作り変えると、以下のようになります。

関数の作成例

python
1def find_triangle_area(tei, taka):  #受け取った底辺と高さを変数 tei と taka とする
2    area = tei * taka / 2
3    return area     #変数 area を戻り値として返す

a

この関数を実行し、結果をprint関数で表示するには以下のようになります。

関数の実行と結果の表示

python
1def find_triangle_area(tei, taka):
2    area = tei * taka / 2
3    return area
4
5triangle_area = find_triangle_area(5, 3)
6print(triangle_area)

a

これにより、find_triangle_area関数は受け取った底辺と高さをもとに三角形の面積を求め、その結果を戻り値として変数triangle_areaに代入するという働きをしてくれます。

a
