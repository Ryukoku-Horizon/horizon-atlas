動的ルーティング

ここでは「動的ルーティング」について解説します。

静的ルーティングと動的ルーティング

ルーティングには大きく分けて 「静的ルーティング」 と 「動的ルーティング」 があります。

名前だけだとイメージしにくいので、まずは具体例で見てみましょう。

静的ルーティング

「ページの住所（ページルート）があらかじめ決まっている」ルーティング方法です。

中身も基本的に固定で、誰がアクセスしても同じページが表示されます。

💡

📌 例

・/about → 会社概要ページ

・/contact → お問い合わせページ

・/product → 製品紹介ページ

✅ 特徴

・ページルートが固定されている

・ページの読み込みが速い

・ページ数が少ないサイトに向いている

動的ルーティング

「ページの住所の一部が変数になっている」ルーティング方法です。

アクセスするユーザーやデータによって、表示される内容が変わります。

💡

📌 例

・/user/[id]

→ id=1 なら /user/1

→ id=2 なら /user/2

（同じ仕組みで、商品ページ /product/[id] なども作れる）

✅ 特徴

・ページルートの一部が可変（パラメータになる）

・多くのページを効率よく管理できる

・ユーザーや商品ごとのページに便利

TemplateRouteクラス

まず動的ルーティングをFletで実装するには、TemplateRouteというクラスを使う必要があります。

python

ft.TemplateRoute()

a

このクラスは「ページルートを分解して、どのルートに一致しているか」を調べるためのものです。

基本の使い方

まずは現在のルートをもとに TemplateRoute のインスタンスを作ります。

python

template_route = ft.TemplateRoute(page.route)

a

このインスタンスを使って、match メソッドでルートを判定します。

・match("/user") → URLが/userなら True を返す

・match("/") → URLが/なら True を返す

実装例

ですので、以下のようにルーティングを実装できます。

python

import flet as ft

def main(page: ft.Page):
  def route_change(e):

        template_route = ft.TemplateRoute(page.route)

        if template_route.match("/user"):
          page.views.appen(
            ft.View(
              "/user", # ユーザーページ
              controls=[ft.Text("ユーザーページだよ！")]
            )
          )
        elif template_route.match("/"):
          page.views.appen(
            ft.View(
              "/",　# 最初のページ
              controls=[ft.Text("最初のページだよ！")]
            )
          )
        page.update()
        
  page.on_route_change = route_change
    page.go(page.route)

ft.app(target=main)

a

if template_route.match("/user"):ここで、ページルートが”/user”であれば、ユーザーページを表示します。

elif template_route.match("/user"):ここで、ページルートが”/”であれば、最初のページを表示します。

このように、TemplateRouteクラスを使うことによってルーティングを実装できます。

動的ルーティングの実装

1. 動的ルートの書き方

ページルートの一部を 変数（パラメータ） にできます。

変数にしたい部分は、先頭に : をつけます。

python

template_route.match("/user/:id")

a

この場合、

・/user/1

・/user/123

のようなURLがすべてマッチします。

ここでの :id が動的な部分です。

ページルートの活用

上記のページルートの一部を変数にすることで動的ルーティングは実装できますが、ページルートの変数部分を活用しなければ意味がないです。

ページルートの変数部分はTemplateRouteクラスのプロパティとなって保管されます。例えば、以下のように変数部分を取得できます。

python

if template_route.match("/user/:id"):
  user_id = template_route.id

a

つまり、template_route.ページルートの変数部分のようにしてページルートを取得できます。

動的ルーティングの実装例

python

import flet as ft

def main(page: ft.Page):
    def route_change(e):

        template_route = ft.TemplateRoute(page.route)

        if template_route.match("/user/:id"):
            user_id = template_route.id  # 動的パラメータを取得
            page.views.append(
                ft.View(
                    f"/user/{user_id}",
                    controls=[
                        ft.Text(f"ユーザーID: {user_id}のページです"),
                        ft.ElevatedButton("ホームに戻る", on_click=lambda _: page.go("/"))
                    ]
                )
            )
        elif template_route.match("/"):
            user_id_field = ft.TextField(label="ユーザーIDを入力してください")
            # ホームページの表示
            page.views.append(
                ft.View(
                    "/",
                    controls=[
                        ft.Text("ホームページ"),
                        user_id_field,
                        ft.ElevatedButton("ユーザーページへ", on_click=lambda _: page.go(f"/user/{user_id_field.value}"))
                    ]
                )
            )
        
        page.update()

    page.on_route_change = route_change
    page.go(page.route)

ft.app(target=main)

a

以下のように、入力したユーザーIDによってページを生成するアプリを実行できます。

a

📌 この例では：

・ホームでユーザーIDを入力してボタンを押すと /user/入力したID に移動

・そのIDに応じてページが生成される

まとめ

・:id のように書くとURLの一部を 動的パラメータ にできる

・値は TemplateRoute のプロパティで取得できる (template_route.id)

・これにより、ユーザーごとや商品ごとのページを簡単に作れる
