インストール方法

windowsかmacの場合は以下のサイトを見てDocker Desktopをインストールしてください

windowsの場合

matsuand.github.io

https://matsuand.github.io/docs.docker.jp.onthefly/desktop/windows/install/

a

macの場合

matsuand.github.io

https://matsuand.github.io/docs.docker.jp.onthefly/desktop/mac/install/

a

Linux（Ubuntu）の場合はDocker Engine（cli）をインストールします

インストールが完了したら

インストールが完了したら以下のコマンドを実行できるか確認してください

shell

docker --version
docker run hello-world
