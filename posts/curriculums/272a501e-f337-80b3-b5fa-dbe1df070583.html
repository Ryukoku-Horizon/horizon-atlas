lambda式

今回はpythonのlambda式について説明します。

lambda式の基本

lambda式は、関数を作るための短縮記法です。通常の関数定義と異なり、lambda式は一行で書け、関数名を省略することができます。

基本構文

python

lambda 引数:処理内容

a

・引数: 関数に渡す引数。

・式: 関数が返す結果（通常、1つの式のみ）。

引数がない場合は引数の部分に_（アンダーバー）を使います

引数がない場合

python

lambda _:処理内容

a

使用例

lambda式の具体的な使用例を示します。

2つの引数を受け取って、その和を返す関数

python

add = lambda x, y: x + y
print(add(3, 5))  # 8

a

リスト内の各要素を2倍にする関数

python

nums = [1, 2, 3, 4]
doubled = list(map(lambda x: x * 2, nums))
print(doubled)  # [2, 4, 6, 8]

a
