1. Hello World!

1. Hello World!

Pythonの学習の第一歩として、好きな言葉を画面に表示する方法を学びましょう。次のようなプログラムを書いてみましょう。

プログラム

python

print("Hello World!")

書けたら、VSCode上部

a

の右にある再生ボタン(▷)を押すと実行できます。
また、この時のように何か作業が終わるごとに保存しておきましょう。（保存はWindowsなら Ctrl + S 、Macなら command + Shift + S）

実際に押してみると、以下のように「Hello World!」とVSCode下部のターミナルという部分に表示されます。（最後の青丸行の次行から黒丸行の前行までが実行結果で今回は一行です。）

a

Hello World!の部分を別の言葉に変えてみましょう。例えば、

プログラム

python

print("Hello Horizon!")

保存をして実行してみると、このように「Hello Horizon!」が表示されます。

a

このように、任意の文字や言葉を画面に表示することをプログラミングでは出力といいます。つまり、一最初のプログラムは「Hello World!を出力した」と言う事ができます。

また、今回printという言葉をプログラムに書いて出力をしました。これを print関数 と呼びます。print関数は続く()の中に入っている言葉を出力する働きを持ちます。

()の中身を様々な言葉に置き換えて、実行をしてみましょう。

a

📌

プログラミングは実践あるのみです！

a

ここで、これからプログラミングをしていくうえで一つ注意点です。それは、プログラム上に全角文字が存在してはいけないということです。なぜダメなのか簡単にいうと、半角文字と全角文字は意味的には同じでもパソコンにとっては全くの別文字だからです。

☝

その違いをわかりやすくまとめているのがこのサイトです。

では、以下のプログラムを見てみてください。

プログラム

python

print（"Hello Horizon!"）

見た目ではわかりにくいですが、このプログラムは（ と ）が全角文字になっています。これで実行をすると…

a

いつもの青丸の行に赤丸の行としてこのようなエラーが出ていしまいます。この他にも、全角の空白によってエラーが引き起こされることもあります。ぜひ意識してみてください。ただし、例外として ””（ダブルクオーテーション）で括られている中身には全角文字があっても問題ありません。
　　↓ これはOK

プログラム

python

print("こんにちは！")

これを実行してみると…

a

というようにエラーしっかりと実行されます。

a
