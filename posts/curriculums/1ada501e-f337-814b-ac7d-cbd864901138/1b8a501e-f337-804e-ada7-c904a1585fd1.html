問題1

Pythonの組み込み関数を用いて、次のリストの要素数（長さ）、最大値、最小値、合計値を出力してください。

python

numbers = [34, -12, 77, 5, -49, 99, 23, -8, 45, 66, -32, 18]

※プログラムは「prac5-1.py」として保存

期待する出力結果

text

リストの要素数は12個です
リストの最大値は99です
リストの最小値は-49です
リストの合計値は266です

a

問題2

ユーザーから入力された台形の上底、下底と高さをもとに、台形の面積を求め出力してください。

ただし、引数として上底、下底と高さを受け取り、戻り値としてその台形の面積を返すfind_daikei関数を作成し、プログラム中で使用してください。

※プログラムは「prac5-2.py」として保存

期待する出力結果

text

台形の面積を求めます
上底を入力 : 7
下底を入力 : 5
高さを入力 : 3
面積は 18.0 です

a

問題3

引数として受け取ったリストの平均値を求めて返すfind_average関数を定義し、それを使用して以下のリストの平均値を出力してください。

python

numbers = [-2, 88, -16, 45, 72, 31, -8, 94, 3, 60]

※プログラムは「prac5-3.py」として保存

期待する出力結果

text

リストの平均値は36.7です

a
