Goガイド

Goガイド

✅ 概要

このガイドは、Go言語がどんな言語なのかを紹介し、「Hello, World!」を出力するところまでをわかりやすく解説する学習資料です。

1. Go言語とは？

✔️ Go言語は、Googleが開発したプログラミング言語です。

✔️ C++よりシンプルな文法で、速くて安定したアプリケーションを作れます。

✔️ Webサービス、ネットワークアプリ、ツール開発などでよく使われています。

💡Go言語の特徴

・シンプルな使い方：覚えることが少ないから、初心者でも始めやすいです。

・コンパイルが超高速：コードを書いたらすぐに実行できて、サクサク開発できます。

・並行処理(ゴルーチン)が得意：たくさんの処理を同時に動かす「並行処理」が、かんたんに書けます。

・インストールだけでOK：Go言語は、コンパイル、ビルド、パッケージ管理などがすべて最初からついてます。

1-2. 開発環境の構築

(1) Go公式サイトからインストール

1. 公式サイト：https://go.dev/dl/ にアクセス

1. 自分のOSに合ったインストーラをダウンロードしてインストール

1. ターミナルやコマンドプロンプトで確認：

plain text

go version

a

→ go version go1.xx... と表示されればOK！

(2) エディタ：Visual Studio Code（VS Code）がおすすめ

1. VS Codeをインストール

1. 拡張機能「Go」をインストール

1. 自動補完やデバッグなども簡単に使えるようになります！

1-3. はじめてのプログラム - "Hello, World!"

Hello Worldを表示するコード

go

package main

import "fmt"

func main() {
    fmt.Println("Hello, World!")
}

a

実行方法（ターミナルまたはVS Code）：

1. hello.go という名前で保存

1. ターミナルで実行：

plain text

go run hello.go

a

実行結果：

plain text

Hello, World!

a

コードの説明

go

package main         // 「mainパッケージ」であることを宣言（プログラムのはじまり）

import "fmt"         // 文字を表示するための「fmtパッケージ」を使うよ

func main() {        // ここがプログラムのスタート地点
    fmt.Println("Hello, World!") // 画面に文字を出力
}

a

a

💡

Goは「パッケージベースの言語」で、まず package main を書いてスタートします。

main() 関数がプログラムの入り口です。

fmt.Println() を使うと、画面に文字が出せます！
