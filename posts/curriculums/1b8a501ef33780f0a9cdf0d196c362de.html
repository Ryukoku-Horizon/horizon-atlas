今回は、「算術演算子」の使い方を学びます。

算術演算子を学ぶことで、複雑な数式や図形の面積などを自動で計算させたり、扱える数値処理の幅が広がります。

目次

算術演算子

今回は、プログラム上で四則演算（足し算、引き算、掛け算、割り算）を行う方法を学びます。といっても、やり方は非常に単純です。次のプログラムを見てください。

基本的な四則演算

コード↓

python
1a = 10 + 5  #足し算
2b = 10 - 5  #引き算
3c = 10 * 5  #掛け算
4d = 10 / 5  #割り算
5print("10 + 5 =", a)
6print("10 - 5 =", b)
7print("10 * 5 =", c)
8print("10 / 5 =", d)

a

その出力結果↓

10 + 5 = 15
10 - 5 = 5
10 * 5 = 50
10 / 5 = 2.0

a

書き方は数学での四則演算に非常に似ていますが、掛け算と割り算だけ記号が少し違うので注意してください。このプログラムの実行結果は以下のようになります。

また、この演算は、変数同士でも同様に行うことができます。以下のプログラムはv1とv2という二つの変数に対して四則演算を施しています。

v1とv2による四則演算

コード↓

python
1v1 = 10
2v2 = 5
3a = v1 + v2  #足し算
4b = v1 - v2  #引き算
5c = v1 * v2  #掛け算
6d = v1 / v2  #割り算
7print("v1 + v2 =", a)
8print("v1 - v2 =", b)
9print("v1 * v2 =", c)
10print("v1 / v2 =", d)

a

その出力結果↓

v1 + v2 = 15
v1 - v2 = 5
v1 * v2 = 50
v1 / v2 = 2.0

a

加えて、Pythonでは次のように割り算のあまりや累乗、小数点以下の切り捨て割り算などを計算することができます。

あまり、累乗、切り捨て割り算の計算

コード↓

python
1v1 = 5
2v2 = 2
3a = v1 % v2     #割り算のあまり
4b = v1 ** v2    #累乗
5c = v1 // v2    #切り捨ての割り算
6print("v1 % v2 =", a)
7print("v1 ** v2 =", b)
8print("v1 // v2 =", c)

a

その出力結果↓

v1 % v2 = 1
v1 ** v2 = 25
v1 // v2 = 2

a

　これらの + - * / % // をあわせて、算術演算子と呼びます。以下の表に各算術演算子と処理内容を示します。

算術演算子処理内容
+足し算
-引き算
*掛け算
/割り算
%あまり
**累乗
//切り捨て除算

もちろん、複数の算術演算子を用いて複雑な計算を行うこともできます。その際には数学での計算と同じように掛け算と割り算が優先されますし、()で囲って計算順序を指定することもできます。また、aやbなどの変数を介さずとも、計算式の答えをprint関数で直接出力することもできます。

台形の面積、球の表面積の計算

コード↓

python
1print("上底4, 下底6, 高さ3の台形の面積", (4 + 6) * 3 / 2)
2print("半径5の球の表面積", 4 * 3.14 * (5 ** 2))    #4πr^2

a

その出力結果↓

上底4, 下底6, 高さ3の台形の面積 15.0
半径5の球の表面積 314.0

a

a

計算をするときの注意点

変数を用いて計算をするとき、その変数の型に注意しておかなければ、エラーや意図しない動作を引き起こす可能性があります。例えば、次のプログラムを見てください。

異なる型のデータの足し算

コード↓

python
1a = 10
2b = "5"
3c = a + b
4print(c)

a

その出力結果↓

a

aには整数の10が、bには文字列として5が格納されています。そのため、3行目の計算では数字と文字を足す計算式となっています。

これを実行してみると、赤色でエラーが出てしまい、実行ができませんでした。簡単に日本語訳すると「int型（整数型）とstr型（文字列型）の足し算はサポートされてないやで」という感じです。当たり前といえば当たり前ですが、このようなミスが規模の大きいプログラムではバグを生み出したりするのです…

☝

プログラミングをするときは、常に変数の型を意識しよう！
