データの保存(Create)

今回はpythonとそのライブラリであるsqlite3を使用して、データベースにデータを保存する方法を紹介します。

データの保存方法

データを保存する方法を見てきましょう。

データを保存するSQL文

sql
1INSERT INTO テーブル名(カラム名) VALUES (保存する値)

a

データを保存するときはINSERTを使います。

INTO テーブル名（カラム名） の部分で、どこにデータを保存するかを指定します。VALIES (保存する値)の部分で、保存したいデータの値を指定します。

実際にデータを保存してみよう

「データベースとの接続とテーブルの作成」で作成したpersonテーブルにデータを保存して見ましょう。

新たに、create.pyというファイルを作ってください。

create.pyの中身を以下のようにしてください。

create.py

python
1import sqlite3
2
3dbname = 'TEST.db'
4conn = sqlite3.connect(dbname)
5cur = conn.cursor()
6
7# データを保存する
8cur.execute('INSERT INTO person(name, age, gender) VALUES ("Sato", 15, "Man")')
9
10conn.commit()
11
12cur.close()
13conn.close()

a

SQL文は以下のようになっています。

sql
1INSERT INTO person(name, age, gender) VALUES ("Sato", 15, "Man")

a

まず、INSERT INTO person(name, age, gender) の部分で、どこにデータを入れるかを決めています。今回はpersonテーブルの中のカラムname、age、genderにデータを入れることを指定しています。

VALUES (”Sato”, 15, “Man”) の部分で、何の値を入れるかを決めています。nameに”Sato”、ageに15、genderに”Man”を入れています。

ちなみに、カラムid は、AUTOINCREMENT 属性があるので値を挿入しなくても自動で値が入れられます。

pythonのファイルを実行してみましょう。

TEST.dbの中身が以下のように表示されればデータの保存に成功しています。

任意のデータを扱う

上記の方法でデータを保存することができますが、この方法では決まった値しか保存できません。実際のアプリでデータベースを利用するには、任意の値を保存できるようにしないと、あまり実用的ではないです。

例えば、以下のコードだと、"Sato", 15, "Man" という決まった値しか保存できません。

python
1cur.execute('INSERT INTO person(name, age, gender) VALUES ("Sato", 15, "Man")')

a

では、任意の値を保存する方法を見ていきましょう。

変数で任意の値を保存するコード

python
1cur.execute('INSERT INTO テーブル名(カラム名) VALUES (?)',(保存したい値))

a

🛑 cur = cursorオブジェクト

このコードだと、変数に代入した任意の値を保存できます。

SQL文の、保存する値を入れる部分に? を入れます。そして、execute メソッドの二つ目の引数に、保存したい値の入ったタプル型を入れます。（タプル型については「タプル型」をご覧ください）

例えば、personテーブルにデータを変数で保存するなら以下のように書きます。

personテーブルにデータを変数で保存する

python
1import sqlite3
2
3dbname = 'TEST.db'
4conn = sqlite3.connect(dbname)
5cur = conn.cursor()
6
7# 任意の値を入れる
8name = "Hashimoto"
9age = 26
10gender = "Woman"
11
12# データを保存する
13cur.execute('INSERT INTO person(name, age, gender) VALUES (?, ?, ?)', (name, age, gender))
14
15conn.commit()
16
17cur.close()
18conn.close()

a

このコードだと変数の内容を変えれば保存するデータの値を変えることができます。
