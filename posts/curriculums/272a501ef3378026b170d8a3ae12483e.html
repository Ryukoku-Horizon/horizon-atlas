タプル型

タプル型

今回はpythonのデータ型の一つであるタプル型について紹介します。

タプルの基本

Pythonのタプル（tuple）は、順序付けられたデータの集合を表すデータ型です。同じくデータの集合を表すリスト型との違いは、一度定義したらイミュータブル（変更不可能）である点です。

それでは定義してみましょう。

タプルは、カンマ , を使って複数の値を括弧 () で囲んで定義します。

タプルを定義

python

# タプルの定義
my_tuple = (1, 2, 3)
print(my_tuple) # (1, 2, 3)

a

タプルの特徴

1. イミュータブル（変更不可能）

・一度作成したタプルの要素は変更できません。

タプルの要素を変更しようとするとエラーが起きる

python

my_tuple = (1, 2, 3)
my_tuple[0] = 10 # エラー: タプルの要素は変更できない

a

1. 順序とデータが保証される

・タプル内の要素は作成時の順序とデータが保持されます。

注意点

タプルを扱う際の注意点として、タプルの中の要素が一つの場合、要素の後に,（カンマ）をつける必要があります。,（カンマ）をつけなかった場合、変数のデータ型は中の要素のデータ型となります。

python

single_tuple = (1,) # カンマが必要
print(type(single_tuple)) # <class 'tuple'>

not_a_tuple = (1) # カンマがない → int型となる
print(type(not_a_tuple)) # <class 'int'>

a

タプルの主な操作

タプル自体を変更することはできませんが、読み取りや操作は可能です。

インデックスでアクセス

インデックス（番号）でアクセス

python

my_tuple = (10, 20, 30)
print(my_tuple[0]) # 10
print(my_tuple[-1]) # 30

a

スライス

スライス

python

my_tuple = (10, 20, 30, 40, 50)
print(my_tuple[1:3]) # (20, 30)
print(my_tuple[:3]) # (10, 20, 30)

a

タプルのアンパック

タプルを分解して複数の変数に割り当てることができます。

python

my_tuple = (1, 2, 3)
a, b, c = my_tuple
print(a, b, c) # 1 2 3

a

タプルの用途

複数の戻り値を返す関数

例

python

def get_coordinates():
return (10, 20)

x, y = get_coordinates()
print(x, y) # 10 20

a

不変なデータの保存

・タプルは変更されるべきでないデータを扱う際に適しています。

辞書のキーや集合の要素

例

python

coordinates = {(0, 0): "Origin", (1, 2): "Point A"}
print(coordinates[(1, 2)]) # Point A
