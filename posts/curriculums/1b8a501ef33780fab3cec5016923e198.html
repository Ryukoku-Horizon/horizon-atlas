9. 文字列

前回(練習問題3)　｜　次回(練習問題4)

今回は、”Hello World!”といった文字列について学んでいきます。
文字列を学ぶことで、文字を自由に組み合わせたり取り出したりすることができるようになります。これにより、メッセージを状況に合わせて作り変えるなど、文字に関係する色々なことができるようになります。

目次

ダブルクォートとシングルクォート

これまで、Pythonで文字列を作成するには、テキストをダブルクォート（""）で囲ってきました。

ダブルクォートでの文字列

python
1str = "Hello World!"

a

Pythonでは同様のことが、シングルクォート（''）でも行えます。

シングルクォートでの文字列

python
1str = 'Helllo World!'

a

ダブルクォートとシングルクォートを組み合わせれば、文字列の中にダブルクォートまたはシングルクォートを入れることもできます。

文字列中でのダブル/シングルクォートの表示

コード↓

python
1str1 = "Hello 'World'!"
2str2 = 'プログラミング部 "Horizon"'
3print(str1)
4print(str2)

a

その出力結果↓

Hello 'World'!
プログラミング部 "Horizon"

a

a

トリプルクォート

さらにトリプルクォートというものも存在します。書き方は””””””または’’’’’’ であり位置付けとしては先ほどの二種類の上位互換です。
これを使うと改行が出来るようになります。（括弧のように使える）

トリプルクォートでの文字列

コード↓

python
1str3 = """
2		Hello 
3		'World'!
4"""
5str4 = '''
6					プログラミング部 
7					"Horizon"
8			 '''
9print(str3)
10print(str4)

a

その出力結果↓


Hello
'World'!


プログラミング部
"Horizon"f

a

a

リストとの類似点

インデックスによる指定

文字列はリストと同じように、インデックスを使って特定の一文字を取り出すことができます。

インデックスによる文字の取り出し

コード↓

python
1str = 'Horizon'
2print(str[0])   #strの0番目（最初）
3print(str[3])   #strの3番目
4print(str[-1])  #strの最後

a

その出力結果↓

H
i
n

a

スライス

リストで行ったのと同じように、文字列もスライスを行うことができます。

文字列でのスライス方法

python
1sliced_str = str[x:y]

a

このようにすることで、最初の文字を0文字目としたstrの x文字目 ～ y-1文字目 (yは含まれず、yの直前の文字まで)を抜き出すことができます。例えば、「Hello World!」から「World」のみを抜き出すには、次のようなプログラムになります。

スライスを使い文字列Worldを取り出す

コード↓

python
1#      0123456    11
2str = 'Hello World!'
3sliced_str = str[6:11]
4print(sliced_str)

a

その出力結果↓

World

a

for文との組み合わせ

文字列はfor文と組み合わせると、文字列から１文字ずつ取り出して処理を行うことができます。

forによる文字列の取り出し

コード↓

python
1str = 'Horizon'
2for char in str:
3    print(char)

a

その出力結果↓

H
o
r
i
z
o
n

a

結合

Pythonでの文字列は、結合（複数の文字列を繋げる処理）がとても簡単です。足し算のように+で文字列の結合を行うことができます。

文字列の結合

コード↓

python
1a = "Hello"
2b = "World!"
3str = a + b
4print(str)

a

その出力結果↓

HelloWorld!

a

これによって、文字列を含む文章を出力しようと思ったとき、これまではprint(”あなたの名前は”, name, “です”)のようにカンマで区切っていましたが、以下のように一つの変数にまとめてから出力ができるようになります。

inputを使った文字列結合の実践

コード↓

python
1name = input("あなたの名前を入力してください；")
2massage = "あなたの名前は" + name + "です"
3print(massage)

a

その出力結果↓

あなたの名前を入力してください：Haruto
あなたの名前はHarutoです

a

a

f文字列（フォーマット済み文字列リテラル）

結合と似ている別の書き方も紹介します。以下のコードを実行すると、

f文字列の書き方

コード↓

python
1name = input("あなたの名前を入力してください；")
2massage = f"あなたの名前は{name}です"
3print(massage)

a

その出力結果↓

あなたの名前を入力してください：Haruto
あなたの名前はHarutoです

a

というように先ほどと同じ結果が得られます。
