ここでは、これまで何度か触れてきた文字列に関してより詳しく学習します。文字列といえば、”Hello World!”とか”Horizon”とかですね

ダブルクォートとシングルクォート

これまで、Pythonで文字列を作成するには、テキストをダブルクォート（""）で囲ってきました。

プログラム

python
1str = "Hello World!"

a

Pythonでは同様のことが、シングルクォート（''）でも行えます。

プログラム

python
1str = 'Helllo World!'

a

ダブルクォートとシングルクォートを組み合わせれば、文字列の中にダブルクォートまたはシングルクォートを入れることもできます。

プログラム

python
1str1 = "Hello 'World'!"
2str2 = 'プログラミング部 "Horizon"'
3print(str1)
4print(str2)

a

出力結果

Hello 'World'!
プログラミング部 "Horizon"

a

トリプルクォート

さらにトリプルクォートというものも存在します。書き方は””””””または’’’’’’ であり位置付けとしては先ほどの二種類の上位互換です。
これを使うと改行が出来るようになります。（括弧のように使える）

プログラム

python
1str3 = """
2		Hello 
3		'World'!
4"""
5str4 = '''
6					プログラミング部 
7					"Horizon"
8			 '''
9print(str3)
10print(str4)

a

出力結果


Hello
'World'!


プログラミング部
"Horizon"f

a

リストとの類似点

インデックスによる指定

文字列はリストと同じように、インデックスを使って特定の一文字を取り出すことができます。

プログラム

python
1str = 'Horizon'
2print(str[0])   #strの0番目（最初）
3print(str[3])   #strの3番目
4print(str[-1])  #strの最後

a

出力結果

H
i
n

a

スライス

リストで行ったのと同じように、文字列もスライスを行うことができます。

プログラム

python
1sliced_str = str[x:y]

a

このようにすることで、最初の文字を0文字目としたstrの x文字目 ～ y-1文字目 (yは含まれず、yの直前の文字まで)を抜き出すことができます。例えば、「Hello World!」から「World」のみを抜き出すには、次のようなプログラムになります。

プログラム

python
1#      0123456    11
2str = 'Hello World!'
3sliced_str = str[6:11]
4print(sliced_str)

a

出力結果

World

a

for文との組み合わせ

文字列はfor文と組み合わせると、文字列から１文字ずつ取り出して処理を行うことができます。

プログラム

python
1str = 'Horizon'
2for char in str:
3    print(char)

a

出力結果

H
o
r
i
z
o
n

a

結合

Pythonでの文字列は、結合（複数の文字列を繋げる処理）がとても簡単です。足し算のように+で文字列の結合を行うことができます。

プログラム

python
1a = "Hello"
2b = "World!"
3str = a + b
4print(str)

a

出力結果

HelloWorld!

a

これによって、文字列を含む文章を出力しようと思ったとき、これまではprint(”あなたの名前は”, name, “です”)のようにカンマで区切っていましたが、以下のように一つの変数にまとめてから出力ができるようになります。

プログラム

python
1name = input("あなたの名前を入力してください；")
2massage = "あなたの名前は" + name + "です"
3print(massage)

a

出力結果

あなたの名前を入力してください：Haruto
あなたの名前はHarutoです

a

f文字列（フォーマット済み文字列リテラル）

結合と似ている別の書き方も紹介します。以下のコードを実行すると

プログラム

python
1name = input("あなたの名前を入力してください；")
2massage = f"あなたの名前は{name}です"
3print(massage)

a

出力結果

あなたの名前を入力してください：Haruto
あなたの名前はHarutoです

a
