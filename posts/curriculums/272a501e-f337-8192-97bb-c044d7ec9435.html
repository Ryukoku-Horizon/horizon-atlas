ルーティングを作る

まず、ルーティングを作りましょう。

ホームページ（ページルート/）と作成ページ（ページルート/create）を作ります。

main.py

python

import flet as ft

def main(page: ft.Page):

def route_change(e):
template_route = ft.TemplateRoute(page.route)

if template_route.match("/create"):
page.views.append(
ft.View(
"/create",
controls=[],
)
)
elif template_route.match("/"):
page.views.append(
ft.View(
"/",
controls=[],
)
)
page.update()

page.on_route_change = route_change
page.go(page.route)

ft.app(main)

ページ移動可能にする

次に、ページ移動を可能にさせましょう。

main.py

python

import flet as ft

def main(page: ft.Page):
appbar = ft.AppBar(
center_title=True,
title=ft.Text(value="TODOアプリ"),
bgcolor=ft.Colors.BLACK12
)

def route_change(e):
template_route = ft.TemplateRoute(page.route)

if template_route.match("/create"):
appbar.leading = ft.IconButton(icon=ft.Icons.ARROW_BACK, on_click=lambda _:page.go("/"))
page.views.append(
ft.View(
"/create",
appbar=appbar,
controls=[]
)
)
elif template_route.match("/"):
appbar.leading = ft.Text("")
floating_button = ft.FloatingActionButton(
icon=ft.Icons.ADD,
bgcolor=ft.Colors.BLUE_200,
on_click=lambda _: page.go("/create")
)
page.views.append(
ft.View(
"/",
appbar=appbar,
controls=[],
floating_action_button=floating_button
)
)
page.update()

page.on_route_change = route_change
page.go(page.route)

ft.app(main)

a

ここではappbarを定義し、作成ページではappbarの左側にホームページに移動できるボタンを設置しました。

ホームページには、画面右下にfloating_buttonというボタンを設置し、作成ページに移動できるようにしました。
