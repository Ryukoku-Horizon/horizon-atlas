✅概要

このガイドは、C++言語がどんな言語なのかを紹介し、「Hello, World!」を出力するところまでをわかりやすく解説する学習資料です。

1. C++言語とは？

✔️ C++は、C言語を拡張して作られた言語で、オブジェクト指向にも対応しています。<br>
✔️ ゲーム開発やシステム開発、競技プログラミングなど幅広い分野で使用されています。

💡C++の特徴

・C言語の上位互換：C言語のコードがほとんどそのまま動くため、Cの知識も活かせます。

・オブジェクト指向：クラスや継承、ポリモーフィズムといった設計手法に対応しています。

・高速で柔軟：コンパイル後の実行速度が非常に速く、大規模なプログラムにも対応できます。

・細かい制御が可能：メモリ管理など低レベルな操作もC同様に行えます。

1-3. はじめてのプログラム - "Hello, World!"

C++で一番シンプルなプログラム、「Hello, World!」を見てみましょう！

Hello Worldを表示するコード

c++
1#include <iostream>
2
3int main() {
4    std::cout << "Hello, World!" << std::endl;
5    return 0;
6}

a

実行方法：

1. ファイルを保存 ( example.cppなど )

2. ターミナルでコンパイル

3. 実行

実行結果：

Hello, World!

a

コード概説：

c++
1#include <iostream>                     // 1. 入出力用ヘッダーを読み込み
2
3int main() {                           // 2. プログラムの開始点となるmain関数
4    std::cout << "Hello, World!"       // 3. 出力ストリームで画面に表示
5              << std::endl;            //    改行も一緒に出力
6    return 0;                          // 4. 正常終了を表す
7}

a

C++では、#include <iostream>で入出力のためのヘッダーを読み込み、std::coutで文字列を画面に表示します。

最後にreturn 0;でプログラムの正常終了を示します。

a
