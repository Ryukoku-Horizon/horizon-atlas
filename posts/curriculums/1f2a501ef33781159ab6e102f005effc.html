Fletを使用するときに、プログラムの土台となるウィンドウを作らなければなりません。

この、ウィンドウ内でプログラムを動かすためのページを生成する方法について学んでいきます。

ページの生成方法

ここからは Flet の基礎について学んでいきます。

まず、PythonのプログラムにこれからFletを使うことを明記しなければなりません。プログラムの先頭にこのように書きます。

Fletのインポート

python
1import flet as ft

a

import fletで「このプログラムではFletを使うよ」ということを示しており、as ftで、「Fletをftという名前で使うよ」と示しています。

つづいて、このようなコードを書くとFletでウィンドウを作ることができます。このウィンドウを生成することがGUI開発の第一歩です。

ページの生成

python
1import flet as ft
2
3def main(page :ft.Page):
4    pass    #ここにさまざまなパーツなどを配置
5
6ft.app(target=main)

a

復習：#ってなんだよ！？

これでコマンドflet run プログラムファイル名を実行することで中身になにも表示されないウィンドウが立ち上がるはずです。

定義したmain関数の中身に、GUIを構成するパーツとなる「コントロール」というもの（次回紹介）を配置していきます。

また、Fletではこのウィンドウ内の領域を「ページ」と呼びます。

☝

今回紹介したコードは、全てきちんと意味のあるプログラムではあるのですが、今それを完全に理解する必要はありません。今は、ウィンドウを生成できる魔法のコード、ぐらいの感覚で大丈夫です。

現在配置しているpassは「なにもしない（配置しない）」ということを示す文言です。おそらく使うのは最初で最後です。
