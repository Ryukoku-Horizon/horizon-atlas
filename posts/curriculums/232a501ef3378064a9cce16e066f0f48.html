回文判定アプリの手引き

Q. 回文って何？

A. 文の最初から読んでも、最後から読んでも同じ文のこと。

具体的には「南」「夜すき焼きするよ」「松茸摘みに来て、奇跡的に見つけた妻」など

a

ただ今回は簡単にするために、漢字変換や句読点・空白なしで実装します。

具体的な入力は「みなみ」「よるすきやきするよ」「まつたけつみにきてきせきてきにみつけたつま」などということ

主な機能

a

コードの全体

python

import flet as ft

def main(page: ft.Page):
    page.title = "Flet 回文判定機-PalindromeJudger" # この行は必須ではない(見た目の問題)
    page.window.height = 230 # この行は必須ではない(見た目の問題)

    def change_nega(e):
        nega_text.value = posi_text.value[::-1] # この行は「nega_text.value = e.control.value[::-1]」でもいい
        page.update()
    def judge(e):
        if posi_text.value == nega_text.value:
            judge_result.value = "これは回文です"
        else:
            judge_result.value = "これは回文ではありません"
        page.update()

    posi_text = ft.TextField(
        label = "ここに言葉を入力して下さい", # この行は必須ではない(わかりやすさの問題)
        on_change = change_nega
    )
    nega_text = ft.TextField(
        label = "文字列の反転結果", # この行は必須ではない(わかりやすさの問題)
        read_only = True
    )
    judge_button = ft.ElevatedButton(
        text = "Judge!",
        on_click = judge
    )
    judge_result = ft.Text()

    page.add(
        posi_text,
        nega_text,
        judge_button,
        judge_result
    )
ft.app(target = main)
