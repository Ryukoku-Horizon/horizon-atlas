パス

ファイルとフォルダの復習(まとめの再掲)

1. ファイルはデータそのもの

1. フォルダは、ファイルとフォルダの入れ物

パスとは

先にファイルとフォルダの復習をしたのにはもちろん意味があって…
パスはこれらの構造を表すものです。
とは言っても「ファイル管理のススメ」にもあったと思いますが、もしこれを全て表そうとする一行では足りません。

ですが、以下のprac2-3.pyに向かうと考えると…

plain text

Desktop ├─python │ └─practices │ ├─prac1 │ ├─prac2 │ │ ├─prac2-1.py │ │ ├─prac2-2.py │ │ └─prac2-3.py │ ├─prac3 │ ├─prac4 │ └─pra ├─CPP │ └─practices

a

Desktop→python→practices→prac2→prac2-3.pyという一通りしか道がないことがわかると思います。

これを見て、「これなら一行で書けそうだな〜」と思ってくれたでしょうか？
思いましたよね？
そう、思うんですよ。

冗談はさておき、この一本道を一行で書いて定式化したもの、それがパスなんです。

パスの構造

さて、件のものは以下のように書かれていると思います。
（両方とも、user,MacBookの部分はあなたのユーザー名,マックブック名になっています。）

何かしらのフォルダを開く前の場合

plain text

user@MacBook ~ %

a

特定のフォルダを開いている場合（例：前に作ったpracticesフォルダ）

plain text

user@MacBook practices %

a

この~やpracticesの部分がパスであり、その内これは「相対パス」と言われるものです。

その内と言うなら、まだ他のパスがあるのかと思われるかもしれませんが…
その通りで、その名は「絶対パス」です。(パスはこの二種類で全て)

「絶対パス」の書き方は、

~なら

plain text

/Users/user

a

practicesなら

plain text

/Users/user/Desktop/python/practices

a

となります。

⚙

では何が違うのかというと…

「相対パス」は今開いているファイルやフォルダ(上の場合で言う~、その下でのpractices)を基準として表現するものに対して、

「絶対パス」は(先頭の)「/」から今開いているファイルやフォルダに至るまでの全てを書いて表現するものです。

区切りは「/」(スラッシュ)です。
(ですが、他のCLIではバックスラッシュのみなどもあるのでモノによります。)

☝

木で例えると、「根の先」から見るか「根の本」から見るかの違いで、

地理的に例えると、「目的地への行き方のメモ」か「住所そのもの」の違いです。

その根本(先頭の/)のことを「ルートディレクトリ」、

ファインダーで触りやすい範囲で最も”根”に近いフォルダは「ホームディレクトリ」、

今開いているフォルダ(今居るフォルダ)のことを「カレントディレクトリ」、

などと言います。

☝

prac2-3.pyまでの道のりのイメージ図↓

a

区切り文字の/がルートディレクトリであることに納得のいかない人へ(後述のコマンド知識が必要)

⚠️

「相対パス」において、VSCodeの~やpracticesは相対パスを表しますが、書き方ではありません。

また、「ルート」、「ホーム」、「カレント」のどちらにもファイルが入らないのは、コンピューターが提示するのはあくまで番地的なものだからです。ですが、それらに関しては後述に説明があるので少し待って下さいね。

コマンド

コマンドとは

コマンド…
これこそがコンピューターとの対話と言われる所以です。

とは言っても、本質は対話というよりは文字によって命令する機能です。

☝

この命令によって、ファインダーなどのファイルやフォルダ管理アプリでの操作は全て代替できます。

また、OSや設定でCLIが変わることがあるのでもちろんコマンドも変わったりします。

正しいコマンド(及びそれに付随する文)を打つと期待する結果が実行(及び表示)され、

間違ったコマンド(及びそれに付随する文)を打つとエラー文が表示されて実行はされません。

また、ファイルが関係するコマンドがありますが、これでよくワーニング文が表示されます(実行はものによる)。

主なコマンド紹介

⚠️

ここではMac用でインストールしたVSCodeを開くとデフォルトで接続され、そのターミナルに表示されるものの実体である「zsh」(アプリ名はTerminal)のコマンドについて解説されていて、VSCodeのターミナルで実行されていることに留意しておいて下さい。

☝

コマンドの後に「-」と「特定の英字」(「-l」など)を付けると「オプション」(機能)の切り替えが起き、実行結果が変わったり追加されたりします。

○ cd パス（パスで指定したフォルダに移動）
Change Directory の略

一行目が打ち方で二行目が実行結果

ホームディレクトリからpracticesに移動

相対パス↓

plain text

user@MacBook ~ % cd Desktop/python/practices user@MacBook practices %

a

絶対パス↓

plain text

user@MacBook ~ % cd /Users/user/Desktop/python/practices user@MacBook practices %

a

移動しない

相対パス↓

plain text

user@MacBook practices % cd . user@MacBook practices %

a

絶対パス↓

plain text

user@MacBook practices % cd /Users/user/Desktop/python/practices user@MacBook practices %

a

カレントディレクトリを一つ上に移動

相対パス↓

plain text

user@MacBook practices % cd .. user@MacBook python %

a

絶対パス↓

plain text

user@MacBook practices % cd /Users/user/Desktop/python user@MacBook python %

a

一つ戻ってからprac2に移動

相対パス↓

plain text

user@MacBook prac1 % cd ../prac2 user@MacBook prac2 %

a

絶対パス↓

plain text

user@MacBook prac1 % cd /Users/user/Desktop/python/practices/prac2 user@MacBook prac2 %

a

practicesからルートディレクトリに移動

相対パス兼絶対パス↓

plain text

user@MacBook practices % cd / user@MacBook / %

a

☝

「.」はカレントディレクトリを表します。

そして、「..」は一つ上に戻ることを表します。
また、「../..」は二つ上に戻ることを表します。
(同様にしていくといくらでも遡れる)

⚠️

cd単体でも実行でき、その移動場所はホームディレクトリになっています。

移動できるのはフォルダまでのパスのみです。(ファイルまでのパスはエラー文を出力)

○ ls（フォルダの中身を表示）
List Segmentの略

■ フォルダの中身を横に羅列(隠しファイルや隠しフォルダは非表示)

一行目が打ち方で二行目以降が実行結果

plain text

user@MacBook prac2 % ls prac2-1.py prac2-2.py prac2-3.py user@MacBook prac2 %

a

■ フォルダの中身を全て横に羅列(オプション「a」)

一行目が打ち方で二行目以降が実行結果

plain text

user@MacBook prac2 % ls -a . .. prac2-1.py prac2-2.py prac2-3.py user@MacBook prac2 %

a

■ フォルダの中身を詳細ありで縦に羅列(オプション「l」)(隠しファイルや隠しフォルダは非表示)

一行目が打ち方で二行目以降が実行結果

plain text

user@MacBook prac2 % ls -l total 32 -rw-r--r-- 1 user staff 14 3 20 11:49 prac2-1.py -rw-r--r-- 1 user staff 4 3 20 11:48 prac2-2.py -rw-r--r-- 1 user staff 4 3 20 11:48 prac2-3.py user@MacBook prac2 %

a

表示の解説

例↓

plain text

total 32 -rw-r--r-- 1 user staff 14 3 20 11:49 prac2-1.py

a

意味↓

plain text

このフォルダ内のファイルの合計ブロック数 単位：512バイト(通常は512バイト単位だが、環境によって異なる場合がある) アクセス権限 ハードリンク数 ユーザー名 グループ ファイルサイズ(単位：バイト) 更新月 更新日 更新時 ファイル名

a

🔑

興味があればわからないところは調べてみよう。

■ 複合オプション(「l」+「a」)

☝

コマンドのプションは複合して使えるものがあります。今回でいうと「l」と「a」ですが、「-l -a」,「-a -l」,「-la」,「-al」の全て同じ複合した結果が出力されます。(ただ、「-la」と「-al」のようなオプションをそのまま複合したものを使うのは実行されないものもあるのでお勧めしません。)
