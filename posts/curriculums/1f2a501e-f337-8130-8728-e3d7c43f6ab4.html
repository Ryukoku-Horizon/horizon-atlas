Fletの練習問題4

問題

以下のプログラムを実行すると、ボタンに表示されている文字「Button !」がターミナル（CLI）上に表示されるはずです。

python

import flet as ft

def main(page: ft.Page):
button = ft.ElevatedButton(
text="Button !",
bgcolor=ft.Colors.PURPLE_100,
)

print(button)

page.add(button)

ft.app(target=main)
