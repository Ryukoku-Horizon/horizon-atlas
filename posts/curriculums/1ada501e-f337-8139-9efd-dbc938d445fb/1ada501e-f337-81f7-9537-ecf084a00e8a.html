カスタムコントロール

カスタムコントロール

Fletの要素であるコントロールは自分でカスタムすることが可能です。今回は「カスタムコントロール」を紹介します。

カストムコントロールとは

カスタムコントロールは、Fletにあるコントロールのクラスを継承した新たなクラスを作り、親クラスの属性の値をカスタムしたコントロールです。（クラスの継承については「クラスの継承」をご覧ください）

例えば、見た目を変更した文字を使い回したいとします。文字を表示するにはTextコントロールを使いますが、その見た目を変更するにはstyle属性を設定しなければいけませんね。

python

ft.Text("文字", style=ft.TextStyle(size=20))

Textコントロールのstyle属性の値を何度も書くのは面倒です。style属性の値が事前に決まっていれば書く必要はなくなります。それを可能にするのがカスタムコントロールです。

カストムコントロールを作る

それでは、カスタムコントロールを作ってみましょう。

試しに、以下の設定のカスタムコントロールを作ってみましょう。

python

ft.Text("文字", style=ft.TextStyle(size=20))

カスタムコントロールを作る

python

import flet as ft

class CustomText(ft.Text):
  def __init__(self,value):
    super().__init__(value=value, style=ft.TextStyle(size=20)

ここではCustomTextというカスタムコントロールを定義しました。

CustomTextは、Textコントロールをカスタムしたコントロールであり、最初からstyleが設定されています。

さっそくCustomTextを使ってみましょう。

CustomTextを使う

python

import flet as ft

class CustomText(ft.Text):
  def __init__(self,value):
    super().__init__(value=value, style=ft.TextStyle(size=20))
    
def main(page: ft.Page):

  normalText = ft.Text(value="普通のTextコントロール")
  customText = CustomText(value="カスタムしたTextコントロール")

  page.add(normalText, customText)
