今回は、プログラミングでの特に重要な機能である入力について学んでいきます。

これまではprint関数を使って数値データなどの出力を行っていましたが、今回はプログラムに対してデータを入力する方法を学びます。

この入力によって、ユーザーの入力に応じて結果が異なるプログラムを作ることができます。

目次

input関数

input関数は、実行中のプログラムがユーザーから「直接情報を聞き出す」ための機能です。あらかじめ決まったデータだけでなく、その時々のユーザーの意図や状況に応じた「動的なデータ」をプログラムに組み込むことができます。

javascript
1あなたの名前を入力してください：　ホライゾン
2Hello ホライゾン
3三角形の面積を求めます
4高さを入力： 6
5底辺を入力： _

a

上では、ユーザー自身で値を入力することができます。そして、入力すると下のようになります。

javascript
1あなたの名前を入力してください：ホライゾン
2Hello　ホライゾン
3三角形の面積を求めます
4高さを入力： 6
5底辺を入力： 4
6高さ　6　底辺　4の三角形の面積は　12.0　

a

このようなユーザーに入力を求めるプログラムを作るには、input関数を使用します。input関数の使い方は以下に示す通りです。

変数に代入

python
1入力されたデータを格納したい変数 = input(”画面上に表示したい文章”)

数字の入力と型変換

最初の例に出した三角形の面積を求めるプログラムを素直に書くと、このようなコードになると思います。

三角形の面積の出力

python
1print("三角形の面積を求めます")
2a = input("高さを入力：")
3b = input("底辺を入力：")
4print("高さ", a, "、底辺", b, "の三角形の面積は", a * b / 2)

a

しかし、このコードを実行すると、

a

このようにエラーが出てしまいました。このエラーは4章で扱ったものとよく似ています。エラーを簡単に訳すと「文字列型（str型）同士の掛け算はできへんぞ」という感じです。

つまり、ユーザーに入力してもらった「6」と「4」という数字は、プログラム上では文字列として扱われてしまっています。3章で紹介したtype関数を使って、変数aとbの型を確認してみましょう。

型変換と確認

コード↓

python
1print("三角形の面積を求めます")
2a = input("高さを入力：")
3b = input("底辺を入力：")
4print("a:", type(a))
5print("b:", type(b))

a

その出力結果↓

javascript
1三角形の面積を求めます
2高さを入力： 6
3底辺を入力： 4
4a: <class 'str'>
5b: <class 'str'>

a

このように、変数aとbが文字列型となっていることがわかります。input関数で入力されたデータは、問答無用で文字列型として格納されてしまうのです。

これを解決するには、文字列型の変数 を 整数型の変数 に変換する必要があります。これは int関数 を使用することで実現可能です。int関数 は続く()内の変数を整数型に変換することができる関数です。

次のようなプログラムを実行してみましょう。

型変換と確認

コード↓

python
1a = "5"     #文字列として 5 を代入
2print(type(a))  #a の型を確認
3a = int(a)      #a を整数型に変換し、a に再代入
4print(type(a))  #再度 a の型を確認

a

その出力結果↓

javascript
1<class 'str'>
2<class 'int'>

a

☝

int(a)を実行するだけでは変換されないため、a = int(a)のように再代入する必要があります！

このようにint関数 を使うことで文字列型であった変数aが整数型に変換されたことがわかります。この int関数 を使用することで、先程のエラーを解決できます。このようにしてみましょう。

値の入力と出力確認

コード↓

python
1print("三角形の面積を求めます")
2a = input("高さを入力：")
3b = input("底辺を入力：")
4a = int(a)
5b = int(b)
6print("高さ", a, "、底辺", b, "の三角形の面積は", a * b / 2)

a

その出力結果↓

javascript
1三角形の面積を求めます
2高さを入力： 6
3底辺を入力： 4
4高さ　6　底辺　4の三角形の面積は　12.0　

a

文字型として入力された変数を int関数 によって整数型に変換したため、問題なくプログラムが実行できました。

a

その他の変換関数

Pythonには、int関数以外にも変数の型を変換するための関数が用意されています。それらをいくつか紹介します。

関数名内容使用例
int関数実数型や文字列型を整数型に変換int(a)
float関数整数型や文字列型を実数型に変換float(a)
str関数整数型や実数型を文字列型に変換str(a)
