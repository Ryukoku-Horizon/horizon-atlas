4. 四則演算

前回(3.変数の型)

算術演算子

今回は、プログラム上で四則演算（足し算、引き算、掛け算、割り算）を行う方法を学びます。といっても、やり方は非常に単純です。次のプログラムを見てください。

プログラム

python

a = 10 + 5 #足し算
b = 10 - 5 #引き算
c = 10 * 5 #掛け算
d = 10 / 5 #割り算
print("10 + 5 =", a)
print("10 - 5 =", b)
print("10 * 5 =", c)
print("10 / 5 =", d)

a

書き方は数学での四則演算に非常に似ていますが、掛け算と割り算だけ記号が少し違うので注意してください。この記号出力は以下のようになります。

a

また、この演算は、変数同士でも同様に行うことができます。以下のプログラムはv1とv2という二つの変数に対して四則演算を施しています。

プログラム

python

v1 = 10
v2 = 5
a = v1 + v2 #足し算
b = v1 - v2 #引き算
c = v1 * v2 #掛け算
d = v1 / v2 #割り算
print("v1 + v2 =", a)
print("v1 - v2 =", b)
print("v1 * v2 =", c)
print("v1 / v2 =", d)

a

a

加えて、Pythonでは次のように割り算のあまりや累乗、小数点以下の切り捨て割り算などを計算することができます。

プログラム

python

v1 = 5
v2 = 2
a = v1 % v2 #割り算のあまり
b = v1 // v2 #切り捨ての割り算
c = v1 ** v2 #累乗
print("v1 % v2 =", a)
print("v1 // v2 =", b)
print("v1 ** v2 =", c)

a

a

　これらの + - * / % // をあわせて、算術演算子と呼びます。以下の表に各算術演算子と処理内容を示します。

算術演算子処理内容
+足し算
-引き算
*掛け算
/割り算
%あまり
**累乗
//切り捨て除算

もちろん、複数の算術演算子を用いて複雑な計算を行うこともできます。その際には数学での計算と同じように掛け算と割り算が優先されますし、()で囲って計算順序を指定することもできます。また、aやbなどの変数を介さずとも、計算式の答えをprint関数で直接出力することもできます。

プログラム

python

print("上底4, 下底6, 高さ3の台形の面積", (4 + 6) * 3 / 2)
print("半径5の球の表面積", 4 * 3.14 * (5 ** 2)) #4πr^2

a

a

計算をするときの注意点

変数を用いて計算をするとき、その変数の型に注意しておかなければ、エラーや意図しない動作を引き起こす可能性があります。例えば、次のプログラムを見てください。

プログラム

python

a = 10
b = "5"
c = a + b
print(c)

a

aには整数の10が、bには文字列として5が格納されています。そのため、3行目の計算では数字と文字を足す計算式となっています。これを実行してみると…

a

赤色でエラーが出てしまい、実行ができませんでした。簡単に日本語訳すると「int型（整数型）とstr型（文字列型）の足し算はサポートされてないやで」という感じです。当たり前といえば当たり前ですが、このようなミスが規模の大きいプログラムではバグを生み出したりするのです…

☝

プログラミングをするときは、常に変数の型を意識しよう！
