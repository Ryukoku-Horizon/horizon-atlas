エラーを体験して理解することは初心者にとって非常に効果的です。そこで、Python・Fletでわざとエラーの出るコードを出すので、その原因を考え、解決してください。

☝

正しいコードは、グループで誰かが問題ごとに一つファイルを作り、そこに書いてください。

解決のステップ

ステップ１：
実行してみて、出てきたエラーの内容を読んでみよう。
ステップ ２：

エラーの内容をヒントに、何が間違っているか？ を考えよう。

ステップ３：

原因が分かったら、そこで正しいコードに修正してみてください

守ること

※今回はグループワークなので、グループ内での知識の共有を徹底してください。

1. 調べて学んだことは問題解決に繋がる・繋がらないに関わらず全員で共有

1. もしうまく行かなかったら、なぜそうなったのかも考えてみる

1. すでにエラーの理由・解決法を知っていたら、なぜそうなるのかをチームメンバーに説明する

問題３

クリックされたボタンの内容を、その下にあるテキストフィールドに反映するプログラミングを書いてみました。

a

しかし、実行してみるとボタンを押しても何も起きません。それどころか、エラーすら出てきません。さて、何が原因でしょうか…？

python

import flet as ft

def main(page: ft.Page):
    def clicked(e):
        txtfld.value = e.control.text
        txtfld.update
    
    button_a = ft.ElevatedButton(text="A!", on_click=clicked)
    button_b = ft.ElevatedButton(text="B!", on_click=clicked)
    button_c = ft.ElevatedButton(text="C!", on_click=clicked)
    txtfld = ft.TextField(value="")

    page.add(
        ft.Row(
            controls=[button_a, button_b, button_c]
        ),
        txtfld
    )

ft.app(target=main)

問題４

プラスボタンを押すと数字が１ずつ増え、マイナスボタンを押すと数字が１ずつ減るアプリを作ってみました。

a

でも、ボタンを押しても数字は変わらず、エラーが出てしまいます。このエラーを解決し、数字が変わるようにするには…？

python

import flet as ft

def main(page: ft.Page):
    def plus(e):
        txt.value = txt.value + 1
        txt.update()
    
    def minus(e):
        txt.value = txt.value - 1
        txt.update()
    
    txt = ft.Text(value="0")
    plus_button = ft.ElevatedButton(text="プラス", on_click=plus)
    minus_button = ft.ElevatedButton(text="マイナス", on_click=minus)

    page.add(txt, plus_button, minus_button)

ft.app(target=main)
