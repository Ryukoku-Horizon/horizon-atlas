6. 主要なコントロール②（テキスト系）

~ ft.Text, ft.TextField ~

ft.Text

ft.TextのFlet公式ページ

見た目

文字だけが表示されるコントロールです。

a

←こんな感じ

※valueプロパティにこれがTextです。を設定しています。

よく使うプロパティとその特徴や設定方法

・value（表示する文字）

文字列型を渡すのが基本。(他の型も可能だけれど公式に推奨されていない)

a

・size（文字の大きさ）

数値で指定する(デフォルトサイズが14)。

a

・weight（文字の線の太さ）

↓設定できる値の一覧

書くものNORMALBOLDW_100100刻み(省略)W_900
太さデフォルトボールドデフォルトより細いボールドを超えて太い

※ft.FontWeight.に続けて書く

例：ft.FontWeight.BOLD

a

・italic（字をイタリック体にするか）

ブールで設定(デフォルトがFalse(オフの意味))。

a

・max_lines（最大行数の指定）

整数で指定(実数で指定すると10.0であっても11行になったりしてしまう)。

a

他コントロールと同じ役割･設定方法のプロパティ

・color（文字の色）

・bgcolor（下地の色）

・width（横幅）

・height（高さ）

a

使用例

python

import flet as ft

def main(page: ft.Page):

    txt = ft.Text(
        value="こんちは！",
        size=20,
        weight=ft.FontWeight.BOLD,
        italic=True,
        color=ft.Colors.GREEN,
        bgcolor=ft.Colors.GREY_300,
    )
    page.add(txt)

ft.app(target=main)

a

ft.TextField

ft.TextFieldのFlet公式ページ

見た目

ft.Textがすっぽり入る高さの、入力可能な領域です(横幅はウィンドウの横幅に合わせて変化する)。

a

←こんな感じ

※全プロパティに特に何も設定していません。

よく使うプロパティとその特徴や設定方法

・border_color（枠の色）

色の指定方法はcolorプロパティなどと同じ。

a

・border_width（枠の幅）

数値で設定。

a

・border_radius（枠の四隅の半径）

数値で設定。

a

・expand（ウィンドウのサイズに合わせるか）

ブールで設定(デフォルトがTrue(オンの意味))。

※Falseにしてもwidthプロパティが設定されていなければ自動でTrueになる。

※Falseにしてもwidthプロパティで設定した値をウインドウの横サイズが下回る範囲では自動でTrueになる。

大体のコントロールにあるけれど、コントロールによって結構挙動が変わる。

a

・multiline（改行できるようにするか）

ブールで設定(デフォルトがFalse(オフの意味))。

※heightプロパティが設定されているとTrueでも無視される。

a

・min_lines（最低何行表示するか）

整数で設定(デフォルトが1で、実数を設定しようとすると1になる)。

※multilineプロパティがTrueの時に有効になり、Falseだと見かけだけmin_linesプロパティの指定行数になるが改行できない。

※heightプロパティが設定されていると設定しても無視される。

a

・max_lines（最高何行表示するか）

整数で設定(デフォルトは考えなくてよく、実数を設定しようとすると無視される)。

※multilineプロパティがTrueの時に有効になり、Falseだと見かけだけmin_linesプロパティの指定行数になるが改行できない。

※あくまで見切れずに一度に見れる最大行数なので、設定した行数を超えて改行しても、しっかり改行できてスクロールできるようになる。

※heightプロパティが設定されていると設定しても無視される。

a

他コントロールと同じ役割･設定方法のプロパティ

・color（字の色）

・bgcolor（入力領域内の色）

・width（横幅）

・height（高さ）

a

使用例

python

import flet as ft

def main(page: ft.Page):

    tf = ft.TextField(
        border_color=ft.Colors.BLUE,
        border_width=5,
        border_radius=10,
        multiline=True,
        min_lines=3,
        max_lines=10,
        color=ft.Colors.BLUE_900,
        bgcolor=ft.Colors.GREY_300
    )
    page.add(tf)

ft.app(target=main)

a
