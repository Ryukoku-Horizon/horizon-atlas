6. 条件分岐（if文）

前回(5.入力)

if文の基本

今回はプログラミングをするうえで重要な概念となる条件分岐について学んでいきます。条件分岐とは、プログラム内で特定の条件を満たすか否かで、処理を変えるための機能です。

たとえば、テストの点数が70点以上の場合は「合格」、そうでない場合は「不合格」と表示する、などを実現できます。

Pythonで条件分岐を実現するには、 if文 と呼ばれる構文を使用します。if文 は次のように書くことができます。

プログラム

python

if 条件式:
#ここに、条件式が成立するときの処理を書く
else:
#ここに、条件式が成立しなかったときの処理を書く

a

ifの後ろにある「条件式」 には大なり記号（>）や小なり記号（<）、イコール（=）などを使用した条件を示す式を書きます。例えば、「点数（score）が70点以上」という条件を示すにはscore >= 70と書きます。ここでの>=は数学での「≧」と同じ意味です。

上に書いたような、点数によって合否を判定するプログラムを作るには、以下のように書きます。

プログラム

python

score = 75
print("あなたは", score, "点です")
if score >= 70:
print("合格です")
else:
print("不合格です")

a

実行結果は以下のようになります。

出力結果

plain text

あなたは 75 点です 合格です

a

a

⚠️

今回から実行結果の表示方法を、画像からテキストに変更していますが、お気になさらず。

変数scoreには75が格納されているため、条件式score >= 70が成立し、print(”合格です”)が実行されています。

では、変数scoreに格納する数字を70未満に変更してみましょう。

プログラム

python

score = 60
print("あなたは", score, "点です")
if score >= 70:
print("合格です")
else:
print("不合格です")

a

実行結果は以下のようになります。

出力結果

plain text

あなたは 60 点です 不合格です

a

出力結果

plain text

あなたは 60 点です 不合格です

a

変数scoreに格納されている数値が60でscore >= 70という条件式を満たさなかったため、print(”不合格です”)が実行されました。

☝

プログラミングでは、if文などで条件式が成立することを真（True）、成立しないことを偽（False）と呼びます。

また、if文は以下のようにelseを省略して、条件式が真の場合のみ特定の処理を実行することもできます。

プログラム

python

score = 80
print("あなたは", score, "点です")
if score >= 70:
print("あなたは合格です")
#score が70未満のときは何も行われない

a

比較演算子

if文で使用する条件式は、>=のような記号を用いて表します。これを比較演算子 と呼びます。比較演算子にはいくつか種類があるため、以下の一覧表で紹介します。

比較演算子使用例説明備考
>x > yxがyより大きい（超過）
<x < yxがyより小さい（未満）
>=x >= yxがy以上数学の ≧ と一緒
<=x <= yxがy以下数学の ≦ と同じ
==x == yxとyが等しい数学の = と一緒
!=x != yxとyが等しくない数学の ≠ と一緒

⚠️

= が付く比較演算子は = を必ず右に書きます。

よく使う演算子

if文で使用する条件式をつなげたり特定の意味を付与します。これを比較演算子 と呼び、演算子にもいくつか種類があるため、以下の一覧表で紹介します。

演算子使用例説明備考
notnot (x < y) 直後を否定 (この場合はxがy以上)下のbool型の説明中のトグルで少し詳しい説明があります
and(x <= z) and (y <= z)xがz以下かつyがz以下
or(x <= z) or (y <= z)xがz以下またはyがz以下
inx in yx が y 中に存在する文字列やリストなどに使う

elif

if文では「もし〜ならば◯◯する」という処理でしたが、elif文 を使用することで「それ以外で、もしーならば△△する」という処理も行うことができます。

書き方は、ifとelseの間にelif 条件式を追加することで、複数の条件を順にチェックし、最初に条件式が真の部分の処理を実行します。以下のコードが記述例です。

プログラム

python

score = 75
print("あなたは", score, "点です")
if score >= 90:
print("あなたの評価はSです")
elif score >= 80:
print("あなたの評価はAです")
elif score >= 70:
print("あなたの評価はBです")
elif score >= 60:
print("あなたの評価はCです")
else:
print("あなたの評価はDです")

a

先程のプログラムは点数から合否を判定することしかできませんでしたが、elifを使用することで、点数に対して多段階の評価を判定することができます。実行結果は以下のようになります。

出力結果

plain text

あなたは 75 点です あなたの評価はBです

a

プログラムの流れを簡単に解説します。

1. 最初のifの条件式が評価され、scoreの値が90以上かどうかをチェックする。scoreの値は75なので、この条件は偽となる。

1. 次にelifの条件式が評価され、scoreの値が80以上かどうかをチェックする。この場合、scoreの値は75なので、この条件も偽となる。

1. さらに次のelifの条件式が評価され、scoreの値が70以上かどうかをチェックする。この場合、scoreの値は75なので、この条件は真となり、「あなたの評価はBです」と出力される。

このようにif, elif, elseを組み合わせることで、より複雑な条件分岐を実現できます。

a

ギモン：ifだけをたくさん使えば同じことできんじゃね？

bool型

ここでは、if文に関連して、3章で登場していないもう一つの「変数の型」を紹介します。それが bool型 です。
bool型 とは真理値を格納するための型です。真理値とは、True（真）またはFalse（偽）のいずれかを取る値のことです。（→このサイトわかりやすい！）

例えば、このように定義できます。

プログラム

python

is_true = True
is_false = False

a

bool型の使い道

bool型は条件文に使われます。
bool型は（他にも使い道はありますが）基本的に条件文にのみ使われます。
条件文の条件分岐というのは、必ずbool型（真か偽か）で判断されます。

プログラム

python

is_true = True
is_false = False
if is_true: # ←ここがTrue（真）なので処理が実行される
print("これは真です(1)")
if is_false: # ←ここがFalse(偽)なので処理が実行されない
print("これは真です(2)")

a

出力結果

plain text

これは真です(1)

a

実行結果を見ると、「これは真です(1)」が出力されています。よって、if文はbool型の変数の中身がTrueの場合のみ処理を実行したことがわかります。

比較演算子との関係

比較演算子（>や<や==）は、簡単に言えば、結果としてbool型の値（TrueかFalseか）を得られる演算子です。

プログラム

python

x = 10
y = 20
flag = x < y
print(flag)

a

出力結果

python

True

a

比較演算子の結果は必ずbool型です。なので、比較演算子は基本的に条件文で使います。

プログラム

python

x = 10
y = 20
flag = x < y
if flag: #flagがTrueなので処理が実行される
print("真")

a

出力結果

python

真

a

bool型とnot演算子の関係

先ほど紹介したnot演算子は、bool値（真偽値）を反転させるための演算子です。

例１

python

# 反転させる
print(not True) # False
print(not False) # True

a

例２

python

x = 10
print(not x == 10) # False（x == 10 → True、なので not True → False）

y = 5
print(not y > 10) # True（y > 10 → False、なので not False → True）

a
