シンプルメモアプリの手引き

Q. シンプルメモアプリとは？

A. ボタンを押すと、タイトルと本文を書けるメモ欄が下に追加されていくアプリです。

具体的には「買い物リスト」「日記」など、自由にメモとして書き残しておけるようなもの。

a

ただ今回は簡単にするために、保存機能や削除機能はつけず、書いて表示するだけで実装します。

具体的な使い方は、「メモを追加」ボタンを押して、「タイトル」と「本文」を入力するだけです。

主な機能

a

1. 「メモを追加」ボタンを押すと、タイトルと本文を書ける新しいメモ欄が1つ増える

2. 各メモ欄には、タイトル入力欄と本文入力欄の2つがある

3. 本文入力欄は複数行入力が可能

4. 何個でもメモを追加でき、下にどんどん積み重なっていく

a

一覧表示するColumnと、ボタンを用意する

目標：メモを一覧表示するColumnと、ボタンを用意しよう

目標の達成方法：

・メイン関数を定義

アプリの起動

python
1import flet as ft
2
3def main(page: ft.Page):
4	page.add()
5
6ft.app(main)

a

・メモを一覧表示するColumnをmemo_columnとして定義

空のColumn（memo_column）の作成

python
1memo_column = ft.Column(
2	controls=[]  # このリストに並べたいコントロールを入れる
3)

a

・Columnは、縦にコントロールを並べるためのコンテナです。

・controlsプロパティはリストになっていて、その中にText, TextField, Containerなどのコントロールを追加できます。

・ここでcontrols=[]とするのは、最初は何も表示しない空のリストを持った状態でColumnを作るためです。

・メモを追加するボタンをadd_buttonとして定義

中に表示する文字をcontentプロパティに入れます

add_button の作成

python
1add_button = ft.FilledTonalButton(
2    content=ft.Text(
3        value="メモを追加",
4    )
5)

a

・memo_columnとadd_buttonをpage.addでページに追加します

部品をページに追加する

python
1page.add(memo_column,add_button)

a

a

2. 「メモを追加」ボタンを押すと、新しいメモが表示される

目標：

「メモを追加」ボタンを押すと、画面下に1つのメモが追加される

目標の達成方法：

・on_click=add_memo でボタンに関数を紐づける

・add_memo関数の中で、memo_column.controls.append(...) を使ってメモカードを追加

・追加後に memo_column.update() を実行して画面を更新

add_memo関数の定義

python
1def add_memo(e):
2    memo_column.controls.append(
3        ft.Container(
4            content=ft.Column(
5                controls=[
6                    ft.TextField(...),  # タイトル入れるTextField
7                    ft.TextField(...),  # 本文入れるTextField
8                ]
9            ),
10            ...
11        )
12    )
13    memo_column.update()

a

なぜmemo_column.controls.append(...)と書けるの？

memo_column.controlsはリストです。

リストにappend()メソッドを使うとリストに要素を追加できます。（リストの中に入ったコントロールが表示されます。）

python
1memo_column.controls.append(ft.Text("新しいメモ"))

a

これは「memo_columnに新しいメモ（コントロール）を1つ追加する」という意味になります。

最終的に、page.add(memo_column)を使えば、ページ上にColumnごと表示できます。

4.見た目を整える

目標：見やすいようにアプリ全体の見た目を整える

目標の達成方法：

・メモをカードのような見た目にする

Containerを使って、内側の余白(padding)や、枠線(border)、角丸(border_radius)を指定

カードの右ようなメモ枠を作る Container の設定

python
1ft.Container(
2    padding=ft.padding.symmetric(vertical=5, horizontal=15),
3    border=ft.border.all(width=2, color=ft.colors.BLACK54),
4    border_radius=20
5)

a

・TextFieldを整える

python
1ft.TextField(
2    hint_text="タイトル",
3    hint_style=ft.TextStyle(color=ft.colors.BLACK26),
4    text_size=20,
5    border=ft.InputBorder.UNDERLINE # ft.InputBorder.NONEにすると枠線が非表示になる
6)

a

hint_textプロパティでヒントテキストを表示
hind_styleプロパティでヒントテキストの見た目を設定できます（今回は色を設定します）
text_sizeプロパティで入力文字の大きさを設定できます
borderプロパティで枠線について設定できます（タイトルではft.InputBorder.UNDERLINEを設定し、本文ではft.InputBorder.NONEを設定しましょう）

・FilledTonalButtonの見た目を整える

python
1add_button = ft.FilledTonalButton(
2	content=ft.Text(
3	  value="メモを追加", 
4	  size=20
5	),
6	height=50,
7	width=page.window.width,　
8	on_click=add_memo
9)

a

各サイズの設定

中のTextコントロールのsizeプロパティで文字の大きさを設定する
heightプロパティで高さを設定する
widthで横幅を設定する（page.window.widthはページ全体の横幅のこと）
