1-2 乱数を扱ってみよう

a

それでは、早速ランダムに数字を生成できるようにしてみましょう。

Pythonでランダムに数字を生成、いわゆる乱数を扱うには「randomモジュール」というものを使用します。これとは別に乱数を扱うことができるモジュールとして「Numpyモジュール」というものがありますが、そのモジュールに関しての説明は今回は省きます。

以下にある表にはこのモジュールを導入することによって使える関数の例をまとめました。

関数関数の意味使用例出力例
random()0≤x≤1までの実数を出力する関数random.random()0.7701951630318443
uniform(a , b)a≤x≤bまでの実数を出力する関数random.uniform(1 , 10)5.853660837158555
randint(a , b)a≤x≤bまでの整数を出力する関数random.randint(1 , 10)8

これ以外にも様々な関数が使えるようになりますが、主に使う関数はこの3つになります。私個人の話ですが。

random関数は、最小が0、最大が1までの範囲の実数を出力する関数です。また、uniform関数もrandom関数のように実数を出力する関数ですが、最大と最小の範囲を自分で設定することができます。それぞれ出力例を見てもらうとわかるのですが、かなり細く実数が出力されています。これを利用して、出された数字を100倍にして小数点以下を切り捨てたのち、6で割った余りに1足してを使ってサイコロの出目にしたり、出された数字を100倍にして小数点以下を切り捨てたのち、3で割った余りを使ってじゃんけんを作ったりと様々なことができます。

…どう考えても面倒くさいことしてますよね、これ。実際にサイコロの出目をさっき書いたことをもとに作ってみると、以下のコードになります。

python

import random

a = random.random()    #まず乱数により生成された実数をaに代入
b = int(a*100)         #aを100倍にした数字を整数型にして小数点以下を切り捨てたものをbに代入
c = b%6                #bを6で割った余りをcに代入
d = c+1                #6で割った余りを足してdに代入

print(d)             #dを出力

print(((int(random.random()*100))%6)+1)    #上のコードを1行にまとめたやつ

a

結果

a

…やっぱりコードで書いても面倒くさいことしてますね、これ。一応サイコロの出目は出力できていますが、これでは変数も多くなるし、1行にまとめたとしても読みにくいコードになってしまいます。

今のようにrandom関数やuniform関数を使って整数の乱数を扱おうとすると、整数にするために、様々な手を加えないといけません。しかし、そんな面倒くさい作業をしなくても整数の乱数を簡単に扱うことができるものがあります。それが、randint関数です。

python

import random

a = random.randint(1,6)

print(a)

a

結果

a

randint関数は、最小と最大を自分で設定することができ、扱う実数は整数になるので、整数値を扱うプログラムにはもってこいの関数となっています。なので、先ほど出ていたサイコロの出目やじゃんけんの手はこれを使った方がはるかに楽になります。

そして、Numer0nはもちろん整数値を扱うため、今回の制作ではrandint関数を使用します。
