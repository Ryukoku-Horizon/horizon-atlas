CUIとGUI

突然ですが、パソコンを使用するのに、この世界には大きく分けて2通りの方法があります。

それは、CUI と GUI です。CUIは Character User Interface、GUIは Graphical User Interface の略です。（覚えなくても大丈夫）

ちなみに、以前学んだ「CLI」は、文字だけで操作する「CUI」という大きな枠組みの中に含まれる操作方法の一つです。

CLI

CLIの基礎 でもやりましたね。CLI (Command Line Interface) は、パソコンを文字だけで操作する方法です。

また、これまでPythonで使用していたprint関数やinput関数も、文字のみの出力と入力しか扱っていないのでCUIといえます。

Pythonで作成したプログラム

このCLIを使用したプログラム・アプリは、作成が簡単、動作が軽量などといったメリットがあります。

ですが、見た目もパッとしませんし、なにより慣れている人でないとCLIを使用したアプリを使いこなすことは難しいでしょう。

そこで登場するのが、GUIです。

GUI

このようなCUIのデメリットを解決するものが、GUI (Graphical User Interface) です。このGUIは日常生活でもっとも普及している方法で、文字に加え図形や画像、さらには映像や音声でパソコンを操作しやすくします。

Flet

Fletとは先ほど紹介したGUIのアプリケーションを、Pythonで簡単に作ることができるライブラリです。

💡

ライブラリとは？

ライブラリとは、Pythonに追加でインストールすることで、さまざまな便利な機能を使えるようになるものです。

拡張機能やアドオン、ゲームで言うMODなどのイメージに近いです。

PythonにはFlet以外にも多くのライブラリが存在しており、それらを追加でインストールすることでPythonをさらに使いやすく、多機能にできるのです。

有名なものにはFlask, django, Kivy, NumPy, pandas, OpenCVなどがあります。気になったらぜひ調べて見てください！
