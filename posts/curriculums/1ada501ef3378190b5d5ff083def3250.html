データの削除(Delete)

今回はpythonとそのライブラリであるsqlite3を使用して、データベースのデータを削除する方法を紹介します。

データの削除方法

データの削除方法を見ていきましょう。

データを削除するSQL文

sql
1DELETE FROM テーブル名 WHERE 条件

a

データを削除するときはDELETE を使います。

FROM テーブル名で、どのテーブルかを指定します。

WHERE 条件で、どの行のデータを削除するかを指定します。
WHERE句がなければ、テーブル内のすべての行のデータが削除されてしまうので、基本的に必ずつけるようにしましょう。

実際にデータを削除してみよう

「データの保存(Create)」で保存したデータを削除してみましょう。

新たにdelete.pyというファイルを作成してください。

delete.pyの内容を以下のようにしてください。

delete.py

python
1import sqlite3
2
3dbname = 'TEST.db'
4conn = sqlite3.connect(dbname)
5cur = conn.cursor()
6
7# データを削除する
8cur.execute('DELETE FROM person WHERE id = 1')
9
10conn.commit()
11
12cur.close()
13conn.close()

a

delete.pyを実行してください。

TEST.dbの内容が以下のようになっていれば削除に成功です。

a

コードを見ていきましょう。

SQL文は以下のようになっています。

sql
1DELETE FROM person WHERE id = 1

a

DELETEでデータを削除することを示しています。

FROM personで、対象がpersonテーブルであることを示しています。

WHERE id = 1 で、対象がid=1の行であることを示しています。

任意のデータを扱う

データの削除をより実用的に扱う場合、任意の行のデータを削除できる必要があります。

任意の行のデータを削除する方法を見ていきましょう。

例：任意のidの行を削除する

python
1cur.execute('DELETE FROM テーブル名 WHERE id = ?', (削除したい行のid,))

a

🛑 cur = cursorオブジェクト

例えば、personテーブルで、任意のidの行のデータを削除したければ、以下のようなコードになります。

personテーブルで任意のidの行のデータを削除する

python
1import sqlite3
2
3dbname = 'TEST.db'
4conn = sqlite3.connect(dbname)
5cur = conn.cursor()
6
7# 任意の値を入れる
8target_id = 1
9
10# データを削除する
11cur.execute('DELETE FROM person WHERE id = ?', (target_id, ))
12
13conn.commit()
14
15cur.close()
16conn.close()

a

このコードでは、target_idの値によって、任意のidの行を削除できます。
