データの取得(Read)

今回はpythonとそのライブラリであるsqlite3を使用して、データベースのデータを取得する方法を紹介します。

データの取得方法

データを取得する方法を見ていきましょう。

データを取得するSQL文

sql
1SELECT カラム名 FROM テーブル名

a

これで指定したテーブルの中のカラムを取得できます。

テーブル内のすべてのデータを取得したい場合はカラム名に*を指定します。

テーブル内のすべてのデータを取得する

sql
1SELECT * FROM テーブル名

a

取得するデータの条件を指定するには、WHERE 句をつけます。

取り出すデータに条件を指定する

sql
1SELECT カラム名 FROM テーブル名 WHERE 条件

a

条件をつけることでどの行のデータを取得するかを指定できます。

条件には、「idが何か」を指定することが多いです。

例えば、idの値が1の行のデータを取り出したい場合は以下のように書きます。

id=1のデータのみを取得する

sql
1SELECT * FROM テーブル名 WHERE id = 1

a

条件を複数指定する時は、AND を使います。

複数の条件を指定する

sql
1SELECT カラム名 FROM テーブル名 WHERE 条件1 AND 条件2 AND ...

a

実際にデータを取得してみよう

「データの保存(Create)」で保存したデータを取得してみよう。

新たにread.pyを作成してください。

read.pyの内容を以下のようにしてください。

read.py

python
1import sqlite3
2
3dbname = 'TEST.db'
4conn = sqlite3.connect(dbname)
5cur = conn.cursor()
6
7# personテーブルデータを全件取得
8cur.execute('SELECT * FROM person')
9data = cur.fetchall()
10print(data)
11
12conn.commit()
13
14cur.close()
15conn.close()

a

このコードを実行してください。
以下のように出力されればデータの取得に成功です。

bash
1[(1, 'Sato', 15, 'Man')]

a

コードを見ていきましょう。

まず、cur.execute(’SELECT * FROM person’) で、personテーブルのデータをすべて取得するSQL文を実行します。次に、fetchallメソッドで取得したデータを全て変数dataに代入し、printで出力しています。

任意のデータを扱う

データの取得をより実用的に扱うには、データを取得するとき、任意の値で条件を指定する必要があります。

任意の値で条件を指定する方法を見ていきましょう。

例：idが任意の値の条件を指定する

python
1cur.execute('SELECT カラム名 FROM テーブル名 WHERE id = ?',(指定したいidの値))

a

🛑 cur = cursorオブジェクト

例えば、personテーブルから、任意のidの行のデータを取得するコードは以下のようになります。

personテーブルから、任意のidの行のデータを取得する

python
1import sqlite3
2
3dbname = 'TEST.db'
4conn = sqlite3.connect(dbname)
5cur = conn.cursor()
6
7# 任意の値を入れる
8target_id = 1
9
10# personテーブルから任意の行のデータを取得
11cur.execute('SELECT * FROM person WHERE id = ?',(target_id,))
12data = cur.fetchall()
13
14# 取得したデータを出力
15print(data)
16
17conn.commit()
18
19cur.close()
20conn.close()

a

このコードだと、target_idの値によって、テーブルから取得するデータの行が変わります。
