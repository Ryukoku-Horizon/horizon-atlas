TextField

TextField

公式ドキュメント

flet.dev

https://flet.dev/docs/controls/textfield/

概要

文字を入力することができるテキストフィールドを作ることが出来ます。

例えば、ユーザーから名前や住所を入力してもらったりするときに最適です。

実装例

実装例とコード

主なプロパティ

value

テキストフィールドに入力されている内容を変更、参照できます。

特別な事情がない限り、最初は空（""）としておくことが一般的です。

color

テキストフィールド内のテキストの色を指定します。

色の設定にはColorsオブジェクトを使用できます。

label

そのテキストフィールドに入力する内容を説明するラベルを設定します。

テキストフィールドがフォーカスされていないときは、ラベルはテキストフィールドの内部に表示されます。テキストフィールドにフォーカスが当てられると (またはフィールドが空でない場合）、ラベルはテキストフィールドの上部に表示されます。

width

テキストフィールドの横幅を指定します。

height

テキストフィールドの縦幅を指定します。

text_size

テキストフィールドに入力するテキストのサイズを設定します。

max_length

テキストフィールドに入力できる最大文字数を設定します。

password

password = Trueと設定すると、パスワードを入力するときのように入力内容が隠されるようになります。

デフォルトはpassword = Falseです。

read_only

read_only = Trueと設定すると、テキストフィールドの内容をユーザーからは変更できなくなります。（プログラム側からの変更は可能）

デフォルトはread_only = Falseです。

on_change

イベントハンドラです。

テキストフィールドの内容が変更されたときに発火します。

on_submit

イベントハンドラです。

テキストフィールドにフォーカスがあたっているときに、エンターが押されると発火します。

a

上記以外にも複数の便利なプロパティが存在します。

詳しくは、公式ドキュメントを読んでみてください。
