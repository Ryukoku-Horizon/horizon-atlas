Fletの練習問題5

問題1

以下のプログラムを見てください。

python

import flet as ft

def main(page: ft.Page):
    def change_text(e):
        tx.value = "Vertical"
        print("内容を更新しました")

    tx = ft.Text(
        value="Horizon",
        size=50
    )

    bt = ft.ElevatedButton(
        text="テキストの内容を更新",
        on_click=change_text
    )

    page.add(tx, bt)

ft.app(target=main)

このプログラムは、「テキストの内容を更新」ボタンを押すと「Horizon」となっているft.Textコントロールが「Vertical」へと変化するのを期待するものです。

しかし、実際には実行してボタンを押してみても変化しません。

正常にft.Textコントロールが更新されるようにプログラムを修正してください。
