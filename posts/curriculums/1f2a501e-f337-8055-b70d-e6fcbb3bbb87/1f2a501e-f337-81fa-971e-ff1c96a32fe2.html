ToDoアプリ

電卓が完成した方は、Todoアプリを作ってみてください。

Todoアプリとは、やること(todo)をリストで保存するアプリです。つまり「やることリストアプリ」のことです。

以下は完成品のデモです。

a

主な機能

・todo（やること）を追加できる

・任意のtodoを削除できる

・任意のtodoを編集できる

使用するコントロール

・TextField
新たに追加するtodoを入力するために使用します。
todoを編集する機能にもまた使います。

・ElevatedButton
新たにtodoを作成するためのボタンに使用します。また、編集ダイアログにおける「変更」ボタンや「キャンセル」ボタンにも使用しています。

・Column
作成されたtodoを縦に並べるのに使用します。
todoがないときは「Nothing」と表示されるようにするとよりよいでしょう。

・Text
作成されたtodoを表示するために使用します。
todoの文字列の前に「・」を連結するとよりよく見えます。

・IconButton
todoを削除するためのボタンと編集するためのボタンに使用しています。
iconプロパティにft.icons.DELETE_FOREVER_ROUNDEDにすると、ゴミ箱のアイコンになり、ft.icons.EDITにすると、ペンのアイコンになります。
（見た目はどうでもいいので、別にアイコンでもかまいません。）

・Row
作成されたtodoと削除ボタンと編集ボタンを横に並べることや、編集するときのダイアログで「変更」ボタンと「キャンセル」ボタンとを横に並べるのに使います。

・AlertDialog
todoを編集するボタンを押すと表示されるダイアログに使用しています。
ダイアログで編集できるようにして、ダイアログ上の変更ボタンを押すと実際に変更が反映されるようにします。

仕組み

・ElevatedButtonがクリックされたときにtodoを作成する機能
まず、作成されるtodoの文字列は、TextFieldのvalueプロパティを参照すると取得することができます。
作成するtodoの文字列を取得したら、Textコントロールを作成し、その中のvalueプロパティに取得した文字列を代入します。次に、その文字列が表示されるように、新たなTextコントロールをColumnコントロールで縦に並べます。Columnコントロールで、コントロールを列挙するには、controlsプロパティのリストの中に入れればいいのです。

python

todolist = ft.Column(controls=[])
#このように中身が空のft.Columnを用意し、controlsプロパティのリストに追加していけば作成したtodoを表示させられる

a

・作成されたtodoを削除する機能
まず、削除する機能を作るには、その機能を実装するボタンが必要です。そのため、Rowコントロールを使い、todoの横に削除ボタンを並べるようにします。

python

ft.Row(controls=[new_todo, delete_button])
#このようにft.Rowを使うことで作成されるtodoと削除ボタンを横に並べる

　　削除ボタンを設置できたら、任意のボタンを押すと該当するtodoを削除できる
　　ようにする必要があります。そのために、todoがある各コントロールと削除ボタ
　　ンにkeyプロパティを追加するようにしましょう。keyプロパティに一意（ユ
　　ニーク）な値をつけることで、各コントロールが識別可能になります。そうする
　　ことで、削除ボタンが押されたときの処理で、e.control.keyによってkeyを取得
　　し、同じkeyのコントロールを探して、リストから除外すれば、該当するtodoを
　　識別し、削除できるようになります。

・一意（ユニーク）の値を作る
一意とは、他と被ることのない値ということです。皆さんの学籍番号のようなもので、その値から誰か（どのデータか）を特定できるような値です。今回は格todoのあるコントロールのkeyプロパティにこの一意の値をつけて、それぞれのtodoを識別できるようにすればいいので、それほど複雑にする必要はないです。
具体的には、まず初期値が0の変数を作ります。
例：todo_counter = 0
新たにtodoが作成されるごとにその変数を1ずつ足せば一意の値になります。
todoを作成する関数の最後に：todo_counter += 1
その変数の値を格todoのコントロールのkeyプロパティに保持させればいいわけです。
（以下はその例です）

python

ft.Row(controls=[new_todo, delete_button], key=f"{todo_counter}")
#key=f"{todo_counter}"の部分がkeyプロパティです

・ダイアログを表示・非表示する
まず、ft.AlertDialogでダイアログを作ります。titleプロパティでタイトルを指定します。actionsプロパティのリストにコントロールを入れることでダイアログの中身を作ります。
dlg = ft.AlertDialog(title=ft.Text("Edit"), actions=[])
上記のようにダイアログを作ったとします。

そして、page.add(dlg)のように、page.addの中に入れてページに追加します。
そうすると、page.open(dlg)でダイアログを表示できます。
page.close(dlg)でダイアログを非表示にできます。

・todoを編集する機能
まず編集ダイアログを開くためのボタンを用意します。todoと削除ボタンの横に設置しましょう。次に、編集ボタンを押したらダイアログを表示する処理を実装します。
ダイアログを表示できたらダイアログの中身を作ります。文字を入力できるft.TextFieldと、決定ボタンとキャンセルボタン（ft.ElevatedButton）を用意します。ft.TextFieldのvalueプロパティの初期値は、編集する前のtodoの文字列を割り当てるとよいでしょう。決定ボタンを押すと編集を実際に反映できるようにして、キャンセルボタンを押すとダイアログを閉じるようにします。
編集を反映できるようにするには、ダイアログ上で入力された文字を取得し、変更ボタンが押されたら該当するtodoの文字を変更できるようにします。
削除する機能と同じように、keyプロパティでそれぞれのtodoに一意の値を割り当て、処理を実装するボタンにも同じ値をkeyプロパティに割り当てます。それで該当するtodoを識別し、該当するtodoの文字を取得した文字を割り当てたら完成です。
