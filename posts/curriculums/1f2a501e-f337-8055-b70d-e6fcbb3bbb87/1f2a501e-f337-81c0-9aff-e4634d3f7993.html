7. コントロールのレイアウト

今回はコントロールをウィンドウ上にレイアウトする方法をお伝えします。

ft.Row

まずは、複数のコントロールを横並びにする方法です。

4. コントロール で紹介したウィンドウを例に説明していきます。

a

コントロールを横並びにするにはRowコントロールを使用します。

Rowコントロールのプロパティであるcontrolsに、横並びにしたい複数のコントロールをリスト型（7. リストと辞書 ）で設定することで、上記のようなウィンドウを表示することができます。

python

import flet as ft

def main(page: ft.Page):
    icon = ft.Icon(
        name=ft.Icons.DRIVE_FILE_RENAME_OUTLINE,
        size=38,
    )
    field = ft.TextField(
        label="名前を入力",
        height=43,
        expand=1,
    )
    button = ft.FilledButton(
        text="送信",
        height=40,
    )
    
    control_list = [icon, field, button]

    row = ft.Row(controls=control_list)

    page.add(row)

ft.app(target=main)

上記の例ではリストを一度control_listという変数に格納していますが、このように変数を介さない書き方も一般的です。

python

row = ft.Row(controls=[icon, field, button])

もちろん、このRowコントロールも設定できるプロパティを複数持っており、コントロールごとの間隔を設定できるspacingなどがあります。

python

import flet as ft

def main(page: ft.Page):
    icon = ft.Icon(
        name=ft.Icons.DRIVE_FILE_RENAME_OUTLINE,
        size=38,
    )
    field = ft.TextField(
        label="名前を入力",
        height=43,
        expand=1,
    )
    button = ft.FilledButton(
        text="送信",
        height=50,
    )

    row = ft.Row(
        controls=[icon, field, button],
        spacing=50,
    )

    page.add(row)

ft.app(target=main)

spacingの設定の違いによる変化

ft.Column

次に、複数のコントロールを縦方向に並べる方法です。

これには、Columコントロールを使用します。Columnコントロールの使用方法は、先程のRowコントロールとよく似ています。

controlsプロパティに、縦並びにしたい複数のコントロールをリスト型で指定します。

python

import flet as ft

def main(page: ft.Page):
    icon = ft.Icon(
        name=ft.Icons.DRIVE_FILE_RENAME_OUTLINE,
        size=38,
    )
    field = ft.TextField(
        label="名前を入力",
        height=43,
    )
    button = ft.FilledButton(
        text="送信",
        height=40,
    )

    column = ft.Column(controls=[icon, field, button])

    page.add(column)

ft.app(target=main)

a

Columnの用途

このColumnコントロールは、先程のft.Rowで横並びにしたコントロールたちをさらに縦に並べるために使われることが多いです。言葉だけではわかりにくいと思うので、画像とコード例を示します。
