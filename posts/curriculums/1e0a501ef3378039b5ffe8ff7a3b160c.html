JAVAガイド

✅ 概要

このガイドは、Javaがどのような言語かを紹介し、「Hello, World!」を出力するプログラムを通して基本を学べるように構成されています。

1. Javaとは？

✔️ Javaは、世界中で広く使われている人気のあるプログラミング言語です。

✔️ Webシステム、Androidアプリ、企業の業務システムなどに多く使われています。

✔️ 「一度書けば、どこでも動く（Write Once, Run Anywhere）」という考え方で作られました。

💡 Javaの特徴

・汎用性、互換性：Javaで書いたプログラムは、WindowsでもMacでもLinuxでも動かせます（JVMがあればOK）。

・安全で安定した設計：エラーが起こりにくく、企業のシステムや大規模な開発でも安心して使えます。

・オブジェクト指向：「部品を組み立てる」ように考えて開発できるので、複雑なプログラムも整理しやすいです。

・スマホ開発（Android）にも対応：Androidアプリの開発にもJavaはよく使われています。

1-2. 開発環境の構築

✅ (1) Windows / Mac / Linux 共通手順

① Javaのインストール（JDK）

・https://www.oracle.com/java/technologies/javase-downloads.html からJDK（開発キット）をダウンロードしインストールします。

② 開発ツール（おすすめ）

・Visual Studio Code（軽量でおすすめ）

→ C/C++拡張と同様に、Java用の拡張機能を追加します（Java Extension Pack）。

・IntelliJ IDEA（上級者向けIDE）

→ Javaに特化した高機能なIDEです（Community版は無料）。

③ インストール確認（ターミナル）

bash
1java -version
2javac -version

1-3. はじめてのプログラム - "Hello, World!"

Javaの基本的な構造を学ぶために、「Hello, World!」を出力してみましょう。

Hello World を表示するJavaコード

java
1public class HelloWorld {
2    public static void main(String[] args) {
3        System.out.println("Hello, World!");
4    }
5}

a

実行方法（ターミナルで）

1. ファイル名を HelloWorld.java として保存

2. コンパイル

shell
1javac HelloWorld.java

a

1. 実行

bash
1java HelloWorld

a

実行結果：

Hello, World!

a

コード解説

java
1public class HelloWorld {         // クラス名（ファイル名と一致する必要あり）
2
3    public static void main(String[] args) {  // プログラムのスタート地点
4        System.out.println("Hello, World!");  // コンソールに文字を出力する命令
5    }
6
7}

a

a

💡

Javaでは、すべてのコードはクラスの中に書く必要があります。

mainメソッドが、プログラムの「入口」であり、ここから処理が始まります。
