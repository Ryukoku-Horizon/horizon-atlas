7. リストと辞書

前回(練習問題2)

a

今回は、Pythonの特に重要な機能であるリストと辞書について学んでいきます。

リスト

Pythonのリストは、複数のデータを一緒にまとめるための便利な機能です。

リストは、数字や文字列、他のリストなど、どんな種類のデータでも含めることができます。リストを作るには、データを角括弧([])で囲み、データの間にカンマ(,)を入れます。例えば、[1, 2, 3]は整数のリストで、["りんご", "バナナ", "チェリー"]は文字列のリストです。

リストは順序があり、最初の要素は0から数えます。したがって、"りんご"は["りんご", "バナナ", "チェリー"]の0番目の要素です。

Pythonでリストを定義するには、次のように記述します。

python

list_data = [1, 2, 3]
print(list_data)

a

plain text

＜出力結果＞ [1, 2, 3]

a

インデックス

リストの各要素にアクセスするには、その位置を指定します。この位置のことを インデックス といいます。

Pythonでは、インデックスを角括弧内に書くことで要素を取り出せます。例えばlist_data[0]とすると、list_dataの0番目の要素、つまり1を得られます。また、list_data[-1]というようにインデックスに-1を指定すれば、リストの最後の要素を得ることができます。

python

list_data = [1, 2, 3]
print(list_data[0])
print(list_data[-1])

a

plain text

＜出力結果＞ 1 3

a

a

スライス

Pythonのリストは「◯番目から△番目」というように、指定した範囲の要素を取り出すこともできます。これをスライスといいます。

スライスは、コロンを挟む形で、取り出したい範囲の始点と終点のインデックスを記述します。

list_data[始点のインデックス:終点のインデックス]

しかし、ここで注意すべき点は、終点として指定した要素は含まれないということです。以下のコードで確認してみましょう。

python

list_data = [0, 1, 2, 3, 4, 5, 6]
sliced_list = list_data[2:5]
print(sliced_list)

a

plain text

＜出力結果＞ [2, 3, 4]

a

このように、終点として指定した5番目の要素は出力結果に含まれていないことがわかります。

list_data[x:y]とするとき、実際に得られる範囲は x番目から y-1番目と考えると良いでしょう。

各種メソッド

Pythonのリストには、データを追加したり、削除したりするための便利な機能が搭載されています。これをメソッドといいます。

メソッドは、操作したいリスト名の後ろにドット（.）をつけ、さらにその後ろにメソッド名をくっつけます。こんなふうに…

python

list_data = [1, 2, 3, 4, 5]
list_data.append(6)     #listに新しい要素6を追加
print(list_data)

a

plain text

＜出力結果＞ [1, 2, 3, 4, 5, 6]

a

このappendメソッドを使うと、リストに新しい要素を追加することができます。

以下に、Pythonのリストで使用できる主なメソッドを一覧で紹介します。

※この表は紹介程度なのでまだ使えなくても大丈夫です。

メソッド名説明使用例
append(x)リストの末尾に要素をひとつ追加します。list.append(3)
remove(x)値がxである最初の項目を削除します。該当する項目がない場合はエラーになります。list.remove(2)
insert(i, x)指定した位置に要素を挿入します。第一引数は挿入される要素のインデックスを指定します。list.insert(1, 2)
pop(x)リストから指定した位置の要素を削除し、その要素を返します。インデックスを指定しない場合はリストの最後の要素を削除します。list.pop(1)
index(x)値がxである最初の項目のインデックスを返します。該当する項目がない場合はエラーになります。list.index(3)
count(x)リストでのxの出現回数を返します。list.count(3)
sort(key=None, reverse=False)リストの項目を、キー関数によって提供される基準で並び替えます。list.sort()

辞書

Pythonの辞書とは、例えば「名前と電話番号」や「商品名と価格」のような、それぞれペアになっている情報を保存しておける便利機能です。

Pythonで辞書を作成するときには、まずペアにしたい値を:で示し、複数ある場合はカンマで区切ります。さらにそれを中括弧（{}）で囲むことで作成可能です。

ちなみに

python

my_dict = {"apple": 100, "banana": 200, "orange": 300}

a

これは、「リンゴが100円」「バナナは200円」「オレンジは300円」というように、フルーツとその値段をmy_dictにペアで格納しています。

このmy_dictをprint関数で出力すると以下のようになります。

plain text

＜出力結果＞ {'apple': 100, 'banana': 200, 'orange': 300}

a

バリューの取り出し

”apple”, “banana”, “orange”はキー（Key）と呼ばれ、100, 200, 300はバリュー（Value）と呼ばれます。辞書ではこのキーを用いてバリューを取り出します。例えば、リンゴの価格を取り出したい場合には、このようにします。

python

my_dict = {"apple": 100, "banana": 200, "orange": 300}
print(my_dict["apple"])

a

plain text

＜出力結果＞ 100

a

要素の追加

辞書に新しい要素を追加するには、新しいキーとバリューのペアを指定することで可能です。具体的には、既存の辞書名の後ろに新しいキー名を角括弧([])内に書き、それに等号(=)を使って新しいバリューを割り当てます。

例えば、既存の辞書my_dictに新しいフルーツ（例えば、「grape」）とその価格（例えば、400）を追加したい場合、以下のように記述します。

python

my_dict = {"apple": 100, "banana": 200, "orange": 300}
my_dict["grape"] = 400
print(my_dict)

a

このコードを実行すると、my_dictに新しいキーとバリューのペア"grape": 400が追加されています。

plain text

＜出力結果＞ {'apple': 100, 'banana': 200, 'orange': 300, 'grape': 400}

a
