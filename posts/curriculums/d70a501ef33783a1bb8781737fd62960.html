a

Fletの要素であるコントロールは自分でカスタムすることが可能です。今回は「カスタムコントロール」を紹介します。

この機能を使用すると、すであるコントロールのデフォルトの見た目を自由に変えることができたり、メソッド（機能）を追加したりすることができます。

👌

前提：

Fletのカスタムコントロールはクラスの継承を使用して実現されています。

このページでは、カリキュラム的に必須であるクラスの基礎知識は前提としています。ですが、クラスの継承については知識がなくてもこのページだけでも最低限の使用方法はわかるように書いています（カリキュラム的には必須ではないため）。

目次

カストムコントロールとは

カスタムコントロールは、その名の通りFletのコントロールをカスタマイズすることができる便利な機能です。

カスタムコントロールの実例

例として、Buttonを考えてみます。普通にButtonを使用すると、以下のように青色を基調としたシンプルな見た目になります。

このボタンの見た目を自分好みに変更したいとなれば、colorプロパティやbgcolorプロパティ、styleプロパティを変更すればいいというのは、皆さんご承知でしょう。

python
1bt = ft.Button(content="ボタン1")

a

続いて、MyButtonという名前でButtonをもとに作成したカスタムコントロールを見てみましょう。

python
1bt = MyButton(content="ボタン1")

a

なんと、"ボタン1"というボタンの表示内容しか指定していないに関わらず、色は緑を基調としたものになり、余白が広くなり、アイコンまで追加されています！

ざっくり言えば、このように「緑を基調として、余白は通常より広めで、このアイコンがくっつくボタン」という見た目をデフォルトにしたオリジナルのパーツを作ることができるのがカスタムコントロールです。

この機能が、実際にアプリを作るとなったときにはとても便利になります。独自の見た目や機能を定義したコントロールを複数のページで使いまわしたり、より高度な機能性をもたせたりすることができるのです。

a

カスタムコントロールの作り方

それでは、カスタムコントロールを作ってみましょう。

まずは簡単化のために、背景色は薄い黄緑、文字色は濃い緑というボタンを作ってみます。

普通にButtonで設定

コード↓

python
1bt = ft.Button(
2        content="ボタン1",
3        bgcolor=ft.Colors.LIGHT_GREEN_100,
4        color=ft.Colors.GREEN_800
5    )

a

ぞの出力結果↓

カスタムコントロールの作成には、classを使用します。

ボタンの表示内容は、コンストラクタの引数tとして受け取ることとします。

カスタムコントロールを作る

python
1import flet as ft
2
3class MyButton(ft.Button):
4    def __init__(self, t: str = ""):
5        super().__init__()
6        self.content = ft.Text(t)
7        self.bgcolor = ft.Colors.LIGHT_GREEN_100
8        self.color = ft.Colors.GREEN_800

a

classの行

順番に解説していきます。

まず、classのあとに書かれたMyButtonが作成するカスタムコントロールの名前になります。呼び出すときに使用しますね。

そして、Mybuttonの後ろのカッコの中に入っているft.Buttonについては、どのコントロールを元にカスタムコントロールを作成するかを指定しています。

☝

ここは厳密にはButtonクラスを継承しています。

カスタムコントロールは新しいコントロールをゼロから作成するのではなく、既存のコントロールのプロパティ等をカスタマイズする形で作ります。

python
1          ↓ 作成するカスタムコントロールの名前
2class MyButton(ft.Button):
3											↑ 元にするコントロールを指定

a

def __init__の行

クラスを作成するときのコンストラクタですね。

今回はボタンの内容を変数tで受け取るため、コンストラクタの引数はselfとtの2つとなっていま

            ↓ コンストラクタ
    def __init__(self, t):
                       ↑ 表示内容を引数で受取

a

super()の行

ここは、カスタムコントロールを作るとき（厳密にはPythonでクラスの継承をするとき）のお約束といえる部分です。

クラスの継承が未履修ならば特段理解をする必要はありませんが、ここがないとカスタムコントロールとして働いてくれないので忘れないようにしましょう。

python
1				    ↓ お約束・おまじない
2        super().__init__()

a

selfの行

ここがコントロールをカスタマイズしているキモの部分です。

selfに続くのは、今回の継承元（カスタマイズの元）であるButtonのプロパティです。

この部分でButtonに存在する各種プロパティを上書きして、コントロールをカスタマイズしています。

今回であれば、contextプロパティを受け取った引数self.t、bgcolorプロパティをft.Colors.LIGHT_GREEN_100 (薄緑) 、colorプロパティをft.Colors.GREEN_800 (濃緑) としていますね。

python
1								↓ ElevatedButtonのプロパティを上書き
2				self.context = self.t
3        self.bgcolor = ft.Colors.LIGHT_GREEN_100
4        self.color = ft.Colors.GREEN_800

a

a

いざ実行！

カスタムコントロールを定義したうえで、main関数の中でMyButtonを使用してみましょう！

カスタムコントロールを使用

コード↓

javascript
1import flet as ft
2
3class MyButton(ft.Button):
4    def __init__(self, t):
5        # super().__init__() に直接プロパティを渡す
6        super().__init__(
7            content=t,
8            bgcolor=ft.Colors.LIGHT_GREEN_100,
9            color=ft.Colors.GREEN_800
10        )
11
12def main(page: ft.Page):
13    bt = MyButton(t="ボタン1")
14    page.add(bt)
15
16ft.run(main)

実例で使用したコード

カスタムコントロール で使用していたカスタムコントロールのコードを載せておきます。

カスタムコントロール

python
1class MyButton(ft.Button):

カスタムコントロールが便利な場面

先程のように、スタマイズしたボタンを一つしか使わないのであれば、単純にButtonのプロパティを設定すればいいだけなので、わざわざカスタムコントロールを使う意味はあまりありません。

しかし、先程のように見た目をカスタマイズしたボタンを、アプリ内の複数箇所で使いまわしたいとなったらどうなるでしょう。

ページの上部にも下部にも置きたいし、なんならViewをまたがってデザインを統一したいかもしれません。そんなときに、すべての箇所でft.Button(content=…) なんて書いていたら大変です。

一箇所で定義しておけばどこでも使い回せるというのが、カスタムコントロールの大きな強みです。

より便利なカスタムコントロールの使い方

上ではだいぶ基礎的なカスタムコントロールの使い方を紹介しました。

もっと実用的で便利な使い方を知りたいぜ！という方は、長いですが以下も読んでもらえるとお得かもです。

コントロールをまとめて一つのパーツとする

先程は一つのコントロール（Button）をカスタマイズしていましたが、工夫によって複数のコントロールをまとめてカスタムコントロールとして扱うことができます。

実例とともに実践形式で学んでいきましょう。

たとえば、アプリ内で簡易的なプロフィールとして機能するプロフィールカード的なものを作るとします。

これは、以下のコントロールを組み合わせれば実現可能ですね。

・Card (モダンなデザインを気軽に実現するため)

・Container (以下のコントロールをラップして幅などを設定するため)

・Image (プロフィール画像表示)

・Text (名前などの表示)

・Row (画像とテキスト情報を横並びにするため)

・Column (役職、名前、技術スタックを縦に並べるため)

このプロフィールカードを実現するカスタムコントロールは以下になります。長いですが、分解して見ていけば難しいことはしていません。

プロフィールカードのカスタムコントロール

javascript
1class ProfileCard(ft.Card):
2    def __init__(self, image, name, role=None, tech_stack=[]):
3        super().__init__()
4        # 最初の3つだけを使用
5        tech_stack = tech_stack[:3]
6        self.content = ft.Container(
7            content=ft.Row(
8                controls=[
9                    ft.Image(
10                        src=image,
11                        width=120,
12                        height=180,
13                        fit=ft.ImageFit.COVER,
14                        border_radius=10,
15                    ),
16                    ft.Column(
17                        controls=[
18                            ft.Text(value=role, size=12, color=ft.Colors.GREY),
19                            ft.Text(value=name, size=25, weight=ft.FontWeight.BOLD),
20                            ft.Column(
21                                controls=[
22                                    ft.Text(value=f"・{i}", size=15) for i in tech_stack
23                                ]
24                            ),
25                        ],
26                    ),
27                ],
28                spacing=30,
29            ),
30            padding=15,
31            width=350,
32        )
33        self.color = ft.Colors.GREEN_50
34        self.elevation = 10
