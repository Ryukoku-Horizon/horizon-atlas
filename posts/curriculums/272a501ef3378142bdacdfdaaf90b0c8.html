Controller層を作る

Controller層を作る

今回はController層を作成します。

Controller層

a

Controller層の役割

Controller層は主に以下の責務を担います。

・ユーザーからの入力を受け取る

・データの加工

・データをViewに渡す

今回のTodoアプリの場合、早い話がModel層で行う処理を除いたほぼ全てのロジック部分がController層になります。

依存関係

まず、Controller層はModel層に依存するので、todoController.pyの上部でModel層のモジュールとクラスをimportしましょう。

todoController.py

python

from lib.models import todoGateway as gate
from lib.models.todoModel import Todo

a

なお、今回のTodoアプリでは、Controller層をView層に依存させずに作ることができるので、依存させずに作成します。

よって、今回のTodoアプリの依存関係は以下のように一方通行となります。

def check_todo(e, isAchieved, id):
    if isAchieved:
        isAchieved = 0
    else:
        isAchieved = 1

def fetch_todo():
    rows = gate.get_todo()
    todo_list = []
    for row in rows:
        todo = Todo(id=row[0],task=row[1],isAchieved=row[2] == 1,created_at=row[3])
        todo_list.append(todo)

    for todo in todo_list:
        text = ft.Text(todo.task)
        checkbox = ft.Checkbox(on_change=lambda e, isAchieved=todo.isAchieved, id=todo.id:check_todo(e, isAchieved,id))

ロジック部分に必要なデータを引き渡す

Controller層には、View層から受け取らなければならない値がいくつかあります。

例えば、create_todo関数を見ましょう。

create_todo関数

python

def create_todo(e, task):
    gate.save_todo(task)
    page.go("/")

a

create_todo関数は、イベント引数eとユーザーが入力したtaskを受け取っています。

しかし、create_todo関数にはpage.go(”/”)がありますが、pageが定義されていません。ですので、新たに引数としてpageを受け取る必要があります。

そして、他の関数でもpageは使われているので、Controller層のほとんどの関数ではpageを受け取る必要があります。そうすると、todoController.pyは以下のようになります。

main.pyの整理

不要な部分を取り除く

todoController.pyに移動させたロジック部分をmain.pyから削除しましょう。

そうすると、main.pyは以下のようになります。

main.py

python

import flet as ft
from lib.models import todoGateway as gate
from lib.models.todoModel import Todo

def main(page: ft.Page):
    appbar = ft.AppBar(
        center_title=True,
        title=ft.Text(value="TODOアプリ"),
        bgcolor=ft.Colors.BLACK12
    )

    def route_change(e):
        template_route = ft.TemplateRoute(page.route)

        if template_route.match("/create"):
            createTextField = ft.TextField(hint_text="TODO")
            appbar.leading = ft.IconButton(icon=ft.Icons.ARROW_BACK, on_click=lambda _:page.go("/"))
            page.views.append(
                ft.View(
                    "/create",
                    appbar=appbar,
                    controls=[
                        ft.Text("TODO作成"),
                        createTextField,
                        ft.ElevatedButton(text="作成",on_click=lambda e:create_todo(e, createTextField.value))
                    ]
                )
            )
        elif template_route.match("/"):
            appbar.leading = ft.Text("")
            floating_button = ft.FloatingActionButton(
                icon=ft.Icons.ADD,
                bgcolor=ft.Colors.BLUE_200,
                on_click=lambda _: page.go("/create")
            )
            fetch_todo()
            page.views.append(
                ft.View(
                    "/",
                    appbar=appbar,
                    controls=[con.todo_list_control],
                    floating_action_button=floating_button
                )
            )
        page.update()

    page.on_route_change = route_change
    page.go(page.route)

ft.app(main)

main.py

import flet as ft
from lib.controllers import todoController as con

def main(page: ft.Page):
    appbar = ft.AppBar(
        center_title=True,
        title=ft.Text(value="TODOアプリ"),
        bgcolor=ft.Colors.BLACK12
    )

    def route_change(e):
        template_route = ft.TemplateRoute(page.route)

        if template_route.match("/create"):
            createTextField = ft.TextField(hint_text="TODO")
            appbar.leading = ft.IconButton(icon=ft.Icons.ARROW_BACK, on_click=lambda _:page.go("/"))
            page.views.append(
                ft.View(
                    "/create",
                    appbar=appbar,
                    controls=[
                        ft.Text("TODO作成"),
                        createTextField,
                        ft.ElevatedButton(text="作成",on_click=lambda e:con.create_todo(e, createTextField.value, page))
                    ]
                )
            )
        elif template_route.match("/"):
            appbar.leading = ft.Text("")
            floating_button = ft.FloatingActionButton(
                icon=ft.Icons.ADD,
                bgcolor=ft.Colors.BLUE_200,
                on_click=lambda _: page.go("/create")
            )
            con.fetch_todo(page)
            page.views.append(
                ft.View(
                    "/",
                    appbar=appbar,
                    controls=[con.todo_list_control],
                    floating_action_button=floating_button
                )
            )
        page.update()

    page.on_route_change = route_change
    page.go(page.route)

ft.app(main)
