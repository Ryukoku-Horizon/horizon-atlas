3-2 数字や桁の一致判定システムを作成しよう

while l == 0:
a = random.randint(100,999)
b = str(a)
answer = list(b)

for f in range(10):
if answer.count(str(f)) >= 2:
answer = []
break

if answer != []:
l = 1

while 1:
player_number = input("正解だと思う3ケタの数字を入力してください。:")
player = list(player_number)

a

おそらくこれとほぼ同じコードになっていると思います。少し変わっているところと言えば、ところどころにあったprint関数と、最後のところにあったelse文が消えているぐらいでしょうか。

今回の一致システムは「while 1:」内に導入します。それでは、次のコードを見てください。

python

while 1:
EAT = 0
BITE = 0
player_number = input("正解だと思う3ケタの数字を入力してください。:")
player = list(player_number)

if len(player) != 3:
continue

for i in range(3):
if player[i] == answer[i]:
EAT += 1
else:
for j in range(3):
if player[i] == answer[j]:
BITE += 1

print(EAT, "EAT ", BITE, "BITE")

a

導入の部分で、桁と数字が一致していることを「EAT」、数字だけが一致していることを「BITE」ということを言いました。今回のこのコードは簡単に言うと、入力された数字と桁が正解の数字と桁が完全一致していればEATに1を足し、数字だけが一致していればBITEに1を足したあと、その数をそれぞれ出力するという意味になります。それをどのように判定させているかを解説します。

playerとanswerにはリストが格納されています。「リスト名[整数]」と記述すればリストの左から大カッコの中にある数字番目を取り出すことができることは基礎文法カリキュラムで学んだと思います。その何番目かを指定するものとして、「for i in range(3)」というfor文を使用しています。これで変数iには0と1と2が順番に代入されるので、それを「リスト名[整数]」の整数部分に入れると正解の数字や入力された数字を1つずつ取り出すことができます。それを使って、if文の条件式で「入力された数字のリストの左からi番目の要素と正解の数字のリストの左からi番目の要素が同じならば」という意味があることによって、「桁と数字が一致しているならば」を再現することができます。

数字と桁が合っていなかった場合、if文内の処理が行われず、else文の処理へと移りますが、個々の中でもfor文が使われていると思います。なぜかというと、数字だけが一致しているかを判定するために、もう一つの変数jに0と1と2を代入しなければならないからです。こうすることによって、if文では入力された数字のリストの左からi番目の要素が正解の数字のリストの中にあるかどうかを条件式で書くことができるのです。これが一致システムの全容です。

a

さて、ここまで何とか一致システムを解説しましたがちょっと気になることがあると思います。それは「EAT += 1」と「BITE += 1」の部分です。さらっと「EATに1を足す」とか「BITEに1を足す」とか言って流していましたが、これについてちょっと説明します。

実はこの「+=」、演算子なんです。名前を「代入演算子」と言います。次の表を見てください。

代入演算子使用例使用例の言い換え(意味)
+=a += 1a = a + 1
-=a -= 1a = a - 1
*=a *= 2a = a * 2
/=a /= 2a = a / 2

これ以外にもまだまだありますが、よく使われる代入演算子をまとめてみました。「a += 1」は、「変数aに1を足したものをaに代入する」という意味であることからこの式は、「a = a + 1」と同じ意味になり、この式に言い換えることができます。これは引き算、掛け算、割り算も一緒です。しかし、この演算子を使うためには事前に変数があることを宣言しなければいけません。次のコードを見てください。

python

a += 1
print(a)

a

結果

a

このように、事前に宣言しておかないと「変数aなんてものありません」というエラーが出てしまいます。実際、演算子の左にある変数に演算子の右にある式の結果を代入するわけですから何も代入されていない変数を使うというのは確かにおかしな話です。なので、エラー対策として事前にその変数があることを宣言するのです。

python

a = 0

a += 1
print(a)

a

結果

a

事前に変数aに0が代入されているので、aに1が足すことができましたね。これが、元の一致システムではwhile文の処理が始まってすぐにEATとBITEに0を代入している意味になります。

では、なぜこんな書き方をするのかという話ですが、僕個人の意見としてはコードが見やすくなるからだと思っています。同じ行に同じ変数があると、あとでそのコードを見た時に何を書いているかが少しわかりにくいと感じてしまうのでしょう。まぁ、僕は思ったことは無いのですが。

ただ、この演算子は結構使われることが多いので、他人のコードを見た時に知っておくとかなり便利です。ぜひ覚えていってください。
