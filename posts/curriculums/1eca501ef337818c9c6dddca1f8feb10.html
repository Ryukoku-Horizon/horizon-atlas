2-1 正解の数字をリスト化しよう

それでは、ここからは本格的に「Numer0n」を作っていきましょう！ここでは、3桁verのNumer0nを制作します。

…とその前に、ここのタイトルにある「正解の数字をリスト化する」という言葉の意味について説明します。次の例を読んでください。

💡

例：正解の数字が123だった場合、3桁の数字として扱うのではなく”1”、”2”、”3”という感じで1つの文字として扱う。それを[’1’ , ‘2’ , ‘3’]という内容のリストを作る。

これが実現できるプログラムを今回は制作します。作る理由としては3-2で制作するシステムの中身がそのリストを使って1文字ずつ桁と数字が合っているか、数字だけが合っているか、それともその数字が使われていないかどうかを判定するからです。(3-2で詳しく解説します。)これを実現させるために、正解の数字と入力された数字をそれぞれ1文字ずつ分け、その分けた文字を配列として、リストに格納する。という感じです。

a

では、実際に作ってみましょう。次のコードを見てください。

python
1import random
2
3a = random.randint(100,999)
4b = str(a)
5answer = list(b)

a

aの値とanswerの値を出力した結果

a

コードの解説をします。ランダムで3桁の数字を生成するために範囲を100～999まで設定することによって確定で3桁の数字を生成することができます。これをaに代入します。その後、aの値を文字列化したものをbに代入し、リスト化したbをanswerに代入する。という処理をします。これで正解の数字をリスト化することに成功しましたね！では続いての説明に移りましょうか！

a

…というわけにはいきませんよね。このコードを見た時に大体の人はこう思ったはずです。

・なぜ、3桁の数字を文字列化する必要があるのか。

・なぜ、リストを作成するのに[](大かっこ)が使われていないのか。

・そもそも、「list()」ってなんやねん。

今から、この3つの疑問を一気に解決していきます。

基礎文法カリキュラムでは、リストを作る際は「変数名 = []」にする必要があると学んだと思います。しかし実は、リストを作る手段としてlist関数、つまり「list()」を使うことがあります。

使用例

python
1a = list()
2
3print(a)

a

結果

a

aに空のリストが入っていることがわかったことから、list関数を使うと空のリストを生成することができます。僕は空のリストを作るときは結構これを使っています。そして、ある値を1文字ずつに分解し、リスト化するときは次のようなコードを書きます。

python
1a = "あいうえお"
2b = list(a)
3print(b)

a

結果

a

aにあ行が書かれた文字列を代入したのち、list関数のカッコ内にaを入れたものをbに代入することによって、あ行の5文字が1文字ずつに分解し、リスト化できていることがわかります。つまり、このlist関数というものはカッコ内にある文字列を一文字ずつに分解し、それらをリスト化する関数であることがわかります。先ほど、空のリストを生成することができるとありましたが、正確にはカッコ内に何も文字列が書かれなかったため、空のリストが生成されたことになります。

ここでの説明ではカッコ内に入れているものが全て文字列を扱っていますが、これを整数にして扱うとどうなるのか、次のコードを見てください。

python
1a = 12345
2b = list(a)
3print(b)

a

結果

a

はい。エラーが出ました。エラーを軽く読んでみると、「整数型は反復可能ではありません(Google翻訳より)」と出ていますが、要約すると「整数じゃlist関数動かへんよ」という意味になります。これが、3桁の数字を文字列化する意味です。整数をlist関数に突っ込むとエラーが出てしまうため、わざわざ文字列にしてからlist関数のカッコ内に入れているというわけです。これは、小数になっても同様のエラーが出ますので使用する際は注意しておいてください。
