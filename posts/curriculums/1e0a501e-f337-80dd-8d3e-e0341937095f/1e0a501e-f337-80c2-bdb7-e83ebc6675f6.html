C#ガイド

C#ガイド

✅ 概要

このガイドは、C#がどんな言語かを紹介し、「Hello, World!」を出力するプログラムまでをわかりやすく説明します。

1. C#とは？

✔️ C#は、Microsoftが開発したプログラミング言語で、アプリケーション開発に広く使われています。

✔️ Windowsアプリ、ゲーム（Unity）、Webシステムなど、様々な場所で活躍します。

✔️ JavaやC++に似た構文を持ちながらも、よりモダンで扱いやすくなっています。

💡 C#の特徴

・オブジェクト指向で書きやすい：「部品を組み合わせる」ようにプログラムが作れる。複雑なものも整理しやすい。

・開発環境がとても充実：Visual Studioなど、便利なツールで効率よく開発できます。

・Unityと相性バツグン：ゲーム開発で人気のUnityはC#で作るので、ゲームを作りたい人にもおすすめ！

・安全で強力な型システム：プログラムの間違いを事前にチェックしやすく、安心して開発できます。

1-2. 開発環境の構築

✅ (1) Windowsユーザー向け（おすすめ）

・Visual Studioのインストール

→ https://visualstudio.microsoft.com/ja/ にアクセス

→ 「Visual Studio Community」を選んでインストール

→ インストール時に「.NETデスクトップ開発」を選択しておくと便利！

✅ (2) MacやLinuxの場合

・.NET SDKのインストール

→ https://dotnet.microsoft.com/ja-jp/download からお使いのOSに合わせてダウンロード

→ ターミナルで確認：

bash

dotnet --version

・VS Codeの使用も可能！

→ VS CodeとC#拡張機能を組み合わせて使うことで、軽量かつ快適に開発できます。

1-3. はじめてのプログラム - "Hello, World!"

C#の基本的な動作を理解するために、「Hello, World!」を表示するプログラムを書いてみましょう！

Hello World を表示するコード

c#

using System;

class Program
{
    static void Main()
    {
        Console.WriteLine("Hello, World!");
    }
}

実行方法（コマンドラインで実行する場合）

1. フォルダを作成し、初期化：

bash

dotnet new console -o HelloWorldApp
cd HelloWorldApp

1. プログラムを実行：

bash

dotnet run

実行結果：

text

Hello, World!

コードの解説（初心者向け）

c#

using System;              // 入出力に使うSystem名前空間を使用

class Program              // クラス（プログラムの基本単位）を定義
{
    static void Main()     // プログラムの開始地点
    {
        Console.WriteLine("Hello, World!"); // コンソールに文字を出力
    }
}

a

💡

C#では、すべてのプログラムがクラスの中で動作します。

Main()メソッドが最初に実行される場所です。
