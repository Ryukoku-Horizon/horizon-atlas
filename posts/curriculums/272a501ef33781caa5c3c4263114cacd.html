Model層を作る

Model層を作る

今回から前回完成させたTodoアプリをMVCに従って役割を分けていきます。今回は、その中でもModel層を作っていきます。

Model層

a

Model層の役割

Model層は主に以下の二つの責務を担います。

・データベースや外部のデータにアクセスする

・データ構造を定義する

今回作ったTodoアプリでは、データベースへのアクセスと、Todoクラスの定義がこれにあたります。

今回は、データベースへのアクセスをtodoGateway.pyファイルに担わせ、Todoクラスの定義をtodoModel.pyファイルに担わせます。

Model層は、他の層に依存しないという特徴があるので、そこに注意しながら設計しましょう。

データ構造の定義

それでは、ここから実際にファイルごとに役割を分けていきましょう。

まず、今回作成したTodoアプリでデータ構造を定義しているのはTodoクラスです。ですので、Todoクラスの定義をそのままtodoModel.pyに移動させましょう。

todoModel.py

python

class Todo:
    def __init__(self, id=0, task='', isAchieved=False, created_at =''):
        self.id = id
        self.task = task
        self.isAchieved = isAchieved
        self.created_at = created_at

a

main.pyで、Todoクラスを呼び出すようにしましょう。

main.py

from lib.models.todoModel import Todo

todoGateway.pyはデータベースへのアクセスに特化させるので、ファイル上部にsqlite3のimportとデータベースファイルの名前を代入した変数を定義しましょう。

todoGateway.py

import sqlite3

それでは、データベースへアクセスする部分をmain.pyから取り出していきましょう。

Todoの取得

main.pyでは、fetch_todo関数でデータの取得とその表示をしています。その中からデータの取得の部分のみ取り出し、todoGateway.pyに移します。fetch_todo関数の以下の部分が、データベースにアクセスしてデータを取り出している部分です。

fetch_todo関数のデータ取得の部分

python

conn = sqlite3.connect(dbname)
cur = conn.cursor()
cur.execute('SELECT * FROM todo')
rows = cur.fetchall()
todo_list = []
for row in rows:
    todo = Todo(id=row[0],task=row[1],isAchieved=row[2] == 1,created_at=row[3])
    todo_list.append(todo)
conn.commit()
cur.close()
conn.close()

a

しかし、この中には、データベースのアクセスに関係ない部分も含んでいます。todoGatewayはデータベースへのアクセスに特化させるので、その部分は取り除きましょう。

具体的には以下の部分がデータベースのアクセスとは関係ない部分です。

データベースとのアクセスと関係ない部分

python

todo_list = []

ということで、データベースにアクセスしてデータを取得する部分を取り出すと以下のようになります。

a

それでは、todoGateway.pyに、データを取得するget_todo関数を作りましょう。

get_todo関数

python

def get_todo():
    conn = sqlite3.connect(dbname)
    cur = conn.cursor()
    cur.execute('SELECT * FROM todo')
    rows = cur.fetchall()
    conn.commit()
    cur.close()
    conn.close()
    return rows

a

get_todo関数では、シンプルに、取得したデータrowsを返すようにしています。

それでは、get_todo関数をfetch_todo関数内で使うようにしましょう。

まずtodoGatewayをモジュールとしてimportします。

main.py

a

get_todo関数をfetch_todo関数で使用すると以下のようになります。

fetch_todo関数

python

def fetch_todo():
		# データを取得
    rows = gate.get_todo()
    todo_list = []
    for row in rows:
        todo = Todo(id=row[0],task=row[1],isAchieved=row[2] == 1,created_at=row[3])
        todo_list.append(todo)
    controls = []
    for todo in todo_list:
        text = ft.Text(todo.task)
        checkbox = ft.Checkbox(on_change=lambda e, isAchieved=todo.isAchieved, id=todo.id:check_todo(e, isAchieved,id))
        if todo.isAchieved:
            text.style = ft.TextStyle(decoration=ft.TextDecoration.LINE_THROUGH)
            checkbox.value = todo.isAchieved
        controls.append(
            ft.Row([
                checkbox,
                text,
                ft.IconButton(icon=ft.Icons.DELETE,on_click=lambda e,id=todo.id: delete_todo(e, id))
            ]))
    todo_list_control.controls = controls
    page.update()

a

Todoの保存

main.pyでは、データの保存をcreate_todo関数で行っています。

create_todo関数

python

def create_todo(e, task):
    conn = sqlite3.connect(dbname)
    cur = conn.cursor()
    cur.execute('INSERT INTO todo(task) VALUES (?)',(task,))
    conn.commit()
    cur.close()
    conn.close()
    page.go("/")

a

このコードはほぼデータベースへのアクセスの処理ですが、最後のpage.go(”/”)だけはデータベースへのアクセスと関係ないので、そこを取り除いた形で、todoGateway.pyにsave_todoという関数を作りましょう。

save_todo関数

python

Todoのチェック

main.pyでは、Todoのチェックはcheck_todo関数で行われています。
