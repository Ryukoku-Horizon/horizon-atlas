AppBar

Fletのアプリをより「アプリっぽく」することができるコントロール、AppBarについてご紹介します。

AppBarを使用すると、こんな感じの画面の上部分に固定されたUIをつくることができます。

a

インスタグラムのアプリで言う、この部分です。

Fletで実装すると、以下のような見た目になります。

From : https://flet.dev/docs/controls/appbar/

AppBarは、パソコンアプリはもちろん、スマホアプリを作るときに役立ちます。

AppBarの実装方法

AppBarの実装方法は、これまで使用していたコントロールと少し違います。

これまで使用していたコントロールは、任意の変数に代入した後、page.addで画面に追加していました。

python

# これまでのコントロール
import flet as ft

def main(page: ft.Page):
    # 任意の変数にコントロールを代入
    text = ft.Text(value="サンプル")

    # page.addする
    page.add(text)

ft.app(target=main)

a

対するAppBarは、すでに名前が決まっている変数page.appbarに代入することで実装することができます。

✏️

page.appbarはpageのメンバ変数ですね。

また、このpage.appbarはpage.addする必要はありません。

以下のコードを見てみてください⇩

python

import flet as ft

def main(page: ft.Page):
    # page.appbarにft.Appbarを代入
    page.appbar = ft.AppBar(
        leading=ft.Icon(ft.icons.APPLE),
        title=ft.Text(value="アプリ名"),
        actions=[
            ft.IconButton(icon=ft.icons.MENU)
        ],
        bgcolor=ft.colors.GREEN
    )

    text = ft.Text(value="AppBarのサンプル")

    page.add(text)

ft.app(target=main)

AppBarには、主に3つの役割があります。一つづつ順番に紹介していきますね。

タイトルの表示

titleプロパティ

AppBarのtitleプロパティにft.Textコントロールを渡すと、AppBarに好きな文字列を表示させることができます。

アプリの名前などを表示すると良いでしょう。

python

import flet as ft

def main(page: ft.Page):
    page.appbar = ft.AppBar(
        title=ft.Text(value="アプリ名"),
        bgcolor=ft.colors.BLACK12
    )

    text = ft.Text(value="AppBarのタイトルのサンプル")

    page.add(text)

ft.app(target=main)

a

a

titleプロパティに渡すのはft.Textコントロールなので、サイズやフォント、色を好きにカスタマイズできます。

python

import flet as ft

def main(page: ft.Page):
    page.fonts = {
        "Jacquarda" : "/fonts/JacquardaBastarda9-Regular.ttf"
    }

    page.appbar = ft.AppBar(
        title=ft.Text(
            value="Applicarion Name",
            color=ft.colors.CYAN,
            size=35,
            font_family="Jacquarda"
        ),
        bgcolor=ft.colors.BLUE_GREY_50
    )

    text = ft.Text(value="AppBarのタイトルのサンプル") 

    page.add(text)

ft.app(target=main)

タイトルの中央寄せ

先ほどの例ではタイトルが左寄りになっていましたが、以下のように中央に寄せることもできます。

a

タイトルを中央に寄せるためには、center_titleプロパティをTrueを設定します。

python

import flet as ft

def main(page: ft.Page):

    page.appbar = ft.AppBar(
        title=ft.Text(value="Applicarion Name"),
        # タイトルを中央寄せ
        center_title=True,
        bgcolor=ft.colors.BLUE_GREY_50
    )

    text = ft.Text(value="AppBarのタイトルのサンプル") 

    page.add(text)

ft.app(target=main)

a

アイコンの表示

leadingプロパティ

このAppBarの左側には、そのアプリを象徴するアイコンを配置することができます。

a

このleadingプロパティには、ft.Iconコントロールを設定することができます。

python

import flet as ft

def main(page: ft.Page):

    page.appbar = ft.AppBar(
        # 左端に配置するアイコン
        leading=ft.Icon(ft.icons.TIPS_AND_UPDATES),
        bgcolor=ft.colors.BLUE_GREY_50
    )

    text = ft.Text(value="AppBarのアイコンのサンプル")  # valueを省略

    page.add(text)

ft.app(target=main)

固定ボタンの設置

actionsプロパティ

AppBarの右側には、複数のボタンを設置することができます。インスタのAppBarでいうDMボタンですね。

a

一般的にはft.IconButtonコントロールを設置します。

このボタンは、antionsプロパティにリスト形式で複数のft.IconButtonsを与えることで設定します。

python

import flet as ft

def main(page: ft.Page):

    page.appbar = ft.AppBar(
        actions=[
            ft.IconButton(ft.icons.MESSAGE),
            ft.IconButton(ft.icons.CALENDAR_MONTH),
            ft.IconButton(ft.icons.SETTINGS)
        ],
        bgcolor=ft.colors.BLUE_GREY_50
    )

    text = ft.Text(value="AppBarの固定ボタンのサンプル")  # valueを省略

    page.add(text)

ft.app(target=main)

a

a

専用の関数を作成し、ボタンにイベントハンドラを設定することで、特定の処理を呼び出したり他の画面に遷移することができるようになります。
