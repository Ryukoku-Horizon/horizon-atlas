not a git repositoryエラーについて

gitでは、not a git repositoryというエラーが起きることがあります。ここではその原因と解決方法を紹介します。

リポジトリについて の知識を前提にしています。読んでいない方は先に読むことを勧めます。

原因

結論：リポジトリ以外の場所でリポジトリの操作を実行していることです

つまり、コマンドを実行する場所が違うので、コマンドを実行する場所を変えればエラーは解決できます。

リポジトリの場所とは？

リポジトリとは.gitフォルダのことです。なので、「リポジトリの場所」とは.gitフォルダがあるフォルダのことです

bash

my-project/
 ├── .git/  ← リポジトリ
 ├── ...(開発ファイル群)

a

my-projectフォルダのように.gitフォルダがある場所がリポジトリです。

ここでgit add, git commit, git pullなど、Gitのリポジトリを操作するコマンドを問題なく実行できます。

つまり、コマンドを実行している場所に.gitフォルダがなければnot a git repositoryエラーが発生します。

どうすれば.gitを確認できるのか

ls -aコマンドを実行すると確認できます。このコマンドを実行すると、以下の画像のようにそのフォルダにあるファイルとフォルダを一覧できます。

a

.gitと表示されればその場所にリポジトリがあるので、問題ないです。

表示されなければ、そこにリポジトリがないということです。

解決法

別のフォルダでコマンドを実行しよう

ということです。

作業フォルダを変えるには、VSCodeで開くフォルダを変えるか、ターミナルで作業フォルダを移動するか、どちらかです。

VSCodeでフォルダを開くのはすでにできると思うので、ターミナルで作業フォルダを移動する方法を説明します。

ターミナルで作業フォルダを移動する方法

詳しくはCLIの基礎 に書いてあります。

cdコマンドを使います。

powershell

cd <移動したいファイル>

a

ターミナルで作業フォルダを移動してから、ls -aを実行し、.gitが表示されれば、そこがリポジトリです。
