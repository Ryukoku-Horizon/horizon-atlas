a

a

問題2

ユーザーから入力された文字列の最初の文字と最後の文字を出力してください

※プログラムは「prac4-2.py」として保存

期待する出力結果

plain text

文字列を入力 : Hello, Horizon 最初の文字 : H 最後の文字 : n

a

答え

python

# ユーザーから入力されたされた文字列の最初の文字と最後の文字を出力してください

str = input('文字列を入力 : ')
print('最初の文字 : ' + str[0])
print('最後の文字 : ' + str[-1])

a

問題3

ユーザーから入力された文字列の3文字目から5文字目までを取り出し、画面に出力してください。

※プログラムは「prac4-3.py」として保存

期待する出力結果

plain text

文字列を入力 : こんにちは！最近は花粉がきついですね 3文字目から5文字目までを表示します にちは

a

答え

python

# ユーザーから入力された文字列の2文字目から5文字目までを取り出し、画面に出力してください。
# ※先頭を0文字目と考えること

str = input('文字列を入力 : ')
sliced_str = str[2:6]
print('2文字目から5文字目までを表示します')
print(sliced_str)

a
