データの削除(Delete)

今回はpythonとそのライブラリであるsqlite3を使用して、データベースのデータを削除する方法を紹介します。

データの削除方法

データの削除方法を見ていきましょう。

データを削除するSQL文

sql

DELETE FROM テーブル名 WHERE 条件

データを削除するときはDELETE を使います。

FROM テーブル名で、どのテーブルかを指定します。

WHERE 条件で、どの行のデータを削除するかを指定します。
WHERE句がなければ、テーブル内のすべての行のデータが削除されてしまうので、基本的に必ずつけるようにしましょう。

実際にデータを削除してみよう

「データの保存(Create)」で保存したデータを削除してみましょう。

新たにdelete.pyというファイルを作成してください。

delete.pyの内容を以下のようにしてください。

delete.py

python

import sqlite3

dbname = 'TEST.db'
conn = sqlite3.connect(dbname)
cur = conn.cursor()

**# データを削除する
cur.execute('DELETE FROM person WHERE id = 1')**

conn.commit()

cur.close()
conn.close()

delete.pyを実行してください。

TEST.dbの内容が以下のようになっていれば削除に成功です。

a

コードを見ていきましょう。

SQL文は以下のようになっています。

sql

DELETE FROM person WHERE id = 1

DELETEでデータを削除することを示しています。

FROM personで、対象がpersonテーブルであることを示しています。

WHERE id = 1 で、対象がid=1の行であることを示しています。

任意のデータを扱う

データの削除をより実用的に扱う場合、任意の行のデータを削除できる必要があります。

任意の行のデータを削除する方法を見ていきましょう。

例：任意のidの行を削除する

python

cur.execute('DELETE FROM テーブル名 WHERE id = ?', (削除したい行のid,))

🛑 cur = cursorオブジェクト

例えば、personテーブルで、任意のidの行のデータを削除したければ、以下のようなコードになります。

personテーブルで任意のidの行のデータを削除する

python

import sqlite3

dbname = 'TEST.db'
conn = sqlite3.connect(dbname)
cur = conn.cursor()

**# 任意の値を入れる
target_id = 1

# データを削除する
cur.execute('DELETE FROM person WHERE id = ?', (target_id, ))**

conn.commit()

cur.close()
conn.close()

このコードでは、target_idの値によって、任意のidの行を削除できます。
