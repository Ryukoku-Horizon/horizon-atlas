テーブルの編集

テーブルの編集

今回は、既存のテーブルを後から編集する方法を説明します。

テーブルの編集方法

テーブルを編集する方法を見ましょう。

テーブルを編集するSQL文

sql

ALTER TABLE テーブル名 編集内容

テーブルを編集するには、ALTER TABLEを使います。

編集内容の部分には、カラム名の変更、カラムの追加、カラムの削除のいずれかが入ります。
順番に見ていきましょう。

カラム名の変更

カラム名の変更

sql

ALTER TABLE テーブル名 RENAME COLUMN 古いカラム名 TO 新しいカラム名

既存のカラムの名前を変更するにはRENAME COLUMNを使います。

例：personテーブルのカラムnameをfull_nameに変更する

sql

ALTER TABLE person RENAME COLUMN name TO full_name

この例では、personテーブルのnameカラムをfull_nameという名前に変更します。

カラムの追加

カラムの追加

sql

ALTER TABLE テーブル名 ADD 新しいカラム名 データ型

カラムを追加するにはADDを使用します。

例：personテーブルにjobカラムを追加する

sql

ALTER TABLE person ADD job TEXT

この例では、personテーブルに、新たなカラムjobを追加しています。

カラムの削除

カラムの削除

sql

ALTER TABLE テーブル名 DROP COLUMN カラム名

カラムを削除するには、DROP COLUMNを使用します。

例：personテーブルのageカラムを削除する

sql

ALTER TABLE person DROP COLUMN age

この例では、personテーブルのageカラムを削除します。
