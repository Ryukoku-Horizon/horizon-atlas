カラムの属性

ここではSQLで使える主なカラムの属性について列挙します。

テーブルを作成する際に参考にしてください。

データ型

整数型

・INTEGER: 整数を保存します。通常、範囲は -2,147,483,648 ～ 2,147,483,647。

・SMALLINT: INTEGER より小さな範囲の整数（-32,768 ～ 32,767）。

浮動小数点型

・FLOAT: 浮動小数点数を保存します。精度はデータベースごとに異なります。

文字列型

・TEXT : 文字列型

・CHAR(n): 固定長文字列。n で文字数を指定します。文字数が不足している場合、スペースで埋められます。

・VARCHAR(n): 可変長文字列。n で最大文字数を指定します。文字数が不足してもスペースで埋めません。

日付と時刻

・DATE: 日付を保存します（YYYY-MM-DD 形式）。

・TIME: 時間を保存します（HH:MM:SS 形式）。

・DATETIME: 日付と時間を合わせて保存します（YYYY-MM-DD HH:MM:SS 形式）。

・TIMESTAMP: 日付と時間を保存し、通常は自動的に現在時刻に更新するオプションもあります。

真偽型

・BOOLEAN：真偽型。0または1として保存されるため、実際にはINTEGER型として動作する。そのため注意が必要。

制約

PRIMARY KEY

・テーブル内で各行を一意に識別するカラムに設定します。PRIMARY KEY に指定されたカラムは重複を許さず、NULL 値も許可しません。

・例: id INTEGER PRIMARY KEY

AUTOINCREMENT

・主に PRIMARY KEY カラムに使用され、自動的に一意の連番を生成します。

・例: id INTEGER PRIMARY KEY AUTO_INCREMENT

UNIQUE

・特定のカラムが一意であることを保証します。同じテーブル内で重複する値が入ることを防ぎます。

・例: email VARCHAR(100) UNIQUE

NOT NULL

・NULL 値を禁止し、必ずデータを入力しなければならないように設定します。

・例: name VARCHAR(50) NOT NULL

CHECK

・カラムに入力されるデータが特定の条件を満たすかどうかをチェックします。

・例: age INTEGER CHECK (age >= 18)

DEFAULT

・カラムにデータが指定されなかった場合に、デフォルト値を自動的に設定します。

・例：created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP

FOREIGN KEY

・他のテーブルの PRIMARY KEY と関連付けをすることで、リレーション（外部キー制約）を作成します。参照整合性を保つために使われます。

・例: user_id INT, FOREIGN KEY (user_id) REFERENCES users(id)

ON DELETE CASCADE / ON UPDATE CASCADE

・外部キーに設定し、参照元のデータが削除または更新された際に、連動して子テーブルのデータも削除または更新するようにします。

・例: FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE
