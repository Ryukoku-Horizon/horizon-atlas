データの編集(Update)

今回はpythonとそのライブラリであるsqlite3を使用して、データベースのデータを編集する方法を紹介します。

データの編集方法

データの編集方法を見てきましょう。

データを編集するSQL文

sql

UPDATE テーブル名 SET カラム名 = 値 WHERE 条件

データを編集するときはUPDATEを使います。

テーブル名の部分でどのテーブルかを指定します。

SET カラム名 = 値 で、どのカラムのデータの値を何にするかを指定します。

WHERE 条件 で、どの行のデータかを指定します。
WHERE句がなければテーブルの中のすべてのデータを書き換えてしまうので、基本的につけるようにしましょう。
WHEREで指定する条件は、ほとんどの場合「idが何か」です。

例えば、id=1の行のデータを編集したい場合は次のように書きます。

id=1のデータを編集する

sql

UPDATE テーブル名 SET カラム名 = 値 WHERE id = 1

実際にデータを編集してみよう

「データの保存(Create)」で保存したデータの値を編集してみましょう。

update.pyというファイルを作成してください。

update.pyの内容を以下のようにしてください。

update.py

python

import sqlite3

dbname = 'TEST.db'
conn = sqlite3.connect(dbname)
cur = conn.cursor()

**# データの編集
cur.execute('UPDATE person SET name = "Fujiwara", age = 69, gender = "Woman" WHERE id = 1')**

conn.commit()

cur.close()
conn.close()

update.pyを実行してください。

TEST.dbの内容が以下のようになっていれば編集に成功しています。

では、コードを見ていきましょう。

SQL文は以下のようになっています。

sql

UPDATE person SET name = "Fujiwara", age = 69, gender = "Woman" WHERE id = 1

UPDATE で、データを編集することを示しており、その後のpersonで、対象がpersonテーブルであることを示しています。

SET name = "Fujiwara", age = 69, gender = "Woman" の部分で、カラムnameの値を”Fujiwara”に変更し、カラムageの値を69に変更し、カラムgenderの値を”Woman”に変更することを指定しています。

WHERE id = 1 で、idが1の行が対象であることを指定しています。

任意のデータを扱う

データの編集をより実用的に扱うためには、任意の値でデータを編集したり、任意の値で条件を指定する必要があります。

任意の値でデータを編集する方法を見ていきましょう。

任意の値で、任意のidの行のデータを編集する方法

python

cur.execute('UPDATE テーブル名 SET カラム名 = ? WHERE id = ?', (編集後の値, 指定したいid))

🛑 cur = cursorオブジェクト

例えば、personテーブルの任意のidの行のデータを任意の値で編集するには以下のようなコードとなります。

personテーブルを任意の値で、任意のidの行のデータを編集する

python

import sqlite3

dbname = 'TEST.db'
conn = sqlite3.connect(dbname)
cur = conn.cursor()

**# 任意の値を入れる
name = "Tanaka"
age = 89
gender = "Man"
target_id = 1

# データの編集
cur.execute('UPDATE person SET name = ?, age = ?, gender = ? WHERE id = ?',(name, age, gender, target_id))**

conn.commit()

cur.close()
conn.close()

このコードで、personテーブルの任意のidの行のデータを、任意の値で編集できます。
